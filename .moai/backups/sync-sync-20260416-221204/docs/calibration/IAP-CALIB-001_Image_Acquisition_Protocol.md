## 1. 문서 정보 및 범위

### 1.1 개요

이 문서는 X-ray Flat Panel Detector (FPD) 캘리브레이션 시스템을 위한 **영상 취득 프로토콜**입니다. 

- **범위**: 제조 공장(Factory) 및 의료 현장(Field)에서 캘리브레이션 영상을 취득하는 절차
- **대상**: 캘리브레이션 엔지니어, 현장 서비스 기술자
- **용도**: 오프셋 맵, 게인 맵, 불량 픽셀 맵, 비선형성 곡선, Lag/Ghost 특성 측정

### 1.2 지원 검출기

| 검출기 유형 | 대표 모델 | 취득 특이사항 |
|-----------|---------|-----------|
| a-Si TFT FPD | Varex XRD 4343N | 높은 온도 민감도, 필수 래그 보정 |
| CMOS FPD | Vieworks VIVIX-S | 낮은 래그, 높은 동적 범위 |
| Perovskite FPD | 연구 단계 | 특수 비선형성 보정 필요 |
| Direct FPD (Se/CdTe) | Siemens, Philips | 고유한 결함 패턴 |

### 1.3 문서 갱신 기록

| 버전 | 일자 | 변경 사항 |
|-----|------|---------|
| 1.0.0 | 2026-04-14 | 초판 발행 |

## 2. 목적 및 적용

### 2.1 목적

캘리브레이션 영상 취득의 일관성, 품질, 추적성을 보장합니다:

1. **일관성**: 모든 기술자가 동일한 프로토콜을 따르는 캘리브레이션 영상 취득
2. **품질**: 명확한 합격/불합격 기준을 통한 영상 품질 보증
3. **추적성**: 취득 조건, 장비, 환경 기록 (IEC 62304 요구)
4. **재현성**: 공장 캘리브레이션과 현장 업데이트 간 일관된 결과

### 2.2 적용 범위

이 프로토콜은 다음을 적용합니다:

- **Factory 캘리브레이션** (제조 공장 신규 검출기)
- **Field 캘리브레이션** (현장 설치 후 QA 및 주기적 검증)
- **Emergency 재캘리브레이션** (온도 드리프트, 신규 X-ray 튜브 설치)

## 3. 용어 정의

### 3.1 핵심 개념

| 용어 | 정의 |
|-----|------|
| **Dark Frame** | X-ray 발생기가 OFF인 상태에서 촬영한 영상 (어두운 전류 측정용) |
| **Flat-field Frame** | 균일한 X-ray 조사 상태에서 촬영한 영상 (검출기 감도 불균일성 측정용) |
| **Offset Map** | 어두운 프레임으로부터 계산한 어두운 전류 맵 (픽셀 오프셋 보정용) |
| **Gain Map** | 플랫-필드 프레임으로부터 계산한 게인/감도 맵 (픽셀 표준화용) |
| **BPM** | Bad Pixel Map (불량 픽셀 맵, 결함 픽셀 위치 기록) |
| **SID** | Source-to-Image Distance (X-ray 발생원에서 검출기까지 거리) |
| **PREP Time** | Preparation Time (X-ray 조사 전 검출기 대기 시간, 온도 안정화용) |
| **Saturation** | 검출기 ADC가 최대값에 도달한 상태 (신호 포화) |

### 3.2 신호 수준 표기

| 용어 | 의미 |
|-----|------|
| **10% 포화** | 검출기 ADC 최대값의 10% 수준 신호 (약 409 ADU at 14-bit) |
| **50% 포화** | 검출기 ADC 최대값의 50% 수준 신호 (약 2048 ADU at 14-bit) |
| **90% 포화** | 검출기 ADC 최대값의 90% 수준 신호 (약 3686 ADU at 14-bit) |

### 4.1 필수 X-ray 장비

### 4.2 캘리브레이션 스탠드 및 팬텀

## 5. 일반 취득 전 조건

### 5.1 워밍업 절차

#### 5.1.1 검출기 워밍업

**목적**: 검출기 내부 온도 안정화

**절차**:

1. **전원 공급**: 검출기 전원 ON (교정된 전압 인가)
2. **대기 시간**: 최소 30분 이상 대기
3. **온도 확인**: NTC 센서에서 읽은 온도 기록
   - 기준 온도: 25°C ±2°C (권장)
   - 편차 > 2°C인 경우: 추가 대기
4. **환경 확인**: 실내 온도 안정화 (±1°C 이상 변동 없음)

#### 5.1.2 X-ray 발생기 워밍업

**목적**: 튜브 열, kVp/mAs 안정화

**절차**:

1. **고압 ON**: 100 kVp, 50 mAs로 시작
2. **워밍업 노출**: 5~10회 반복 노출 (열 누적)
3. **온도 확인**: 튜브 온도가 안정 범위 내 확인
4. **kVp/mAs 확인**: 최대 편차 ±2% 이내
5. **대기**: 최소 15분 추가 안정화

### 5.2 환경 조건 기록

**취득 전 다음 조건을 기록하세요**:

| 항목 | 기록값 | 비고 |

| 상대 습도 (%) | __ | 참고용 (25~75% 권장) |
| 검출기 온도 (°C) | __ | NTC 센서 값 |
| X-ray 튜브 온도 (°C) | __ | 발생기 표시 온도 |
| kVp 설정값 | __ | 확인된 값 기록 |
| 기본 mAs | __ | 참고용 |
| 캘리브레이션 날짜/시간 | __ | YYYY-MM-DD HH:mm |

**반드시 확인하세요**:

- [ ] 모든 인원이 제어실에 있거나 리드 앞치마 착용

## 6. 캘리브레이션 영상 유형별 취득 프로토콜

### 6.1 Dark Frame (오프셋 맵용)

#### 6.1.1 목적

X-ray 발생기가 OFF인 상태에서 픽셀별 어두운 전류(offset)를 측정합니다.

- **사용처**: Offset Map 생성 (다른 모든 영상에서 차감)
- **특성**: 온도, PREP time에 매우 민감

#### 6.1.2 필요 장비

- 검출기 (X-ray 실 내 정상 위치)
- X-ray 발생기 (OFF 상태)
- 환경: X-ray 실 표준 조명 가능 (어둠 불필요)
- NTC 온도 센서

#### 6.1.3 X-ray 조건

| 항목 | 설정 |
|-----|------|
| **X-ray 발생기** | **OFF** (조사 없음) |
| **Anti-scatter Grid** | 제거 또는 위치 (영향 미미) |
| **선원 거리 (SID)** | 기록만 (영향 없음) |

#### 6.1.4 팬텀 설정

| 항목 | 설정 |
|-----|------|
| **팬텀** | **없음** (필요 없음) |
| **검출기 앞** | 자유 공간 |

#### 6.1.5 취득 단계 (Factory 프로토콜)

**Factory**: 온도×PREP time 매트릭스 (42 dark map entries)

**단계 1**: 온도 포인트 설정 (6개)
```
온도 포인트: 15°C, 20°C, 25°C, 30°C, 35°C, 40°C
```

**단계 2**: PREP time 레벨 설정 (7개)
```
PREP time: 1초, 2초, 5초, 10초, 15초, 20초, 30초
```

**단계 3**: 각 온도×PREP time 조합마다 다음 실행

```
FOR each Temperature T in [15, 20, 25, 30, 35, 40]:
    FOR each PREP_Time P in [1, 2, 5, 10, 15, 20, 30]:
        
        Step 3a. 온도 안정화
        ├─ 검출기를 온도 T로 조절
        ├─ 온도 변화 < 0.1°C/분 확인
        └─ 최소 10분 대기 (온도 드리프트 최소화)
        
        Step 3b. PREP time 설정 (Dark Frame 취득 전 대기)
        ├─ HnVue에서 PREP time = P 초로 설정
        └─ 이 기간 동안 검출기 판독 준비 (전하 누적 시뮬레이션)
        
        Step 3c. Dark Frame 수집
        ├─ N = 100 프레임 연속 수집
        │  (X-ray는 계속 OFF)
        ├─ 프레임 시간 간격: 1 프레임/초
        └─ 획득 시간: 약 100초
        
        Step 3d. 메타데이터 기록
        ├─ 파일명: dark_T[temp]_P[prep_time].raw
        ├─ 취득 시간, 온도, PREP time, 프레임 수
        └─ 예: dark_T25.0_P10.0.raw
        
        Step 3e. 합격 기준 확인 (6.1.7 참조)
```

**단계 4**: 모든 42개 조합 완료 확인

#### 6.1.6 취득 수량

| Factory | Field |
|---------|-------|
| **N = 100 프레임** × 42 조합 | **N = 16 프레임** (또는 2개 post-exposure dark) |
| **총 4,200 프레임** | 빠른 업데이트용 (30분마다 가능) |

#### 6.1.7 합격 기준

**취득 후 각 dark map에 대해 다음을 확인**:

| 기준 | 임계값 | 합격/불합격 판정 |
|-----|--------|---------|
| **평균 어두운 수준** | 30~100 ADU (14-bit) | < 10 ADU: **불합격** (신호 너무 작음) |
| **표준편차 (σ)** | σ < 5 ADU | > 5 ADU: **불합격** (노이즈 과다) |
| **σ/μ 비율** | < 5% | > 5%: **불합격** (상대 노이즈 과다) |
| **온도 안정도** | ±0.5°C | > ±0.5°C 편차: **재촬영** |
| **프레임 모자란 경우** | N ≥ 100 (또는 16 for Field) | N < 요구값: **재촬영** |

**조치**:
- **합격**: 파일 저장, 계속 진행
- **불합격**: Section 8 (재촬영 조건) 참조

#### 6.1.8 주의사항

1. **온도 안정화 필수**: 매 온도마다 최소 10분 대기 (드리프트 < 0.1°C/분)
2. **PREP time 간격**: 1~30초까지 모두 취득 (선형 보간용)
3. **X-ray OFF 확인**: 발생기 OFF LED 점등 확인
4. **환경 진동**: 취득 중 진동 최소화 (근처 장비 OFF)
5. **저장 형식**: `.raw` 16-bit unsigned 또는 DICOM 형식

#### 6.1.9 취득 시간 추정

- **온도 1개**: 약 7 × 100초 + 온도 변경 시간 = ~12분
- **온도 6개 전체**: 약 72분 (+ 온도 변경/안정화 = ~2시간)

### 6.2 Flat-field Frame (게인 맵용)

#### 6.2.1 목적

균일한 X-ray 조사 하에서 픽셀별 감도(게인)를 측정합니다.

- **사용처**: Gain Map 생성 (픽셀 표준화)
- **특성**: SID, 필터, 팬텀에 매우 민감

#### 6.2.2 필요 장비

- 검출기 (정상 위치)
- X-ray 발생기 (RQA-5 스펙트럼 설정)
- 균일 산란 팬텀 (3cm PMMA)
- Anti-scatter Grid (제거 또는 기록)
- NTC 온도 센서

#### 6.2.3 X-ray 조건

| 항목 | 설정 |
|-----|------|
| **kVp** | **70 kVp** (RQA-5 표준) |
| **필터** | **21 mm Al** (RQA-5 표준) |
| **노출 시간** | 30~50 ms (선량계 확인) |
| **mAs** | 신호 40~60% 포화되도록 조절 |
| **Anti-scatter Grid** | **제거** (균일성 영향) |

#### 6.2.4 팬텀 설정

| 항목 | 설정 |
|-----|------|
| **팬텀** | 3cm PMMA 균일 산란 팬텀 |
| **위치** | 검출기 정면, 중심 정렬 |
| **높이** | X-ray 빔 중앙 (혼자 시야 필드) |

#### 6.2.5 취득 단계 (Factory 프로토콜 - Duo-SID 방식)

**목표**: 두 개의 SID에서 각각 20 프레임씩 플랫-필드 취득 (힐 효과 보상)

**단계 1**: SID 설정 (두 거리)

```
SID_min = 110 cm  (또는 최단 허용 거리)
SID_max = 150 cm  (또는 최장 임상 거리)
```

**단계 2**: SID_min에서 취득

```
Step 2a. SID 설정 및 확인
├─ X-ray 튜브-검출기 거리를 110 cm로 설정
├─ 눈금자로 정확히 측정 (±1 mm)
├─ 검출기 중심과 X-ray 중심 정렬
└─ 환기/냉각 장비 확인 (열 누적 방지)

Step 2b. mAs 조절 (신호 40~60% 포화)
├─ 테스트 노출: 기본 mAs로 한 프레임 취득
├─ 신호 수준 확인 (평균 ADU 기대값):
│  40% 포화 = 2621 ADU (14-bit)
│  60% 포화 = 3932 ADU (14-bit)
├─ 신호 < 40%: mAs 증가
├─ 신호 > 60%: mAs 감소
└─ 재테스트 후 확정

Step 2c. Dark Frame 취득 (Flat-field 직전)
├─ X-ray OFF로 설정
├─ 검출기가 dark frame을 자동 수집
├─ N = 20 프레임 (flat-field과 동일 수)
└─ 파일명: dark_sid110_pre.raw

Step 2d. Flat-field Frame 취득
├─ X-ray ON (70 kVp, 21 mm Al, 확정된 mAs)
├─ PREP time = 10초 설정 (안정화)
├─ 10초 대기 (검출기 자동 준비)
├─ P = 20 프레임 연속 수집
│  (각 프레임 = 단일 노출)
├─ 프레임 간격: 1 프레임/초
├─ 획득 시간: 약 20초
└─ 파일명: ff_sid110_70kv_21al.raw

Step 2e. 메타데이터 기록
├─ 취득 시간, SID, kVp, 필터, mAs
├─ 평균 신호 수준 (ADU)
├─ 신호 표준편차
└─ 팬텀 위치, 온도
```

**단계 3**: SID_max에서 취득 (단계 2 반복)

```
mAs를 SID_max에 맞춰 조절
(일반적으로 더 큰 거리 = 더 높은 mAs 필요)

예: SID_max = 150 cm에서 신호 40~60% 포화되도록
(증가된 거리 = 신선량 감소 = mAs ↑)
```

**단계 4**: 다중 게인 레벨 취득 (선택, 권장)

```
고급: 신호 10%, 30%, 50%, 70%, 90% 포화 수준에서
각각 P=20 프레임씩 취득 (다항식 게인 피팅용)
```

#### 6.2.6 취득 수량

| Factory | Field |
|---------|-------|
| **P = 20 프레임** × 2 SID | **P = 20 프레임** (또는 기준 SID 1개) |
| + Dark: 20 × 2 | + Dark: 20 |
| **총 80 flat-field 프레임** | **총 40 프레임** (또는 20) |

#### 6.2.7 합격 기준

**취득 후 각 flat-field 세트에 대해**:

| 기준 | 임계값 | 합격/불합격 |
|-----|--------|----------|
| **신호 범위** | 40~60% 포화 | < 40%: **불합격** (신호 부족) |
| | | > 60%: **불합격** (과포화 위험) |
| **균일성** | σ/μ < 1% (80% FOV) | > 1%: **불합격** (팬텀/조정 확인) |
| **중심 빔 위치** | (cx, cy) 기록 | 편차 > 5mm: **재조정** |
| **암부 신호** | < 5% 포화 | 암부 > 5%: **불합격** (스캐터 과다) |
| **프레임 수** | P ≥ 20 | P < 20: **재촬영** |

**조치**:
- **합격**: 맵 생성 진행
- **불합격**: Section 8 참조

#### 6.2.8 주의사항

1. **팬텀 위치**: 프레임마다 동일 위치 (움직임 없음)
2. **Anti-scatter Grid 제거**: 그리드 있으면 균일성 악화
3. **빔 중심 기록**: (cx, cy) 픽셀 좌표 기록 (힐 효과 보상)
4. **튜브 열 관리**: 연속 노출 시 냉각 대기 필요
5. **신호 안정화**: PREP time = 10초 필수

#### 6.2.9 취득 시간 추정

- **SID 1개** (2 SID 방식): 약 5분 (팬텀 설정 제외)
- **2 SID 전체**: 약 15분 (SID 변경 + 재정렬)

### 6.3 불량 픽셀 맵 (BPM) 생성용 영상

#### 6.3.1 목적

세 온도 수준에서 핫(hot) 픽셀과 데드(dead) 픽셀을 검출합니다.

- **사용처**: Bad Pixel Map (결함 픽셀 검출 및 보간)
- **특성**: 온도 의존 (핫 픽셀), 신호 의존 (데드 픽셀)

#### 6.3.2 필요 장비

- 검출기
- X-ray 발생기 (70 kVp, 21 mm Al, 팬텀)
- NTC 온도 센서
- 균일 산란 팬텀

#### 6.3.3 X-ray 조건

| 항목 | 설정 |
|-----|------|
| **kVp** | **70 kVp** (표준) |
| **필터** | **21 mm Al** (표준) |
| **신호 수준** | **50% 포화** (일정한 조건) |
| **SID** | 기준 거리 (예: 110 cm) |

#### 6.3.4 측정 절차

**세 온도에서 각각**: 200 Dark + 200 Flat-field 프레임

```
FOR each Temperature T in [cold, nominal, warm]:
    
    T_cold   = 15°C (또는 최저 임상)
    T_nominal = 25°C (기준)
    T_warm   = 35°C (또는 최고 임상)
    
    Step 4a. 온도 조절 및 안정화
    ├─ 검출기를 온도 T로 설정
    ├─ 온도 안정화: ±0.1°C 이내
    └─ 최소 10분 대기
    
    Step 4b. Hot Pixel 검출 (Dark Frame)
    ├─ X-ray OFF
    ├─ T = 200 dark 프레임 수집
    │  (온도 의존 누설 전류 측정)
    ├─ PREP time = 20초 (최대 누설 조건)
    └─ 파일명: dark_bpm_T[temp].raw
    
    Step 4c. Dead Pixel 검출 (Flat-field Frame)
    ├─ X-ray ON (70 kVp, 21 mm Al)
    ├─ 신호 = 50% 포화 (명확한 신호/노이즈)
    ├─ T = 200 flat-field 프레임 수집
    │  (응답 없는 픽셀 검출)
    └─ 파일명: ff_bpm_T[temp]_50sat.raw
```

#### 6.3.5 취득 수량

| 항목 | 수량 |
|-----|------|
| **온도 포인트** | 3개 (15°C, 25°C, 35°C) |
| **Dark Frame/온도** | 200 |
| **Flat-field Frame/온도** | 200 |
| **총 프레임** | (200+200) × 3 = **1,200 프레임** |

#### 6.3.6 합격 기준

**검출 후 BPM에 대해**:

| 기준 | 임계값 | 조치 |
|-----|--------|------|
| **결함 픽셀 비율** | < 1% | > 1%: **불합격** (검출기 불량) |
| **Hot pixel 격자** | 나이퀴스트 조건 (2×2 이상 간격) | 밀집 결함: **대안 검출기** |
| **Dead pixel 패턴** | 임의 분포 | 줄(row)/열(column) 패턴: **재검사** |
| **온도 의존성** | 뜨거운 쪽 more defects | 반대: **재촬영** |

#### 6.3.7 주의사항

1. **온도 정확도**: 각 온도마다 정확히 설정 (±0.5°C)
2. **PREP time**: Hot pixel 검출에는 긴 PREP time (20초) 권장
3. **프레임 200개 필수**: 통계 신뢰도 높음

#### 6.3.8 취득 시간 추정

- **온도 1개**: 약 50분 (dark + flat-field)
- **3 온도 전체**: 약 2.5~3시간

### 6.4 비선형성 측정용 영상

#### 6.4.1 목적

여러 신호 수준에서 픽셀 응답 곡선을 측정합니다 (선형화 곡선 계산).

- **사용처**: 비선형성 Look-Up Table (LUT) 또는 다항식 계수
- **특성**: 신호 수준에 매우 의존

#### 6.4.2 필요 장비

- 검출기
- X-ray 발생기 (70 kVp, 21 mm Al)
- 스텝 웨지 또는 여러 산란 팬텀
- NTC 온도 센서

#### 6.4.3 신호 수준 설정

**최소 5개 신호 수준** (권장 7~10개):

| 신호 수준 | ADU 값 (14-bit) | 포화 비율 |
|----------|--------|-----------|
| Level 1 | 655 | 5% |
| Level 2 | 1310 | 10% |
| Level 3 | 2621 | 20% |
| Level 4 | 4096 | **30%** |
| Level 5 | 6553 | **50%** |
| Level 6 | 8192 | 62.5% |
| Level 7 | 10240 | 78% |
| Level 8 | 11469 | 88% |
| Level 9 | 12290 | 94% |

#### 6.4.4 측정 절차

```
FOR each Signal_Level E in [5%, 10%, 20%, ..., 90%]:
    
    Step a. 신호 수준 맞춤 (mAs 조절)
    ├─ 테스트 프레임 1개 취득
    ├─ 평균 신호 확인
    ├─ 목표 신호 수준이 될 때까지 mAs 조절
    └─ 최대 3회 반복 조절
    
    Step b. 다중 프레임 취득 (신뢰도)
    ├─ N = 16 프레임 연속 수집
    │  (같은 mAs 설정)
    ├─ 프레임 평균화 (노이즈 감소)
    └─ 파일명: nlin_E[level]_[percent]sat.raw
```

#### 6.4.5 취득 수량

| 항목 | 수량 |
|-----|------|
| **신호 수준** | 최소 5 (권장 7~10) |
| **프레임/수준** | 16 |
| **총 프레임** | 5 × 16 = **80 프레임** (최소) |

#### 6.4.6 합격 기준

**비선형성 보정 후**:

| 기준 | 임계값 |
|-----|--------|
| **R² 값** | > 0.999 (다항식 피팅) |
| **잔차 > 1%** | < 5% 픽셀 |
| **보정 후 평탄도** | σ/μ < 0.5% |

#### 6.4.7 주의사항

1. **신호 선형성**: mAs와 신호의 선형 관계 확인
2. **포화 회피**: 90% 포화 이상 피할 것 (과포화 시작)
3. **온도 안정**: 측정 중 온도 변동 < 0.5°C

#### 6.4.8 취득 시간 추정

- **신호 5개 수준**: 약 20분 (각 수준당 1회 조절 가정)

### 6.5 Lag/Ghost 측정용 영상

#### 6.5.1 목적

노출 후 전하 갇힘 시간 상수(Lag)를 측정합니다.

- **사용처**: 래그 보정 계수 (지수 상수 τ 등)
- **특성**: 신호 수준, 온도, 노출 조건 의존

#### 6.5.2 필요 장비

- 검출기
- X-ray 발생기 (70 kVp, 21 mm Al)
- 균일 산란 팬텀
- NTC 온도 센서

#### 6.5.3 측정 절차

**9개 신호 수준에서 각각: FSRF + RSRF 측정**

```
FOR each Signal_Level E in [2%, 5%, 10%, 20%, 30%, 50%, 70%, 80%, 92%]:
    
    Step a. 검출기 안정화
    ├─ 20개 dark 프레임 취득
    │  (신호 가공을 위한 기준선)
    └─ 파일명: dark_lag_E[level].raw
    
    Step b. FSRF 측정 (Falling Step Response Function)
    │ (노출 ON → OFF 모니터링)
    │
    ├─ 노출 수준을 E% 포화로 설정 (mAs 확인)
    ├─ X-ray ON
    ├─ N_pre = 200 프레임 수집 (안정 신호)
    ├─ X-ray OFF (즉시)
    ├─ N_post = 200 프레임 연속 수집
    │  (감쇠하는 래그 신호 기록)
    ├─ 프레임 시간: 30 Hz (약 33 ms 간격)
    └─ 파일명: fsrf_E[level]_[percent]sat.raw
    
    Step c. RSRF 측정 (Rising Step Response Function)
    │ (노출 OFF → ON 모니터링)
    │
    ├─ N_pre = 50 dark 프레임
    ├─ X-ray ON (신호 수준 E%)
    ├─ N_post = 200 프레임 수집
    │  (상승하는 신호 + 미세 과조사 기록)
    └─ 파일명: rsrf_E[level]_[percent]sat.raw
```

#### 6.5.4 취득 수량

| 항목 | 수량 |
|-----|------|
| **신호 수준** | 9개 |
| **FSRF 프레임/수준** | 200 + 200 = 400 |
| **RSRF 프레임/수준** | 50 + 200 = 250 |
| **Dark 프레임/수준** | 20 |
| **총 프레임/수준** | 400 + 250 + 20 = **670** |
| **전체 총계** | 670 × 9 = **6,030 프레임** |

#### 6.5.5 합격 기준

**래그 보정 후**:

| 기준 | 임계값 |
|-----|--------|
| **1차 프레임 래그** | < 0.3% |
| **50차 프레임 래그** | < 0.01% |
| **지수 피팅 R²** | > 0.98 |
| **신호 수준 선형성** | 반경향성 일관 |

#### 6.5.6 주의사항

1. **프레임 레이트**: 일정한 프레임 간격 (30 Hz 권장)
2. **노출 전환**: 즉시 X-ray 켜짐/꺼짐 (서서히 아님)
3. **온도 안정**: 측정 중 온도 변동 < 1°C

#### 6.5.7 취득 시간 추정

- **신호 수준 1개**: (400+250+20) / 30 fps ≈ 23초
- **9 수준 전체**: 약 3.5분 (수준 간 전환 제외)

```
│ - 균일성: σ/μ < 임계값?     │
│ - 어두운 수준: < 임계값?    │
└─────┬──────────────┬─────────┘
      |              |
     YES            NO
      |              |
      v              v
  계속      → 조정/재촬영
      |
      v
┌──────────────────────────────┐
│ 아티팩트 검사                │

      |              |
      v              v
  ✓ 합격    → 실패 (Section 8)
```

## 8. 취득 실패 판정 및 재촬영 조건

### 8.1 실패 원인 분류

| 원인 | 증상 | 즉시 조치 |
|-----|------|--------|
| **온도 불안정** | ΔT > 0.5°C | 30분 대기 후 재촬영 |
| **신호 부족** | 평균 < 요구값의 50% | mAs ↑ 또는 기지 조절 |
| **신호 과잉** | 포화 > 임계값 | mAs ↓ 또는 거리 ↑ |
| **노이즈 과다** | σ > 임계값 | 프레임 수 ↑ 또는 환경 개선 |
| **팬텀 오위치** | σ/μ 불균일 | 팬텀 재정렬 |
| **X-ray 불안정** | 프레임 간 신호 편차 > 3% | 튜브 재워밍업 |
| **검출기 결함** | 계속되는 불합격 | 검출기 교체 검토 |

### 8.2 재촬영 절차

#### 8.2.1 온도 불안정 원인

**원인 분석**:
- 실내 에어컨 변동
- 검출기 워밍업 불충분
- 튜브 열 방출

**재촬영 조건**:
```
1. 원인 제거 (에어컨 안정화, 추가 워밍업 등)
2. 온도 안정화 대기: 30분 이상
3. 온도 편차 < 0.1°C/분 확인
4. 영상 재촬영
```

#### 8.2.2 신호 수준 불적절

**원인 분석**:
- mAs 설정 부정확
- SID 변경
- 팬텀 이동
- X-ray 필터 손상

**재촬영 조건**:
```
Dark Frame 불합격:
└─ 원인: X-ray OFF 확인 불완전
   재촬영: X-ray OFF LED 재확인 후

Flat-field Frame 불합격:
├─ 신호 < 40% 포화:
│  └─ mAs를 20~30% 증가
├─ 신호 > 60% 포화:
│  └─ mAs를 20~30% 감소
└─ 불균일 (σ/μ > 1%):
   └─ 팬텀 위치 확인, 재정렬
```

#### 8.2.3 아티팩트 발견

**증상**: 포화 픽셀, 스트라이프, 명확한 결함 영역

**재촠영 조건**:
```
1. 원인 식별:
   - 포화: mAs 감소 필요
   - 스트라이프: X-ray 간섭 또는 튜브 불안정
   - 결함: 검출기 결함 또는 팬텀 오염
   
2. 조치:
   - mAs 수정 또는 환경 개선
   - 장비 재확인
   
3. 재촬영
```
