## 1. 목적 및 범위

### 1.1 목적

이 소프트웨어 요건 명세(SRS)는 XPE 기본 강화 모듈(`xpe_enhance_basic.dll`, Layer 1, Phase 1b)의 모든 기능, 안전, 성능 및 인터페이스 요건을 정의합니다. 이 모듈은 float32 검출기 도메인 이미지를 받아서 4개 처리 단계(EI 기준선 + Log Transform + CLAHE + Window/Level)를 거쳐 float32 강화 도메인 이미지로 변환합니다.

### 1.2 범위

**포함**:
- EI 기준선 계산 (SWU-2.0, IEC 62494-1)
- Log Transform (Stage 5)
- CLAHE 처리 (Stage 6, Pizer 1987)
- Window/Level 매핑 (Stage 7, DICOM VOI LUT)
- 구성 관리 및 우회 정책
- 성능 및 메모리 제약

**제외**:
- 프리젠테이션 도메인 변환 (GSDF) → `gsvg.dll`
- ROI 콜리메이션 분석 → Phase 2
- AI 강화 → Phase 3

## 2. 기능 요건

### 2.1 EI 기준선 (SWU-2.0) - 그룹 FR-100

| Req ID | 요건 | 이유 | 검증 |
|--------|------|------|------|
| **FR-100-001** | 시스템은 검출기 도메인 float32 입력에서 EI(노출 지수)를 계산해야 함. 공식: `EI = K_gain × Q_mean`, 여기서 K_gain은 검출기별 보정 계수(ADU → 에어 커마), Q_mean은 이미지 평균 신호(검출기 도메인, 로그 변환 전). | IEC 62494-1 표준: EI는 검출기의 원시 신호에서 계산되며, 로그 변환 후 계산하면 지수 압축으로 인해 과다 추정됨. | EI 계산 정확도 ± 2% |
| **FR-100-002** | 시스템은 `DI = 10 × log10(EI / EI_T)`를 계산해야 함. 여기서 EI_T는 기준 노출 지수(검사/보기별). 수락 범위: `-1 ≤ DI ≤ +1`. 경고: `|DI| > 3`. | AAPM TG-232: DI ±1은 임상 표준 선량 범위. |DI| > 3은 이상 선량 경고. | DI 계산 정확도 ± 0.1 |
| **FR-100-003** | EI 계산은 Stage 5 (Log Transform) **전**에 수행되어야 함. 검출기 도메인 데이터가 여전히 선형일 때. | 데이터 도메인 규칙: EI는 검출기 도메인에서만 정의됨. 로그 변환 후 계산은 무효. | 우회 로직 검증: EI _계산 타이밍 로그에 기록 |
| **FR-100-004** | 스티치 이미지에서 EI 계산을 억제해야 함 (메타데이터 플래그 확인). 다중 조사 또는 무효 ROI인 경우도 마찬가지. | 여러 조사의 신호가 혼합되면 EI가 무의미함. | 우회 로직 테스트 (플래그 감지) |
| **FR-100-005** | K_gain은 검출기 교정 파일에서 로드해야 함 (ADU → 에어 커마 변환). 파일 형식: JSON. 값 범위: 0.001 ~ 1.0 (일반 FPD 범위). | K_gain의 정확도는 DI 정확도에 직접 영향. ± 2% 정확도 필요. | K_gain 로드 및 범위 검증 |
| **FR-100-006** | EI_T (기준 지수) 값은 검사 프로필에서 로드해야 함. 기본값은 IEC 62494-1 표준값 사용 (검사별). | EI_T가 없으면 DI = 0이 의미 없음. | EI_T 로드 및 기본값 검증 |

### 2.2 Log Transform (Stage 5) - 그룹 FR-200

| Req ID | 요건 | 이유 | 검증 |
|--------|------|------|------|
| **FR-200-001** | 시스템은 각 픽셀에서 `I_log(x,y) = log(I_calib(x,y) + ε)` 변환을 적용해야 함. | 동적 범위 압축 및 시각적 선형성. 로그는 단조 함수이므로 픽셀 순서 보존. | 로그 정확도 테스트: 수치 오류 < 0.01% |
| **FR-200-002** | ε(바닥 값)은 `max(1e-6 × dynamic_range, 1e-3)`로 계산해야 함. 동적 범위 = max(I) - min(I). | log(0) = -∞ 방지. ε는 이상치 방지. | ε 계산 검증 (입력별) |
| **FR-200-003** | Log Transform은 조건부 우회 불가능. 항상 실행 (필수). | Log Transform은 강화 파이프라인의 기초. 우회하면 다운스트림 CLAHE 입력이 선형. | 우회 로직 검증: 우회 실패 확인 |
| **FR-200-004** | 출력은 float32로 유지되어야 함. 오버플로우 보호: 최대값 3.4e38, 최소값 0.0. | Float32 범위 초과 방지 (infinity/NaN 생성 금지). | 범위 검증 테스트 |
| **FR-200-005** | 단조성 보증: `I1 < I2 ⟹ log(I1) < log(I2)`. 대비 반전 없음. | 로그는 단조증가 함수. 픽셀 순서 보존 필수. | 단조성 테스트: 100개 무작위 쌍 |

### 2.3 CLAHE (Stage 6) - 그룹 FR-300

| Req ID | 요건 | 이유 | 검증 |
|--------|------|------|------|
| **FR-300-001** | 시스템은 Pizer et al. (1987) CLAHE 알고리즘을 구현해야 함. (1) 타일 분할, (2) 로컬 히스토그램, (3) 클립 제한, (4) CDF, (5) 쌍선형 보간. | CLAHE는 적응형 명도 강화의 표준. 타일 기반 처리로 국소 대비 개선. | CLAHE 정확도: 참고 구현과 비교 |
| **FR-300-002** | 타일 크기는 구성 가능해야 함: 16 ~ 128 픽셀 (기본 64). 제약: tile_size < image_width / 4. | 타일이 너무 작으면 노이즈 증폭. 너무 크면 적응형 특성 상실. | 타일 크기 범위 검증 |
| **FR-300-003** | 클립 한계는 구성 가능: 0.01 ~ 0.1 (기본 0.03). 히스토그램 빈이 clip_limit을 초과하면 초과분 재분배. | 과도한 클립 → 노이즈 증폭. 적절한 클립 → 과도한 강화 방지. | 클립 한계 범위 검증 |
| **FR-300-004** | 타일 경계에서 쌍선형 보간을 적용해야 함 (이웃 4개 타일의 CDF 혼합). | 선형 보간 없으면 타일 경계에서 시각적 seam 아티팩트. | Seam 아티팩트 시각적 검사 |
| **FR-300-005** | 해부학 인식 구성: 검사 유형별 프리셋 (흉부, 골격, 복부, 소아). 각 프리셋은 tile_size와 clip_limit 최적값 포함. | 다른 조직은 다른 대비 특성. 프리셋은 해부학 최적화. | 프리셋 로드 및 적용 검증 |
| **FR-300-006** | 우회 가능: 구성 `clahe_enabled = false`. 우회 시 Stage 5 출력 → Stage 7 (Window). | 선택적 강화. 일부 임상 시나리오에서는 CLAHE 불필요. | 우회 로직 검증 |

### 2.4 Window/Level (Stage 7) - 그룹 FR-400

| Req ID | 요건 | 이유 | 검증 |
|--------|------|------|------|
| **FR-400-001** | 선형 윈도우 공식 구현: `I_out = clip((I_in - (WC - WW/2)) / WW, 0, 1)`. WC = Window Center, WW = Window Width. | VOI LUT 표준 변환. 관심 조직을 [0, 1] 범위로 정규화. | Window 정확도: 알려진 WC/WW → 예상 출력 |
| **FR-400-002** | 비선형 옵션 (시그모이드): `I_out = 1 / (1 + exp(-(I_in - WC) / WW))`. 부드러운 전환. | 임상에서 선택: 선형 vs 비선형. | 시그모이드 정확도 테스트 |
| **FR-400-003** | DICOM VOI LUT 호환성: DICOM SOP Class Window Preset 직접 지원. | 상호운용성: DICOM 보기기와 일관성. | DICOM VOI LUT 검증 (프리셋 로드) |
| **FR-400-004** | 표준 검사별 윈도우 프리셋 제공: 흉부 (폐, 종격동, 뼈), 골격, 복부 (간, 신장, 뼈), 투시. | 검사별 최적 윈도우. | 프리셋 로드 및 적용 검증 |
| **FR-400-005** | WW > 0 (양수) 검증. WW <= 0 → 오류 `XPE_ERR_INVALID_PARAM`. | 음수 너비는 무의미 (역 명도). | WW 범위 검증 |
| **FR-400-006** | 출력 클립: 모든 픽셀을 [0, 1]로 강제. 초과분은 clamp. | Float32 범위 강제. | 클립 검증: 범위 외 값 없음 |
