## 2. EI/DI 기준값 취득 (SWU-2.0 검증)

### 2.1 K_gain 캘리브레이션 취득

**목적**: K_gain = 에어 커마 / ADU_mean 계산

**프로토콜**:
- 장비: 알려진 에어 커마가 있는 교정된 선량계
- 기술: RQA-5 균일 조사 (IEC 62494-1)
- 노출: 5개 수준 (전체 범위)
- 프레임/수준: 10개
- 온도: 25°C ± 2°C

**합격 기준**:
- K_gain 범위: 0.001 ~ 1.0 (검출기 유형별)
- 선형성: R² > 0.99

### 2.2 EI_T 기준값 취득

**기준 상황**:
| 검사 | 뷰 | EI_T (IEC 62494-1 표준) |
|------|-----|--------------------------|
| 흉부 | PA | 100 |
| 흉부 | 측면 | 80 |
| 골격 (손) | PA | 120 |
| 복부 | AP | 110 |

**프로토콜**: 표준 임상 노출, 교정된 선량계로 검증

## 3. CLAHE 파라미터 최적화 취득

### 3.1 비교 팬텀

| 팬텀 | 용도 |
|------|------|
| CDRAD 2.0 | 세부 대비 감지 |
| Leeds TOR CDR | 대비-세부 곡선 |

### 3.2 프로토콜

**파라미터 그리드**:
- 타일 크기: 16, 32, 64, 128
- 클립 한계: 0.01, 0.03, 0.05, 0.07, 0.10
- 총 20개 조합

**합격 기준**:
- 세부 감지력 최대화
- 노이즈 증폭 < 3σ
- 아티팩트 없음

## 4. Window 프리셋 검증 취득

**프로토콜**: 임상 팬텀 + 해부학 검사별

| 검사 | 팬텀 | 프리셋 | 프레임 |
|------|------|--------|--------|
| 흉부 | ATOM | 폐, 종격동, 뼈 | 3 |
| 골격 | Rando | 뼈 | 1 |
| 복부 | ATOM 복부 | 간, 신장, 뼈 | 3 |

**합격 기준**: 주관적 임상 검토 (대비, 시인성)
