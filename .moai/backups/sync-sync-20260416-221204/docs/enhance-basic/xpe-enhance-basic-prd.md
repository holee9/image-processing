# XPE Basic Enhancement Algorithm - Product Requirements Document

**문서 ID**: xpe-enhance-basic-prd v1.0  
**모듈**: `xpe_enhance_basic.dll`  
**레이어**: Layer 1, Phase 1b  
**안전 등급**: IEC 62304 Class B  
**날짜**: 2026-04-14  
**상태**: Working Draft

---

## 개요

`xpe_enhance_basic.dll`은 X-ray FPD 이미지 처리 엔진의 기본 강화 모듈입니다. 캘리브레이션 전처리(`xpe_preprocess.dll`) 출력인 float32 검출기 도메인 이미지를 받아서 4개 단계를 거쳐 float32 강화 도메인 이미지로 변환합니다.

### 핵심 특징

- **4개 처리 단계 + EI 기준선** (총 5개 SWU)
- **SWU-2.0**: EI 기준선 (IEC 62494-1, 검출기 도메인에서 필수 계산)
- **Stage 5**: Log Transform (log 압축)
- **Stage 6**: CLAHE (적응형 히스토그램 균등화)
- **Stage 7**: Window/Level (창 처리)
- **데이터 도메인 전환**: 검출기 도메인 → 강화 도메인 (Stage 5에서)
- **성능 목표**: 프레임당 < 80ms (Phase 1 전체)

### 규범 참고 문헌

- **IEC 62494-1:2022**: Exposure Index (노출 지수) 표준
- **IEC 62304:2006+A1:2015**: 소프트웨어 생명주기 (Class B)
- **ISO 14971:2019**: 위험 관리
- **AAPM TG-232**: Exposure Index 임상 응용
- **DICOM PS3.4**: VOI LUT (Windowing 호환성)
- **Pizer et al. 1987**: CLAHE 알고리즘 원본 연구
- **Samei et al. 2015**: 이미지 품질 및 진단 신뢰도
- **Niemann et al. 2019**: 컨트라스트 강화 임상 효과

- **입력**: float32 검출기 도메인 이미지 (3072 × 3072, xpe_preprocess.dll 출력)

- **성능 제약**: 총 < 80ms/프레임

### 1.2 범위 외

- 프리젠테이션 도메인 변환 (GSDF 적용) → `gsvg.dll` 담당

## 2. 알고리즘 파이프라인

### 2.1 전체 처리 순서

```
float32 검출기 도메인 입력 (보정됨)
    ↓
┌─────────────────────────────────────┐
│ (SWU-2.0) EI 기준선 계산           │
│ 공식: EI = K_gain × Q_mean        │
│ 도메인: 검출기 도메인 (반드시!)  │
│ DI = 10 × log10(EI / EI_T)         │
│ 수락 범위: -1 ≤ DI ≤ +1           │
│ 경고: |DI| > 3                    │
│ 우회: 스티치 이미지, 다중 조사    │
└─────────────────────────────────────┘
    ↓ [검출기 도메인 데이터는 여기서 끝남]
┌─────────────────────────────────────┐
│ (Stage 5) Log Transform             │
│ I_log(x,y) = log(I_calib + ε)      │
│ ε = ~1e-6 × 동적 범위              │
│ 단조성 보장                        │
│ 우회 불가                          │
└─────────────────────────────────────┘
    ↓ [강화 도메인 시작]
┌─────────────────────────────────────┐
│ (Stage 6) CLAHE                     │
│ 타일 크기: 16~128 픽셀 (구성 가능)│
│ 클립 한계: 0.01~0.1 (구성 가능)   │
│ 쌍선형 보간 (타일 경계)           │
│ 해부학 인식 (검사별 프로필)        │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ (Stage 7) Window/Level              │
│ 선형: (I - WC + WW/2) / WW         │
│ 비선형: 시그모이드 옵션            │
│ DICOM VOI LUT 호환성               │
│ 검사 프리셋 (흉부, 골격, 복부)    │
└─────────────────────────────────────┘
    ↓
float32 강화 도메인 출력
```

### 2.2 EI 기준선 (SWU-2.0) - 임계 규칙

**⚠️ 중요**: EI는 검출기 도메인에서만 계산되어야 하며, Stage 5 로그 변환 **전**에 실행되어야 합니다.

**근거**: 
- IEC 62494-1 표준에서 EI는 검출기의 원시 신호 레벨을 기반으로 정의됨
- 로그 변환 후 계산하면 지수 압축으로 인해 EI가 과다 추정됨
- 따라서 EI 계산은 Phase 1b 시작 부분에서 발생해야 함

**공식**:
```
EI = K_gain × Q_mean

여기서:
  K_gain = 검출기 특정 게인 계수 (ADU → 에어 커마 변환)
  Q_mean = 검출기 도메인 평균 신호 (ADU)
  
DI (Dose Index) = 10 × log10(EI / EI_T)
  EI_T = 기준 노출 지수 (검사/보기별)
  수락 범위: -1 ≤ DI ≤ +1
  경고: |DI| > 3
  우회: 스티치 이미지, 다중 조사, 무효 ROI
```

### 2.3 Log Transform (Stage 5)

**목적**: 동적 범위 압축 및 시각적 선형성 개선

**공식**:
```
I_log(x,y) = log(I_calib(x,y) + ε)

여기서:
  ε = max(1e-6 × dynamic_range, 1e-3) (이상치 방지)
  dynamic_range = max(I_calib) - min(I_calib)
```

**임계 속성**:
- **단조성**: log는 단조증가 함수이므로 픽셀 순서 보존
- **역함수 존재**: 필요시 역로그 변환 가능
- **우회 불가**: 로그 변환은 필수 (강화 파이프라인의 기초)

### 2.4 CLAHE (Stage 6) - Contrast Limited Adaptive Histogram Equalization

**알고리즘**: Pizer et al. (1987)

**처리 단계**:

1. **타일 분할**: 이미지를 M × N 타일로 분할 (기본 8×8, 구성 가능 16×128)

2. **히스토그램 계산**: 각 타일의 로컬 히스토그램 생성

3. **클립 제한**: 히스토그램 빈이 clip_limit을 초과하는 경우 초과분을 재분배
   ```
   if (hist[bin] > clip_limit):
       excess = hist[bin] - clip_limit
       redistribute(excess, neighboring_bins)
   ```

4. **누적 분포 함수 (CDF)**: 각 타일에 대해 CDF 생성

5. **쌍선형 보간**: 타일 경계에서 이웃하는 4개 타일의 CDF를 쌍선형 보간으로 혼합

**구성 매개변수**:

| 매개변수 | 범위 | 기본값 | 설명 |
|----------|------|--------|------|
| 타일 크기 | 16~128 | 64 | 적응형 영역 크기 (픽셀) |
| 클립 한계 | 0.01~0.1 | 0.03 | 히스토그램 peak 제한 (정규화) |
| 보간 모드 | bilinear, cubic | bilinear | 타일 경계 보간 방식 |

**해부학 인식**:
```json
{
  "exam_presets": {
    "chest": {"clip_limit": 0.02, "tile_size": 64},
    "skeletal": {"clip_limit": 0.04, "tile_size": 48},
    "abdomen": {"clip_limit": 0.03, "tile_size": 64},
    "pediatric": {"clip_limit": 0.01, "tile_size": 32}
  }
}
```

### 2.5 Window/Level (Stage 7) - VOI LUT 매핑

**목적**: 임상 해석을 위해 관심 조직의 명도 대비를 최적화

**선형 윈도우 공식**:
```
I_windowed(x,y) = clip((I_log(x,y) - (WC - WW/2)) / WW, 0, 1)

여기서:
  WC (Window Center) = 관심 조직 중심
  WW (Window Width) = 명도 범위
  clip() = [0, 1] 범위로 자르기
```

**비선형 옵션** (시그모이드):
```
I_windowed(x,y) = 1 / (1 + exp(-(I_log - WC) / WW))
```

**DICOM PS3.4 VOI LUT 호환성**:
- 선형 VOI LUT: DICOM SOP Class에서 정의한 윈도우 프리셋 직접 지원
- LUT 참조: DICOM Modality LUT Sequence 준수

**표준 검사별 윈도우 프리셋**:

| 검사 | 해부학 | WC | WW | 용도 |
|------|--------|-----|-----|------|
| **흉부** | 폐 | -400 | 1500 | 폐 결절 감지 |
| **흉부** | 종격동 | 40 | 400 | 종격동 윤곽 |
| **흉부** | 뼈 | 500 | 2000 | 늑골, 척추 |
| **골격** | 뼈 | 300 | 1500 | 골다공증, 골절 |
| **복부** | 간 | 60 | 150 | 간 병변 |
| **복부** | 신장 | 40 | 350 | 신장 실질 |
| **복부** | 뼈 | 400 | 2000 | 척추, 골반 |
| **투시** | 통상 | 100 | 500 | 실시간 관찰 |

## 4. 데이터 도메인 규칙 (임계)

```
3개 도메인 분리 명령:

1. 검출기 도메인
   ├─ 내용: 원시 또는 검출기 보정 프레임
   ├─ 소유자: xpe_preprocess.dll → SWU-2.0 (EI만 계산)
   ├─ 계산: EI/DI, 래그 잔여, QC 메트릭
   └─ 하한: Stage 5 시작 전

2. 강화 도메인
   ├─ 내용: 로그 변환 후 프레임
   ├─ 소유자: xpe_enhance_basic.dll (Stage 5~7)
   ├─ 계산: CLAHE 파라미터, 윈도우/레벨
   └─ 상한: 프리젠테이션 LUT 적용 전

3. 프리젠테이션 도메인
   ├─ 내용: GSDF/LUT 적용 프레임
   ├─ 소유자: gsvg.dll
   ├─ 계산: 디스플레이 선형 렌더링
   └─ 출력: 최종 표시용
```

**위반 시 결과**: 
- 검출기 도메인 데이터에 CLAHE 적용 → EI 과다 추정 (위험!)
- 강화 도메인 에서 QC 메트릭 계산 → 부정확한 DQE/MTF
- 프리젠테이션 후 윈도우 적용 → 기술적 진단 오류

## 8. 테스트 기준

### 8.1 Log Transform 검증

| 케이스 | 입력 | 기대 | 검증 방법 |
|--------|------|------|----------|
| 정상 범위 | 1-4095 ADU → float32 | log(x) ± 0.01% | 수치 정확도 |
| ε 바닥 | 0 ADU | log(ε) (오류 아님) | 예외 처리 |
| 단조성 | I1 < I2 | log(I1) < log(I2) | 100개 무작위 픽셀 |
| 동적 범위 | min/max 값 | 적절한 로그 범위 | 히스토그램 시각화 |

### 8.2 CLAHE 검증

| 케이스 | 입력 | 기대 | 검증 방법 |
|--------|------|------|----------|
| 균일 필드 | 평면 배경 | 인공 구조 없음 | 표준 편차 < 5% |
| 스텝 에지 | 단계 팬텀 | 타일 경계 seam 없음 | 시각적 검사 |
| 저선량 배경 | 노이즈 배경 | 노이즈 증폭 <= 3σ | SNR 계산 |
| 클립 한계 범위 | 0.01~0.1 | 점진적 강화 | 주관적 스케일 |

### 8.3 EI/DI 검증

| 케이스 | 입력 | 기대 | 검증 방법 |
|--------|------|------|----------|
| 알려진 노출 | K_gain × Q_mean = EI_T | DI = 0 | 계산 일치 |
| 과다 노출 | EI > EI_T | DI > 0 | 로그 정확도 |
| 저선량 | EI < EI_T | DI < 0 | 로그 정확도 |
| 스티치 억제 | 스티치 플래그 설정 | EI 계산 건너뜀 | 우회 로직 |
