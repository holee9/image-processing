## 1. 개요

### 1.1 목적

본 문서는 Flat Panel X-ray Detector(FPD) 제조 환경에서 Noise 평가를 포함한 성능 측정 전반을 체계적으로 관리하기 위한 종합적인 품질 관리 방안을 제시한다. 구체적으로는 다음 목적을 달성하기 위해 작성되었다:

1. **회사 자체 정량적 FPD 평가 체계 구축**: 국제표준(IEC 62220-1-1:2015, AAPM TG-150)에 기반한 내부 품질 평가 시스템을 수립하여, 외부 의존도를 최소화하고 자체 검증 역량을 확보한다.

2. **지속적 품질 관리 체계 운영**: 양산 라인에서 측정된 DQE(Detective Quantum Efficiency), NPS(Noise Power Spectrum), MTF(Modulation Transfer Function) 등 핵심 성능 지표를 SPC(Statistical Process Control) 방법론으로 실시간 모니터링하여 공정 이상을 조기에 감지한다.

3. **규제 요구사항 충족**: FDA 510(k)/PMA, CE 마킹(MDR 2017/745), MFDS 의료기기 GMP 등 글로벌 규제 요구사항을 충족하는 문서화된 품질 시스템을 구축한다.

4. **지속적 개선(PDCA)**: 정기적인 관리 검토(Management Review), 내부 감사(Internal Audit), CAPA 시스템을 통해 품질 성능을 지속적으로 개선한다.

### 1.2 적용 범위

본 관리 방안은 다음 범위에 적용된다:

| 구분 | 세부 내용 |
|------|----------|
| **제품 범위** | 일반 방사선 촬영용 FPD (Radiographic FPD), 동영상용 FPD (Fluoroscopic/Dynamic FPD), 유방 촬영용 FPD (Mammographic FPD) |
| **공정 범위** | 양산 라인 수락 검사(Incoming Inspection), 공정 내 검사(In-Process Inspection), 최종 검사(Final Inspection), 출하 검사(Outgoing QC) |
| **측정 항목** | Dark Noise, Flat-field 균일성, NPS/NNPS, DQE, MTF, Defective Pixel, Lag/Ghosting, Dynamic Range, Linearity |
| **지역 범위** | 국내 생산 시설 전체; 협력사 및 위탁 생산(CMO) 시설 (별도 계약 기반) |

### 1.3 용어 정의

| 용어 | 정의 |
|------|------|
| FPD | Flat Panel X-ray Detector. 평판형 디지털 X선 검출기 |

| NEQ | Noise Equivalent Quanta. 유효 잡음 등가 양자 수 |
| SPC | Statistical Process Control. 통계적 공정 관리 |
| CAPA | Corrective Action and Preventive Action. 시정 및 예방 조치 |
| DHF | Design History File. 설계 이력 파일 |
| ALCOA+ | Attributable, Legible, Contemporaneous, Original, Accurate + Complete, Consistent, Enduring, Available. 데이터 무결성 원칙 |
| RQA 5 | Radiation Quality A, Level 5. 70 kV, 21 mm Al 필터, HVL 6.8 mm Al (IEC 61267 기준 표준 시험 조건) |

#### 3.1.4 측정 불확도 관리

IEC 62220-1-1:2015에 따른 핵심 측정 불확도 요소:

| 불확도 원인 | 유형 | 관리 방법 |
|-----------|------|---------|
| Air Kerma 측정기 교정 불확도 | Type B | 교정 성적서의 k=2 확장 불확도 사용, <5% 유지 |
| HVL 측정 불확도 | Type B | ±2% 이내 유지 (IEC 61267 요구사항) |
| 방사선 출력 재현성 | Type A | 5회 이상 반복 측정 후 표준오차 산출 |
| SID 설정 불확도 | Type B | 레이저 거리계 ±1 mm; SID ≥1.5 m에서 영향 <0.1% |
| 조사야 정렬 불확도 | Type B | 정렬 지그 사용, ±1 mm 이내 |
| NPS 통계 불확도 | Type A | 최소 4백만 독립 픽셀(IEC 요구사항), ROI 수 증가로 감소 |
| 합성 측정 불확도 (DQE) | 합성 | 개별 불확도 성분 제곱합의 제곱근(RSS 방법), 목표 k=2 <10% |

## 4. 데이터 관리 체계

### 4.1 측정 데이터 수집

#### 4.1.1 자동 vs 수동 데이터 수집 비교

| 항목 | 자동 수집 | 수동 수집 |
|------|---------|---------|
| **적용 항목** | Flat-field, Dark Noise, NPS, DQE (자동화 시스템 연동) | 환경 조건, 장비 상태, 시각적 검사 항목 |
| **장점** | 인적 오류 최소화, 빠른 처리 속도, 실시간 SPC 연동 | 장비 투자 불필요, 비정형 항목 기록 가능 |
| **단점** | 초기 구축 비용, 소프트웨어 유지 관리 필요 | 인적 오류 위험, 처리 지연 가능 |
| **권장 단계** | Phase 2 이후 점진적 자동화 | Phase 1에서 즉시 시작 |

**자동화 우선순위** (ROI 기준):
1. 순위 1: Dark Noise 측정 자동화 (단순 통계, 빠른 ROI)
2. 순위 2: Flat-field 균일성 자동화 (반복 측정 빈도 높음)
3. 순위 3: Defective Pixel 검출 자동화 (알고리즘 표준화 용이)
4. 순위 4: NPS/DQE 계산 자동화 (알고리즘 복잡, 검증 필요)

#### 4.1.2 데이터 형식 표준화

| 데이터 유형 | 권장 형식 | 이유 |
|-----------|---------|------|
| 원시 이미지 데이터 | DICOM (IHE DR Profile 준수) | 의료기기 산업 표준, 메타데이터 포함 |
| 측정 결과 수치 데이터 | CSV (UTF-8, 헤더 포함) | 범용 호환성, 스프레드시트 및 Python 직접 처리 |
| 대용량 다차원 데이터 (NPS 2D 스펙트럼) | HDF5 | 고속 I/O, 계층 구조, Python h5py 지원 |

#### 5.1.1 FPD 측정 항목별 관리도 선택

| 측정 항목 | 관리도 유형 | 이유 |
|---------|-----------|------|
| DQE(0), DQE(1 lp/mm), DQE(Nyquist/2) | X̄-R 또는 I-MR | 연속 데이터, 소량 샘플 |

| Lag/Ghosting 비율 | I-MR | 개별 측정값 |

#### 5.1.2 X̄-R 관리도 설계 (예: DQE(0) 관리도)

**초기 관리 한계 설정 절차**:
1. 측정 시스템 분석(MSA/Gage R&R) 실시하여 측정 시스템 능력 확인
2. 초기 데이터 수집: 안정적 공정에서 25개 이상의 소그룹 (n=2~5) 측정
3. 관리 한계 계산:

```
X̄ 관리도:
  UCL_X̄ = X̿ + A₂ × R̄
  CL_X̄  = X̿
  LCL_X̄ = X̿ - A₂ × R̄

R 관리도:
  UCL_R  = D₄ × R̄
  CL_R   = R̄
  LCL_R  = D₃ × R̄  (n < 7이면 LCL_R = 0)

A₂, D₃, D₄: 소그룹 크기 n에 따른 관리도 계수
  n=2: A₂=1.880, D₃=0, D₄=3.267
  n=3: A₂=1.023, D₃=0, D₄=2.574
  n=4: A₂=0.729, D₃=0, D₄=2.282
  n=5: A₂=0.577, D₃=0, D₄=2.114
```

4. 관리 이탈 점 조사 및 원인 제거 후 관리 한계 재계산
5. 공정 안정성 확인 후 관리도 가동

**I-MR 관리도 (개별값-이동범위)**:

```
I 관리도:
  UCL_I = X̄ + 3 × (MR̄/d₂)  [d₂ = 1.128 for n=2]
  CL_I  = X̄
  LCL_I = X̄ - 3 × (MR̄/d₂)

MR 관리도:
  UCL_MR = D₄ × MR̄  [D₄ = 3.267 for n=2]
  CL_MR  = MR̄
  LCL_MR = 0
```

### 5.2 공정 능력 분석

#### 5.2.1 공정 능력 지수 (Cp, Cpk)

**기본 공식**:

```
Cp  = (USL - LSL) / (6σ)
         ─────────────────────────────────────────
         = (스펙 폭) / (공정 변동의 6배)

Cpk = min[(USL - X̄)/3σ, (X̄ - LSL)/3σ]
         ─────────────────────────────────────────
         = 실제 공정 중심을 고려한 공정 능력

여기서:
  USL: Upper Specification Limit (스펙 상한)
  LSL: Lower Specification Limit (스펙 하한)
  σ: 공정 표준편차 (장기 σ_total 또는 단기 σ_within)
  X̄: 공정 평균

* 단기 능력: Cp, Cpk (σ_within 사용)
* 장기 능력: Pp, Ppk (σ_total 사용)
```

**목표 공정 능력**:

| 제품 구분 | 목표 Cpk | 경고 수준 | 조치 수준 |
|---------|---------|---------|---------|
| 일반 규격 항목 | ≥ 1.33 (4σ 수준) | 1.00~1.33 | < 1.00 |
| 안전 관련 규격 항목 | ≥ 1.67 (5σ 수준) | 1.33~1.67 | < 1.33 |
| 신제품 초기 수율 개선 중 | ≥ 1.00 (단기 목표) | 0.67~1.00 | < 0.67 |

## 6. 품질 지표 (KPI) 관리

### 6.1 공정 품질 KPI

#### 6.1.1 First Pass Yield (FPY)

```
FPY = (재검사/재작업 없이 최초 검사 합격 수량) / (전체 검사 수량) × 100%

Rolled Throughput Yield (RTY):
  RTY = FPY_1 × FPY_2 × ... × FPY_n  (다단계 검사 시)
  
예: FPY_Dark(0.98) × FPY_Flatfield(0.97) × FPY_NPS(0.96) × FPY_Defect(0.99) = 0.903 (90.3%)
```

| FPY KPI | 목표 | 경고 | 조치 |
|--------|------|------|------|
| 전체 FPY | ≥ 95% | 90~95% | < 90% |
| 최종 검사 FPY | ≥ 98% | 95~98% | < 95% |
| 재검사 후 합격률 | ≥ 99.5% | 99~99.5% | < 99% |

#### 6.1.2 Defect Rate by Category (불량 항목별 불량률)

**불량 분류 체계 (Defect Classification)**:

| Defect Category | 정의 | 측정 방법 |
|----------------|------|---------|
| Cat. 1: Dark Noise 불량 | 암전류 잡음이 스펙 초과 | Dark image σ > 스펙 상한 |
| Cat. 2: Flat-field 균일성 불량 | 신호 균일성 또는 SNR 스펙 미달 | NU_S,global > 스펙 상한 |
| Cat. 3: DQE 불량 | DQE가 스펙 하한 미달 | DQE(f) < 스펙 하한 |
| Cat. 4: Defective Pixel 과다 | 결함 화소 비율 스펙 초과 | 결함 화소 수 / 전체 화소 수 > 스펙 |
| Cat. 5: Lag/Ghosting 불량 | 잔상 비율 스펙 초과 | Lag Frame2 > 스펙 상한 |
| Cat. 6: MTF 불량 | 공간 해상도 스펙 미달 | MTF(Nyquist/2) < 스펙 하한 |
| Cat. 7: 복합 불량 | 2가지 이상 카테고리 동시 불량 | - |

#### 6.1.3 Noise 스펙 마진 추이

**스펙 마진(Spec Margin) 정의**:

```
상한 스펙 항목 (예: Dark Noise σ):
  마진(%) = (USL - X̄) / (USL - LSL) × 100
  또는: 마진(σ 단위) = (USL - X̄) / σ_process

하한 스펙 항목 (예: DQE(0)):
  마진(%) = (X̄ - LSL) / (USL - LSL) × 100
  또는: 마진(σ 단위) = (X̄ - LSL) / σ_process
```

**월간 추이 관리 목표**:
- 스펙 마진이 3개월 연속 감소하지 않을 것
- 최소 스펙 마진 ≥ 20% (스펙 폭 기준)
