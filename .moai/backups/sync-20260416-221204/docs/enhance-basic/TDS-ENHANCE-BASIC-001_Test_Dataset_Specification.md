## 1. 목적

알고리즘별 테스트 입력 데이터 사양입니다. 합성 데이터 + 실제 데이터 + Golden Reference로 구성합니다.

---

## 2. Log Transform 검증 (SWU-2.1)

### 2.1 테스트 케이스

| TC ID | 입력 | 기대 | Golden Hash (SHA-256) |
|-------|------|------|----------------------|
| **TST-LOG-001** | 균일 필드 (255 ADU) | log(255 + ε) = 5.547... | `a3f2c...` |
| **TST-LOG-002** | 0 ADU (ε 바닥) | log(ε) ≠ -∞ | `b5d1e...` |
| **TST-LOG-003** | 단조성: [0, 100, 200, 400] | log(x1) < log(x2) | `c7a9b...` |
| **TST-LOG-004** | 동적 범위 (min/max) | 로그 범위 적절 | `d2f3k...` |

### 2.2 합격 기준

- 수치 오차 < 0.01%
- Golden Hash 일치
- 범위 오버플로우 없음

---

## 3. CLAHE 검증 (SWU-2.2)

### 3.1 테스트 입력

| 팬텀 | 파라미터 | 기대 | Golden Hash |
|------|---------|------|-------------|
| 균일 필드 | clip_limit=0.03, tile=64 | 인공 구조 없음 | `e4g6j...` |
| 스텝 에지 | 동일 | seam 아티팩트 없음 | `f1h8m...` |
| 저선량 배경 | 동일 | 노이즈 증폭 <= 3σ | `g2i9p...` |

### 3.2 정량적 기준

| 메트릭 | 목표 | 측정 방법 |
|--------|------|----------|
| 균일 필드 σ | < 5% | ROI 표준 편차 |
| Seam 가시성 | 0 | 시각적 검사 |
| CNR 증폭 | >= 20% | 팬텀 ROI SNR |

---

## 4. EI/DI 검증 (SWU-2.0)

### 4.1 테스트 케이스

| TC ID | 입력 | K_gain | Q_mean | EI_T | 기대 DI | Golden |
|-------|------|--------|---------|-------|---------|--------|
| **TST-EI-001** | 표준 노출 | 0.1 | 1000 | 100 | 0.0 | `h3j5x...` |
| **TST-EI-002** | 과다 | 0.1 | 2000 | 100 | +3.01 | `i4k7z...` |
| **TST-EI-003** | 저선량 | 0.1 | 500 | 100 | -3.01 | `j5l8a...` |
| **TST-EI-004** | 스티치 억제 | (계산 건너뜀) | - | - | (우회) | `k6m9b...` |

### 4.2 정확도 기준

- EI 계산: ± 2%
- DI 계산: ± 0.1
- 우회 로직: 100% 정확도

---

## 5. Window/Level 검증 (SWU-2.3)

### 5.1 테스트 케이스

| Mode | WC | WW | 입력 범위 | 기대 출력 | Golden |
|------|-----|-----|----------|----------|--------|
| 선형 | 0.5 | 0.2 | [0, 1] | [0, 1] | `l7n1c...` |
| 비선형 | 0.5 | 0.2 | [0, 1] | sigmoid | `m8o2d...` |

### 5.2 정확도 기준

- 선형: 수치 오류 < 0.01%
- 비선형: sigmoid 정확도 < 1%
- DICOM 호환성: VOI LUT 준수 확인

---

## 6. Golden Reference 관리

### 6.1 생성 및 잠금

```
단계 1: 참고 구현으로 테스트 케이스 처리
단계 2: 출력의 SHA-256 계산
단계 3: 비교 소프트웨어로 검증 (예: MATLAB)
단계 4: 파일에 잠금 (체크섬 포함)
```

### 6.2 저장소

```
tests/datasets/golden/
├── log_transform_golden.bin
├── clahe_golden.bin
├── ei_di_golden.json
└── window_golden.bin
```
