## 1. 문서 정보 및 범위

### 1.1 개요

이 문서는 X-ray Flat Panel Detector (FPD) **래그/고스팅 소프트웨어 보정** 모듈용 캘리브레이션 영상 취득 프로토콜입니다.

- **범위**: 제조 공장(Factory) 및 의료 현장(Field)에서 FSRF/RSRF 영상을 취득하는 절차
- **대상**: 캘리브레이션 엔지니어, 현장 서비스 기술자
- **용도**: 인디렉트 변환 FPD (a-Si TFT + CsI:Tl)의 전하 갇힘 시간 상수 측정

### 1.2 지원 검출기

| 검출기 유형 | 대표 모델 | 래그 특성 | 이 프로토콜 적용 |
|-----------|---------|---------|-------------|
| **a-Si TFT FPD** | Varex XRD 4343N, AUO R1717 | 높은 래그 (0.3~3%, 신호 의존) | **필수** |
| **CMOS FPD** | Vieworks VIVIX-S | 매우 낮은 래그 (<0.05%) | 선택 (필요시만) |
| **Direct FPD** | 직접 변환 (Se/CdTe) | 무시할 수 있음 | 불필요 |

### 1.3 핵심 용어

| 용어 | 정의 |
|-----|------|
| **FSRF** | Falling Step Response Function (노출 ON→OFF 감쇠) |
| **RSRF** | Rising Step Response Function (노출 OFF→ON 상승) |
| **Lag** | 노출 후 격자에 갇힌 전하의 시간 감쇠 (ms 수준) |
| **Ghost** | 이전 촬영의 잔여 신호 (frame-to-frame 누적) |
| **포화 수준** | ADC 최대값의 비율 (예: 2% = 낮은 신호, 92% = 높은 신호) |
| **프레임 레이트** | 영상 취득 주기 (30 fps = 약 33.3 ms/frame) |

## 2. 목적 및 적용

### 2.1 목적

전하 갇힘의 물리적 모수를 측정하여 소프트웨어 래그 보정 모듈의 교정 계수를 결정합니다:

1. **지수 감쇠 상수 (τ)**: 갇힌 전하의 이완 시간
2. **다중 지수 항 (bn, an)**: Tier 2 (LTI) 및 Tier 3 (NLCSC) 보정 계수
3. **노출 의존 비선형성**: 신호 수준에 따른 래그 변화

### 2.2 적용 범위

- **Factory 캘리브레이션** (제조 공장 신규 검출기)
- **Field 업데이트** (현장에서 온도 드리프트, 수명 열화 추적)
- **응급 재캘리브레이션** (불량 이미지 보고 시)

## 6. FSRF 취득 프로토콜

### 6.1 목적

**노출 ON→OFF 감쇠**: 래그 신호가 지수적으로 감쇠하는 과정을 기록하여 시간 상수 τ 계산

### 6.2 핵심 원리

```
시간축 →

X-ray ON:  ▁▁▁▁▁▁▁▁▁▁▁▁▁▁  (200 프레임, 안정된 신호)
           └─ 신호 = E_bright

X-ray OFF: (즉시 OFF)
           │
           ├─ 1프레임: 신호 급격히 감소 (1st frame residual)
           │
           ├─ 50프레임: 완만하게 감쇠
           │
           └─ 200프레임: 기준선으로 수렴

수학 모델:
  I(n) = I_dark + Σ( b_k × (1-a_k)^n )  [다중 지수]
```

### 6.3 9개 신호 수준별 FSRF 취득

**신호 수준 설정**:

| 레벨 | 포화 수준 | ADU (14-bit) | 용도 |
|-----|---------|--------|------|
| 1 | 2% | ~131 | 낮은 신호 영역 |
| 2 | 5% | ~327 | 낮은-중간 |
| 3 | 10% | ~655 | 중간-낮은 |
| 4 | 20% | ~1,310 | 중간 |
| 5 | 30% | ~1,966 | 표준 신호 |
| 6 | 50% | ~3,276 | **표준 높은 신호** |
| 7 | 70% | ~4,586 | 높은 신호 |
| 8 | 80% | ~5,242 | 매우 높은 |
| 9 | 92% | ~6,020 | 최대 범위 |

### 6.4 각 신호 수준별 FSRF 취득 절차

```
FOR each Signal_Level L in [1~9]:

    Step 1. 검출기 안정화 (Cold start)
    ├─ 이전 노출 이후 최소 20분 대기
    │  (갇힌 전하 완전 방전 확인)
    ├─ NTC 온도 기록
    └─ 온도 변화 < 0.1°C/분 확인

    Step 2. 신호 수준 설정 및 검증
    ├─ 목표 포화 수준 = L%
    ├─ mAs를 세부 조절하여 신호 수준 설정
    ├─ 테스트 프레임 1개 취득
    ├─ 평균 신호 = 목표 ADU?
    │  └─ 편차 > 5%: mAs 재조절, 테스트 재실행
    └─ 확정된 mAs 값 기록

    Step 3a. Dark Frame 수집 (기준선 확보)
    ├─ X-ray OFF 상태
    ├─ PREP time = 10초 (기본)
    ├─ N_dark = 20 프레임 연속 수집
    │  (어두운 전류 기준 패턴)
    └─ 파일명: dark_fsrf_L[level]_[percent]sat.raw

    Step 3b. FSRF Pre-exposure Phase
    ├─ X-ray ON (70 kVp, 21 mm Al)
    ├─ 확정된 mAs로 노출
    ├─ PREP time = 10초 설정
    ├─ 10초 대기 (검출기 준비)
    ├─ **N_pre = 200 프레임** 연속 수집
    │  (안정된 밝은 신호 기록)
    ├─ 프레임 간격: 정확히 30 fps (33.3 ms)
    ├─ 획득 시간: 약 6.7초
    └─ 파일명: fsrf_pre_L[level]_[percent]sat.raw

    Step 3c. FSRF Post-exposure Phase (핵심)
    ├─ X-ray **즉시 OFF** (서서히 아님)
    │  └─ OFF 지연 > 50ms: 데이터 폐기, 재촬영
    ├─ **N_post = 200 프레임** 연속 수집
    │  (감쇠하는 래그 신호 기록)
    ├─ 첫 프레임 = 1st frame residual
    ├─ 50번째 프레임 = 50th frame lag
    ├─ 프레임 간격: 정확히 30 fps (시간 계(tracking 중요))
    ├─ 획득 시간: 약 6.7초
    └─ 파일명: fsrf_post_L[level]_[percent]sat.raw

    Step 4. 메타데이터 기록
    ├─ 취득 시간 (ISO 8601)
    ├─ 신호 수준 (포화 비율 + ADU)
    ├─ mAs 값
    ├─ kVp 값 (70 고정)
    ├─ 필터 (21 mm Al 고정)
    ├─ 검출기 온도
    ├─ Dark/Pre/Post 프레임 수
    └─ Cold start 대기 시간

    Step 5. 합격 기준 확인 (Section 8 참조)
    ├─ N_pre >= 200?
    ├─ N_post >= 200?
    ├─ 신호 범위 OK?
    ├─ 1st frame lag < 0.3%?
    └─ 모두 YES → 다음 수준으로, NO → 재촬영
```

### 6.5 FSRF 취득 수량

| 항목 | 수량 |
|-----|------|
| **신호 수준** | 9개 (2~92% 포화) |
| **N_pre (On-exposure)** | 200 프레임/수준 |
| **N_post (Off-exposure)** | 200 프레임/수준 |
| **Dark 프레임** | 20 프레임/수준 |
| **소계/수준** | 200 + 200 + 20 = 420 프레임 |
| **전체 총계** | 420 × 9 = **3,780 프레임** |

### 6.6 FSRF 취득 시간 추정

- **신호 수준 1개**: (200+200+20) / 30 fps + cold start 20분 ≈ 33분
- **9 수준 전체**: ~5시간 (cold start 포함)

## 7. RSRF 취득 프로토콜

### 7.1 목적

**노출 OFF→ON 상승**: 신호 상승 과정에서 래그 영향 측정, 특히 Tier 3 (NLCSC) 노출 의존 계수 a2_n(E) 재정의

### 7.2 핵심 원리

```
시간축 →

X-ray OFF: ▁▁▁▁▁▁▁▁▁▁▁  (50 프레임, 어두운 프레임)
           └─ 신호 = I_dark

X-ray ON:  (즉시 ON)
           │
           ├─ 1~10프레임: 신호 상승
           │  (이전 노출의 래그가 신호 상승을 방해)
           │
           ├─ 50프레임: 새로운 신호 수준에 수렴
           │
           └─ 200프레임: 안정된 신호

수학 모델:
  I(n) = I_target - Σ( lag_residual × decay^n )
         [상승하는 신호에서 래그가 감소분 역할]
```

### 7.3 9개 신호 수준별 RSRF 취득

**신호 수준**: FSRF와 동일 (2~92% 포화)

### 7.4 각 신호 수준별 RSRF 취득 절차

```
FOR each Signal_Level L in [1~9]:

    Step 1. 검출기 안정화 (Cold start)
    ├─ FSRF 측정 이후 최소 20분 대기
    │  (이전 FSRF의 래그 완전 방전)
    ├─ NTC 온도 기록
    └─ 온도 변화 < 0.1°C/분 확인

    Step 2. 신호 수준 설정
    ├─ FSRF와 동일한 mAs로 설정
    │  (신호 선형성 확인)
    └─ 테스트 프레임 1개로 검증

    Step 3a. Dark Frame 수집
    ├─ X-ray OFF
    ├─ PREP time = 10초
    ├─ N_dark = 20 프레임
    └─ 파일명: dark_rsrf_L[level]_[percent]sat.raw

    Step 3b. RSRF Pre-exposure Phase (어두운 상태)
    ├─ X-ray OFF 상태 유지
    ├─ **N_pre = 50 프레임** 수집
    │  (어두운 기준선)
    ├─ 프레임 간격: 정확히 30 fps
    ├─ 획득 시간: 약 1.7초
    └─ 파일명: rsrf_pre_L[level]_[percent]sat.raw

    Step 3c. RSRF Post-exposure Phase (핵심)
    ├─ X-ray **즉시 ON** (서서히 아님)
    │  └─ ON 지연 > 50ms: 데이터 폐기, 재촬영
    ├─ **N_post = 200 프레임** 연속 수집
    │  (상승하는 신호 + 래그 영향 기록)
    ├─ 첫 프레임 = 신호 급상승 시작
    ├─ 50번째 프레임 = 부분 도달 (래그 영향 가시)
    ├─ 200번째 프레임 = 최종 수렴
    ├─ 프레임 간격: 정확히 30 fps
    ├─ 획득 시간: 약 6.7초
    └─ 파일명: rsrf_post_L[level]_[percent]sat.raw

    Step 4. 메타데이터 기록
    ├─ (FSRF와 동일 항목)
    ├─ RSRF 특이사항: "상승 시작 프레임", "부분 수렴 프레임"
    └─ Cold start 대기 시간

    Step 5. 합격 기준 확인
    ├─ N_pre >= 50?
    ├─ N_post >= 200?
    ├─ 신호 상승률 선형?
    └─ 모두 YES → 완료, NO → 재촬영
```

### 7.5 RSRF 취득 수량

| 항목 | 수량 |
|-----|------|
| **신호 수준** | 9개 |
| **N_pre (Off-exposure)** | 50 프레임/수준 |
| **N_post (On-exposure)** | 200 프레임/수준 |
| **Dark 프레임** | 20 프레임/수준 |
| **소계/수준** | 50 + 200 + 20 = 270 프레임 |
| **전체 총계** | 270 × 9 = **2,430 프레임** |

### 7.6 RSRF 취득 시간 추정

- **신호 수준 1개**: (50+200+20) / 30 fps + cold start 20분 ≈ 28분
- **9 수준 전체**: ~4.5시간

## 8. 영상 품질 합격 기준

### 8.1 메타데이터 검증

**모든 취득 후 다음을 확인**:

| 기준 | 임계값 | 합격 조건 |
|-----|--------|---------|
| **N_pre (FSRF)** | ≥ 200 | = 200 |
| **N_post (FSRF)** | ≥ 200 | = 200 |
| **N_pre (RSRF)** | ≥ 50 | ≥ 50 |
| **N_post (RSRF)** | ≥ 200 | = 200 |
| **Dark 프레임** | ≥ 20 | = 20 |
| **온도 안정도** | ±0.5°C | ΔT < 0.5°C |
| **Cold start** | ≥ 20분 | 기록됨 |

### 8.2 신호 수준 검증 (FSRF N_pre)

| 기준 | 임계값 | 불합격 조건 |
|-----|--------|----------|
| **평균 신호** | 목표 ±5% | 편차 > 5% |
| **신호 표준편차** | σ < 2% μ | σ > 2% μ |
| **포화 픽셀** | < 1% | > 1% |
| **완전 어둠 픽셀** | 0 | > 0 |

### 8.3 래그 감쇠 패턴 검증 (FSRF N_post)

**래그 곡선이 지수 감쇠를 따르는지 확인**:

| 기준 | 임계값 | 합격/불합격 |
|-----|--------|----------|
| **1st frame lag (1사감율)** | < 0.3% | > 0.3%: **불합격** |
| **50th frame lag** | < 0.01% | > 0.01%: **불합격** |
| **지수 피팅 R²** | > 0.98 | < 0.98: **불합격** |
| **감쇠 시간 상수 τ** | 30~500 ms | 범위 밖: **재검토** |

### 8.4 신호 상승 패턴 검증 (RSRF N_post)

| 기준 | 임계값 | 합격/불합격 |
|-----|--------|----------|
| **상승 시간** | 5~20 프레임 | 범위 밖: **불합격** |
| **상승률 선형성** | 선형적 증가 | 비선형/불규칙: **불합격** |
| **최종 신호 수렴** | 목표 ±3% | 편차 > 3%: **불합격** |

### 8.5 영상 품질 체크리스트

```
메타데이터
[ ] 프레임 수: 요구값 ✓
[ ] 온도: ±0.5°C ✓
[ ] Cold start: ≥20분 ✓
[ ] mAs, kVp: 기록됨 ✓

FSRF 신호 (N_pre)
[ ] 평균 신호: 목표 ±5% ✓
[ ] 노이즈: σ < 2% μ ✓
[ ] 포화: < 1% ✓

FSRF 감쇠 (N_post)
[ ] 1st frame: < 0.3% ✓
[ ] 50th frame: < 0.01% ✓
[ ] R² 지수: > 0.98 ✓

RSRF 상승 (N_post)
[ ] 상승 시간: 5~20프레임 ✓
[ ] 선형성: 양호 ✓
[ ] 최종 수렴: 목표 ±3% ✓
```

**모두 ✓ = 합격** → 다음 수준  
**하나라도 ✗ = 불합격** → Section 9 (재촬영)

## 9. 취득 실패 판정 및 재촬영

### 9.1 실패 원인 분류

| 원인 | 증상 | 즉시 조치 |
|-----|------|--------|
| **온도 불안정** | ΔT > 0.5°C | 30분 대기 후 재촬영 |
| **Cold start 부족** | 래그 불일치 | 20분 이상 대기 후 재촬영 |
| **X-ray 불안정** | 신호 편차 > 3% | 튜브 재워밍업 |
| **프레임 누락** | N < 요구값 | 레이트 확인 후 재촬영 |
| **포화 픽셀 초과** | > 1% 포화 | 신호 수준 ↓ (mAs 감소) |
| **래그 곡선 이상** | R² < 0.98 | 환경 확인 후 재촬영 |

### 9.2 신호 조정 가이드

**FSRF N_pre 신호가 목표를 벗어난 경우**:

| 현재 신호 | 조치 | 재촬영 |
|----------|------|------|
| 목표의 70% 이하 | mAs를 50% 증가 | 신호 재확인 후 |
| 목표의 95~105% | OK, 계속 진행 | - |
| 목표의 130% 이상 | mAs를 30% 감소 | 신호 재확인 후 |

### 9.3 반복 실패 (3회 이상) 대응

**조건**: 동일 신호 수준에서 3회 실패

**대응**:
```
1. 캘리브레이션 중단
2. 원인 분석:
   - 검출기 온도 센서 정상?
   - X-ray 발생기 안정?
   - 팬텀 및 기구 손상?
3. 관리자 보고
4. 검출기 교체 검토
```
