# QA-A-254 — 결함 맵 형식 확장 (FUNC-039 형식) (이 카드만)

## 왜
보정 단계가 라인 방향을 알려면 결함 맵에 라인 기록이 있어야 한다. 앱이 읽는 파일이므로 기존 FUNC-003 화소 코드와 호환해야 한다.

## 할 일
1. `defect.xcal` 형식 확장안: 화소 코드(FUNC-003 호환) + 라인 기록(방향, 번호, 시작·끝, 종류, 보정 방법) + 덩어리 표시. 기존 판 파일도 그대로 읽힐 것.
2. 작성기·읽기기·검증기 갱신, 생성 도구(`xpe_calib_fixture_gen`)와 manifest 반영.
3. 형식 문서를 SAD 3.3 갱신 초안(.txt)으로 리더에게 제출(문서는 리더 소유).
4. 구버전 파일·신버전 파일·손상 파일 적재 시험.

## 실행 범위
