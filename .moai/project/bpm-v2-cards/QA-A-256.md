# QA-A-256 — 1판/2판 비교 판정 (B16) (이 카드만)

## 왜
B16 판정. 합격 수치는 QA-A-251 의 1판 기준값을 본 뒤, 2판 결과 전에 리더가 고정한다.

## 할 일
1. QA-A-251 평가 도구로 1판과 2판을 같은 입력·같은 시드로 잰다.
2. 지표: 종류·진폭별 검출률, 오경보, 대조군 오검출, 절반 분할 일치도, 보정 오차, D_n, 처리 시간.
3. 장비 회사 맵과의 차이는 특성별로 나눠 원인 진단만 한다(판정에 쓰지 않음).

## 실행 범위
해당 단위 시험 + QA-A-251 평가 도구 1회. 한 번에 하나, 종료 뒤 남은 프로세스 0. 전체 스위트는 CI 몫.
