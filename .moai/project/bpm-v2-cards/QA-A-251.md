# QA-A-251 — 결함 화소 맵 평가 도구 + 1판 기준값 (이 카드만)

## 왜
정답 결함 맵이 없다(AAPM TG-150 §4.3.8). 1판과 2판을 비교하려면 위치를 아는 결함으로 검출률·오경보·보정 품질을 재는 도구가 먼저 있어야 한다. 이 도구의 1판 결과가 B16 합격 수치의 기준이 된다.

## 할 일
1. **결함 주입기.** 원시 프레임(다크·평탄, offset 보정 전)에 위치를 아는 결함을 심는다. 생성 입력 프레임 전체에 같은 위치로 심고, 정답 목록을 파일로 남긴다.
   - 화소: dead(신호 0 근처), hot(다크 수준 상승), 잡음 이상(프레임마다 흔들림), 선량 응답 이상(기울기·직선성)
   - 라인: 행·열 전체, 일부 구간, 인접 두 줄, 교차
   - 덩어리: 2×2 이상
   - 대조군: 결함이 아닌 띠 무늬(offset·gain 으로 사라지는 행·열 성분). 결함으로 표시되면 오검출
   - 심는 화소는 1판·장비 회사 맵 어느 쪽에도 결함이 아닌 화소에서 고른다. 진폭은 여러 단계로 둔다.
2. **채점기.** 검출률(종류·진폭별), 오경보 수, 대조군 오검출 수, 프레임 절반 분할 일치도(Jaccard), 보정 오차(국소 잡음 대비), 보정 후 라인 지표 D_n(TG-150 §4.3.9).
3. **1판 기준값.** 현재 `xpe_bpm_generate`(1판)와 현재 보정으로 위 지표를 잰다. 입력: cyan_test, 다크 `Dark_08~14`(첫 장 제외), 밝은 영상 17~36 중 생성 입력.

## 순서
주입 사양(종류·진폭·개수·시드)과 채점 정의를 먼저 커밋 → 1판 측정 → 결과 커밋.

## 실행 범위
주입기·채점기 단위 시험 + 1판 측정 1회. 한 번에 하나, 종료 뒤 남은 프로세스 0. 전체 스위트 안 돌림.
