# QA-A-252 — 화소 결함 검출 2판 (FUNC-022) (이 카드만)

## 왜
1판은 고정 λ=8(다크)과 ±7 %(오프셋을 빼지 않은 평탄 영상) 두 검사뿐이다. SRS v1.4 FUNC-022 는 특성별 합집합 검출과 데이터로 정한 임계값을 요구한다(근거: PMC9721322, EMVA 1288 §4.4).

## 할 일
1. 첫 다크 제외. 다크 평균의 국소 편차(중앙값·MAD).
2. 다크 시간 잡음: 프레임별 전체·행 성분을 뺀 뒤 화소별 표준편차, 국소 대비 비율.
3. 선량 응답: 평탄 영상에서 다크를 빼고, 선량 단계별 화소 평균으로 화소별 기울기와 직선성 잔차(cyan_test 5단계).
4. 평탄 편차: 다크를 빼고 저주파 음영을 제거한 뒤 국소 편차.
5. 각 특성 임계값은 목표 오경보 수에서 정하고 manifest 에 값과 근거 기록. 결과는 특성별 합집합.
6. 행·열 성분은 국소 통계 전에 빼서 라인이 화소 결함으로 번지지 않게 한다(라인 자체는 QA-A-253).
