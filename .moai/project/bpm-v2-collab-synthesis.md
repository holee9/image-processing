## 1. 확인된 사실

| # | 사실 | 출처 |
|---|---|---|
| F1 | 결함의 공통 정량 기준은 없다. EMVA 1288 은 "응용별 기준"을 요구한다(§4.4, p.15). TG-150 은 줄 잡음의 임상 허용 한계가 없다고 적는다(§4.3.9, p.82). FDA 지침은 허용 결함의 종류·수량과 보상 방법을 **제출하라**고만 한다(VI.C 항목 10, p.8, 2020 보관본) | Codex·gui·doc 원문 열람 |
| F2 | 공개된 정량 기준은 PerkinElmer 매뉴얼 두 판뿐이다. 오프셋만 보정한 밝은 영상에서 중앙값의 150 % 초과, 45 % 미만이면 결함이다. 2005 판은 20~45 % 를 "보정 곤란"으로 따로 둔다. ASTM E2597 의 0.6·1.3 은 미검증이다 | post 원문 열람 |
| F3 | 기준은 두 층으로 존재한다. 감도(응답) 결함은 오프셋만 보정한 영상에서, 균일도·결함 줄은 게인 보정 후 영상에서 판정한다 | post (PerkinElmer, Hamamatsu) |
| F4 | 같은 낮은 응답이라도 원인이 변환 이득(K) 저하인지 검출 효율(η) 저하인지에 따라 보정 후 잡음 증가가 다르다(EMVA §6.6, R = Kη). 효율 저하면 잡음이 늘고, 이득 저하면 이상적 보정 뒤 원래 잡음으로 돌아간다. **응답 비율만으로 잡음 비용을 정할 수 없다** | Codex·gui |
| F5 | 지금 주입기는 응답 결함을 신호·잡음에 함께 곱한다. 그래서 응답 0.5 줄은 보정 뒤 잡음 비용이 0 dB 이고, "잡음 3 dB 초과 결함"이라는 정답 표시는 이 주입으로 정당화되지 않는다. PerkinElmer 기준으로도 0.5 는 정상이다 | gui, 리더 코드 확인 |
| F6 | 광자 전달 곡선: 표본 분산 중앙값의 프레임 수 편향(2·3·8장)을 보정하면 분산/평균이 0.340~0.352 로 거의 일정하다. pre 의 "0.16~0.32 로 고르지 않다"는 이 편향 때문이었다. 양자 몫 96~99.7 % 는 절편을 18.5 로 둔 값이다. 절편 142 면 저선량(3,053)에서 83.5 % 다 | Codex(조건부 계산), 리더 산술 |
| F7 | x 1830~2020(핵심 1872~1938, 1964~1998): 다크에서만 보이는 판독 쪽 공통 모드 잡음이다. 프레임마다 움직이고 고정 성분이 없다. 판독 칩 경계(256 배수)와 맞지 않는다. 밝은 영상(선량 3천~3만)에서는 이웃과 같다(1 %) | pre RES-01b·01c, gui |
| F8 | "원시 1.3~1.9배"(QA-A-253)와 "특별하지 않다"(RES-01)는 서로 다른 통계량이다. 공통 성분을 빼기 전 비는 1.05~1.22, 뺀 뒤는 2.16~2.27 이다. 모순이 아니다 | Codex, pre RES-01b |
| F9 | 움직이는 줄 잡음은 결함 맵이 아니라 실행 중 행 보정 대상이다. 보정 데이터에 섞이면 보정 후 "변하지 않는 줄 아티팩트"가 새로 생긴다 | gui (TG-150 §4.3.9 p.80, Toshiba US6819740 등 특허 4건) |

## 2. 개선안 (리더 제안)

| # | 개선 | 근거 | 결정 |
|---|---|---|---|
| P1 | **응답 결함(1층):** 오프셋만 보정한 밝은 영상에서 화소 응답이 국소 중앙값의 **45 % 미만 또는 150 % 초과**면 결함이다. 45~70 % 는 "약한 응답"으로 진단 표시만 하고 결함은 아니다 | F2(유일한 공개 정량 기준), F3 | **사용자 승인 필요**(잠정 수치 채택) |
| P2 | **잡음 비용 결함(2층):** 게인 보정 후, 같은 선량 프레임들에서 **실측한** 화소 시간 분산이 국소 기대의 2배(3.01 dB) 이상이면 결함이다. 응답 비율로 잡음을 추정하지 않는다. 자유도를 반영한 통계로 판정한다 | F4, F6 | 리더 결정. 2배는 잠정 공학 기준으로 표시하고, 현재 데이터에서는 8장 묶음(9.3k)에만 적용 |
| P3 | **줄 잡음:** 다크에서만 보이는 움직이는 공통 모드 잡음은 결함 맵에 넣지 않는다. 줄 판정의 잡음 비교는 다크 분산이 아니라 촬영 선량의 전체 분산으로 한다. x 1830~2020 은 "패널 특성(판독 쪽 공통 모드 잡음)"으로 기록하고 공급사 문의 항목에 넣는다 | F7, F8, F9 | 리더 결정 |
| P4 | **평가 주입기 수정:** 응답 결함을 두 생성 모델로 나눈다. 효율 저하는 광자 수를 줄여 잡음을 물리적으로 늘리고, 이득 저하는 지금 방식이다. 수준은 0.3·0.45·0.7 을 더한다. 지금의 "dead 0.5 줄"은 P1 기준으로 정상(보정 가능)이므로 정답 표시를 바꾼다 | F5, gui 제안 | **사용자 승인 필요**(B16 표 행 변경) |
| P5 | **통계 정정:** 분산 특성과 광자 전달 분석에서 표본 분산 중앙값의 프레임 수 편향을 보정한다. "3 dB" 와 "분산 2배" 를 하나로 통일한다(2배 = 3.01 dB) | F6 | 리더 결정 |
| P6 | **보정 맵 생성(다음 단계 offset·gain 재점검으로):** offset·gain 맵을 만들 때 움직이는 줄 잡음을 거른다 | F9 | offset·gain 재점검 단계에서 |

## 3. 남는 한계
- 한 장비, 선량 5점, 다크 7장, 촬영 1회분이다. 게인 설정·적분 시간·재가동 뒤 같은 열에서 나타나는지는 모른다.
- P1 의 45 %·150 % 는 PerkinElmer 두 판에서 온 수치다. 우리 패널에 맞는지는 추가 촬영(다른 날 반복, 선량별 8장 이상)으로 확인한다.
- 칩 배치와 패널 재질(a-Si 인지 IGZO 인지)은 사내 문서끼리 맞지 않는다. 공급사 확인이 필요하다.
