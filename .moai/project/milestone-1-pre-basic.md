## 순서

1. **전처리 기본 (이 문서)** — 실영상에서 기본 보정이 동작하고 성능 요구를 만족한다. 출력을 기준 영상으로 고정한다
2. 후처리 기본 — 1의 기준 영상을 입력으로 enhance_basic·display 검증
3. 운영자 앱 사용자 흐름 E2E — 통과 조건을 먼저 정하고 실행으로 평가
4. DICOM — 마지막

## 체크리스트 — 각 항목은 실행해서 판정한다

판정은 셋 중 하나: **통과**(명령과 출력 인용) / **실패**(무엇이 기준과 다른가) / **미구현·기준 없음**(기준 문구가 없으면 지어내지 않고 "기준 없음" 으로 적는다).

| # | 항목 | 기준 출처 |
|---|---|---|
| B1 | offset 맵 적재 + 치수 검증 | SRS-CALIB-FUNC-001·006 |
| B2 | gain 맵 적재 + 치수·값 범위 검증 | SRS-CALIB-FUNC-002·007·008 |
| B3 | 결함 맵 적재 + 무결성 | SRS-CALIB-FUNC-003 |
| B4 | 맵 없음·손상·만료 시 안전 동작(실행 안 함·알림) | SRS-CALIB-SAFE-001~004, FUNC-012 |
| B5 | 실영상에 offset → gain → 결함 순서로 보정이 적용됨 | PR-FUNC-002 |
| B6 | 보정 품질 — 평탄 영상 보정 후 균일도, 결함 화소 잔여 | SRS-CALIB 의 정량 기준(있는 것만 인용) |
| B7 | 프레임 처리 시간 ≤ 500 ms (3072²) | SRS-CALIB-PERF-001 |
| B8 | 최대 메모리 ≤ 200 MB, 100 프레임 누수 없음 (고스트 끈 기본 경로) | SRS-CALIB-PERF-002 |
| B9 | 맵 적재 ≤ 200 ms | SRS-CALIB-PERF-003 |
| B10 | 실영상 보정 출력을 기준 영상으로 고정(다이제스트 + 파일) | 2단계 입력 |

## 진척 보고 방식

"B1~B10 중 통과 N" 으로 보고한다. 카드는 어느 항목을 움직이는지 적는다. 어느 항목도 움직이지 않는 일은 안전 결함이 아니면 미룬다.
