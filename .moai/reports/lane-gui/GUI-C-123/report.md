# GUI-C-123 — 아무것도 안 고르고 Copy 를 눌렀을 때 (#173)

## 1. 고른 방식 — **비활성화**, 그리고 이유

세 선택지 중 **버튼 비활성화**를 골랐다.

- **상태 표시줄 한 줄**은 사후 통지다. 사용자는 **이미 눌렀고**, 그 사이 붙여넣기를 했다면 엉뚱한 것이 들어간 뒤다. 메시지는 "왜 이상한 게 붙었나" 를 나중에 설명해 줄 뿐이다.
- **"선택 없으면 마지막 줄 복사"** 는 앱이 사용자 대신 고르는 것이다. 조용한 무동작을 **조용한 오답**으로 바꾼다 — 클립보드에 뭔가 들어가므로 붙여넣기는 성공하고, 그것이 원한 줄인지는 아무도 확인하지 않는다.
- **비활성 버튼은 오해할 수가 없다.** 누를 수 없으므로 "눌렀는데 안 됐다" 라는 상태 자체가 생기지 않는다.

구현은 `RelayCommand` 의 `canExecute` 이고, `SelectedLog` 가 바뀔 때 `RaiseCanExecuteChanged()` 를 부른다. WPF 가 `IsEnabled` 를 따라간다.

## 2. 단언 — 양방향

**① 선택 없음**: 클립보드에 표시(sentinel)를 넣고 → 버튼을 **클릭한 뒤** → 표시가 그대로인지 + 버튼이 비활성인지.

```
with no selection, enabled=False
clipboard after the press: 'xpe-c123-sentinel-950dbcbe...'     ← 그대로
```

**둘 다** 단언한다. 표시가 그대로인 것만으로는 부족하다 — **복사가 고장 난 경우와 구별되지 않는다.** 비활성이라는 사실이 "누를 수 없었으므로 오해가 불가능했다" 를 더한다.

**② 선택 있음**: 여전히 복사된다(C-122 가 세운 것이 안 깨짐).

```
with a selection, enabled=True
clipboard after copying: '[12:48:18.993] Your saved settings could not be read, ... .unreadable-20260919-124818'.'
```

## 3. 반증 — 그리고 **되돌린 상태가 진짜 무동작인지 먼저 확인했다**

`canExecute` 를 떼어 항상 누를 수 있게 되돌렸다. 카드의 경고(주입한 것이 애초에 손상이 아닌 경우)를 따라, **단언 전에 눌러 보고 결과를 먼저 기록하도록 순서를 바꿨다.**

```
with no selection, enabled=True
clipboard after the press: 'xpe-c123-sentinel-6f35103f...'          ← 눌러도 클립보드 그대로
status bar after the press: 'Your saved settings could not be read, ...'   ← 상태 표시줄도 그대로
→ 실패: Copy is pressable with nothing selected, so a press does nothing while looking like it copied.
```

즉 되돌린 상태는 **실제로 사용자가 겪는 조용한 무동작**이다 — 눌렀는데 클립보드도 상태 표시줄도 변하지 않는다. 그 위에서 빨강이 떴다.

이 순서는 되돌린 뒤에도 남긴다: 실행 기록이 **증상을 먼저 적고** 그다음에 판정한다.

## 5. 미검증 (Gaps)

- **클립보드가 다른 프로세스에 점유된 경우**는 여전히 재지 않았다. 그 경로는 `CopySelectedLog` 의 `catch` 가 상태 표시줄에 사유를 적게 되어 있지만 실행하지 않았다.
- 비활성 버튼에 **왜 비활성인지 설명하는 툴팁은 넣지 않았다.** 로그 목록에서 한 줄을 고르면 켜지므로 발견 가능하다고 판단했으나, 그 판단은 사용자에게 확인하지 않았다.
- 키보드로 선택(`Tab`+화살표)했을 때도 켜지는지는 재지 않았다. 마우스 선택으로만 측정했다.
- `#198`(Alerts 표시 자리·네이티브 알림 미수신)은 **건드리지 않았다.**

## 6. 잔여 위험

- 비활성화는 **선택이 없다는 사실**만 말한다. 사용자가 "왜 못 누르지" 로 멈출 수 있다 — 발견 가능성과 오해 불가능성을 맞바꾼 결정이고, 이 카드는 후자를 골랐다.
