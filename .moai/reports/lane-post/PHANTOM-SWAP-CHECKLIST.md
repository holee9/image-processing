# 팬텀을 바꿀 때 할 일 (512² MC 도입 체크리스트)

QA-B-118 (#180). pre 레인의 512² MC 팬텀(QA-A-114)이 들어왔을 때, **무엇이 깨지고 무엇을 다시 재야 하는지**를 한곳에 모았다. 카드마다 흩어져 있던 것을 합쳤으므로, 팬텀 교체 카드는 이 파일만 보면 된다.

마지막 갱신: QA-B-118. 근거 카드: QA-B-110 §1(6), QA-B-115 §3, QA-B-116 §1(3), QA-B-117 §1(2)(3).

---

## 0. 한 줄 요약

**MC 팬텀에 묶인 시험은 하나뿐이다** — REQ-GSVG-018 의 잠정 바닥. 나머지 잠정 바닥은 전부 시험 파일 안에서 만드는 합성 장면을 쓰므로 팬텀을 바꿔도 건드릴 필요가 없다.

---

## 1. 받을 때 확인할 것 (팬텀 자체)

| 항목 | 요구 | 왜 |
|---|---|---|
| 화소 수 | **512² 이상** | QA-B-110 §1(6): 6단 피라미드 영향 범위 128화소 → 조사야 ≥ 2×128+64 = 320화소, 영상 ≥ 448화소 |
| 화소 간격 | **0.14 ~ 0.4 mm**(제품 수준) | 영향 범위는 **화소 수**로 정해진다. 지금 팬텀의 4 mm 로 512² 를 만들면 2 m 가 되어 뜻이 없다 |
| 조사야 | 한 변 **320화소 이상**, 경계가 **영상 안**에 있을 것 | 지금 80² 는 조사야가 74화소라 경계가 가장자리에 붙어 있어 마스크 대안을 비교할 수 없다 |
| 포함 영상 | `total`, `primary`, `thickness`, `air` | `air` 로 조사야 마스크를 만든다(`FieldMask`). `thickness` 로 두께 구간을 나눈다 |
| 두께 범위 | **10 ~ 30 cm** 구간이 있을 것(계단 또는 쐐기) | REQ-GSVG-017 을 MC 기준으로 재현하려면 각 두께에 화소가 충분해야 한다 |
| 격자 | **이상 격자 기준**(tp 1, ts 0) — 정답은 `primary` 하나 | QA-B-116 §1(3) 리더 결정. 제품 격자로 보면 정답에 우리 표의 Ts/Tp 가 들어가 자기 순환이 생긴다 |

## 2. 반드시 다시 재고 고쳐야 하는 것

### (1) REQ-GSVG-018 잠정 바닥 — **유일하게 팬텀에 묶여 있다**

| | |
|---|---|
| 파일 | `modules/gsvg/tests/test_virtual_grid_mc.cpp` |
| 시험 | `GsvgVirtualGridMc.ProvisionalFloor_StepEdgeUnderSubtraction_REQ_GSVG_018` |
| 상수 | 열 평균 봉우리 **1.465**, 최악 화소 **1.612**, 중앙값 \|r−1\| **0.069** |
| 현재 측정값 | 1.4521 / 1.5522 / 0.0623 |
| 왜 깨지는가 | 봉우리가 **최댓값 통계**라 잡음이 한쪽으로만 민다. 상대 잡음 0.1% 로 여유(0.013)의 58~83% 를 먹고 **0.3% 면 넘는다**(QA-B-117 §1(2)) |
| 할 일 | 새 팬텀에서 세 값을 **다시 재고**, 리더 결정(QA-B-117: A안)대로 **측정값 기준으로 재설정**한다. 미리 넓히지 않는다 |

또한 같은 파일의 다른 MC 시험들이 팬텀 모양에 의존한다 — 바꾸면 함께 본다:

| 시험 | 무엇에 의존 |
|---|---|
| `GsvgVirtualGridMc.DataAndConditions` | 두께 방향(열), 조사야 행/열 범위, `kAirDn`, 최대 두께 < 27, `factor == 1` |
| `GsvgVirtualGridMc.CompareToPrimary` | 설정별 `absMedian < none.absMedian`(느슨한 경계라 아마 유지) |
| `GsvgVirtualGridMcMask.*` | `FieldMask`(air 기준), 조사야 밖 화소가 존재할 것 |
| 파일 상단 상수 | `kN = 80`, `kPitchMm = 4.0`, `kDnScale`, `kAirDn`, `kLo = 8, kHi = 72` — **전부 새 팬텀 값으로** |

## 3. 건드릴 필요 없는 것 — 그리고 그 이유

| 요구 | 시험 | 지표의 성질 | 지금 불변? | 팬텀 교체 시 |
|---|---|---|---|---|
| **005** 잔여 격자 | `GsvgGridSuppression.ProvisionalFloor_ResidualGridEnergy_REQ_GSVG_005` | 대역 **에너지 비**(극값 아님) | 예 | **불필요** — 합성 장면(seed 180) |
| **006** 경계 가로 MTF | `GsvgGridSuppression.ProvisionalFloor_MtfLossAcrossTheEdge_REQ_GSVG_006` | **최악 손실 = 극값**(밴드의 max, 각 밴드는 주파수의 max) | 예 | **불필요** — 합성 경사 경계. 다만 넷 중 018 과 가장 성질이 비슷하다 |
| **008** 에일리어싱 | `GsvgGridSuppression.ProvisionalFloor_SevereAliasing_REQ_GSVG_008` | 에너지 비 + 검출 플래그(이산) | 예 | **불필요** — 합성 장면 |
| **017** 두께별 | `GsvgVirtualGridRange.ProvisionalFloor_RecoveryAcrossTheRequiredThickness_REQ_GSVG_017` | **중앙값**(강건) + p95(약한 극값) | 예 | **불필요** — 합성 장면. 단 (2)의 MC 재측정은 별도로 한다 |
| **018** 계단 덜 뺌 | `GsvgVirtualGridMc.ProvisionalFloor_StepEdgeUnderSubtraction_REQ_GSVG_018` | **봉우리 = 최댓값** | 예 | **필요** — 위 (1) |

"지금 불변" 은 같은 빌드에서 두 번 돌려 출력이 한 글자도 다르지 않음을 확인한 것이다(QA-B-118 `_run1.txt` / `_run2.txt`). 005·006·008 은 QA-B-109 에서 5회 반복으로도 확인했다.

**주의**: "불변" 은 장면을 바꾸지 않았을 때다. 각 시험의 장면을 건드리면(잡음 씨앗, 경계 각도, 두께 구성) 값이 움직인다 — QA-B-109 가 잰 폭은 005 의 after/before ±1%, 008 ±6%, 006 ±4%, 005 의 after/baseline 은 최대 3배다.

## 4. 순서 제안

1. 팬텀을 받아 §1 의 여섯 항목을 확인한다. 하나라도 어긋나면 **재측정 전에** pre 레인에 알린다.
2. `test_virtual_grid_mc.cpp` 의 상단 상수를 새 팬텀에 맞춘다. 이 단계에서 MC 시험 여러 건이 빨강이 된다 — **정상이다.**
3. 018 세 값을 다시 재고 재설정한다(§2(1)).
4. §2(2)의 새 측정을 한다 — 마스크 대안(4·6단), 017 의 MC 기준 재측정.
5. 005·006·008·017 의 바닥은 **손대지 않는다**(§3). 손대야 할 것 같으면 그 이유를 먼저 적는다.

## 5. 이 파일이 놓칠 수 있는 것

- 새 팬텀의 **잡음 수준을 모른다.** §2(1)의 재설정 폭이 얼마나 될지는 받아 봐야 안다.
- 512² 는 80² 의 41배 화소다. MC 시험 전체 시간이 늘어난다 — **측정 전용 시험을 따로 두고 기본 회귀에는 넣지 않는 것**을 제안한다(QA-B-115 §3(3)).
- 이 목록은 gsvg 모듈 안만 본다. 다른 모듈이 MC 자료를 쓰는지는 확인하지 않았다.
