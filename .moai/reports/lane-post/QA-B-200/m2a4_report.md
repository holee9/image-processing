## 1. 보류 1 — 모든 쌍

**원인.** M2a3 는 선택값(우선순위 첫 유효값)과 나머지 유효값을 각각 비교했다. 두 값이 각자 선택값과는 허용오차 안인데 서로는 어긋날 수 있다. Codex 재현: 1153 = 2500 µAs(2.5 ±0.0005, 선택), 9332 = 2.4994(±0.0001), 1152 = 3(±0.5) — 선택값과는 각각 한도 안이지만 9332 와 1152 의 차 0.5006 이 한도 0.5001 을 넘는다.
**고침.** 세 값 가운데 유효한 것들의 모든 쌍(0-1, 0-2, 1-2)을 `|차| > 허용오차 합 + 1e-9` 로 비교한다. 불일치가 하나라도 있으면 알림 한 번(문구는 그대로: 유효한 값 전부와 사용한 값). 가능한 실제값 구간의 교집합이 비었는지 보는 방법도 같은 결과를 주지만 쌍 비교가 코드와 설명이 단순해 택했다(세 구간에서는 모든 쌍이 겹침과 교집합이 존재함이 동치다).
**시험(`TwoValuesThatContradictEachOtherPostTheAlertEvenWhenEachAgreesWithTheChosenOne`).**
- Codex 재현값(2500 / 2.4994 / 3): 읽은 mAs 는 선택값 2.5, 알림 정확히 1건, 알림이 세 값과 선택값을 모두 이름으로 담음.
- 경계 대조: 9332 = 2.4999, 1152 = 3 (차 0.5001 = 허용 0.5 + 0.0001) → 알림 0건. 더 엄격해지기만 한 비교가 아니라는 대조군.
- 선택값과 다른 값이 충돌하는 경우(1153 = 3000 µAs, 9332 = 2.4, 1152 = 3): 알림 1건(이 경우는 옛 규칙도 잡았다).
**반증.** 선택값과만 비교(옛 규칙) → 재현값 시험이 빨강. 쌍 비교의 허용오차를 무시(1e-9) → 경계 대조와 M2a3 의 일치 시험이 빨강. 허용오차를 사실상 무한대로 → 충돌 시험 빨강.

## 2. 보류 2 — IS 의 12바이트 상한

**원인.** `findAndGetOFString` 은 IS 값의 앞뒤 공백을 지우고 돌려준다. M2a3 의 `parseIntegerString` 은 그 뒤의 길이로 12바이트를 재서, 공백 12개 + `1` 처럼 파일 속 값이 13바이트(저장 14바이트)여도 `1` 로 읽혔다. (M2a3 보고서의 "공백 제거를 끈 팔은 DCMTK 가 이미 제거해 도달 불가" 와 같은 뿌리: 공백 제거가 DCMTK 에서 일어나므로 길이는 거기서 이미 짧아진다.)
**고침.** 원소 자체의 길이를 본다: `single(key, maxBytes)` 도우미가 VM 1 과 `getLength() <= maxBytes` 를 함께 검사한다. IS 두 속성은 12, FD(9332)는 8. 숫자 문법은 기존 `parseIntegerString` 그대로.
**시험(`TheTwelveByteLimitOfAnIntegerStringIsMeasuredOnTheValueAsStored`).** `(0018,1152)`: 12개 공백 + `1`(13바이트) → mAs 없음(0), 11개 공백 + `1`(정확히 12바이트) → 1(대조). `(0018,1153)`: 9개 공백 + `2500`(13바이트) → 건너뛰고 `(0018,1152)` 의 7, 8개 공백 + `2500`(정확히 12바이트) → 2.5.
**반증.** 저장 길이 검사를 끔 → 시험 빨강. 상한을 `<=` 에서 `<` 로(경계 어긋남) → 시험과, FD 9332 의 8바이트 길이도 막혀 읽기 순서 시험 등이 함께 빨강.

## 4. Gap / 잔여 위험
Gap
- 저장된 길이는 DCMTK 가 읽어 온 원소의 길이이다. 파일을 DCMTK 로 직접 만들어 시험했고 다른 도구가 쓴 파일(예: 짝수 맞춤 NUL 패딩)은 시험하지 않았다.
- `(0018,9332)` FD 의 길이 8 검사는 시험하지 않았다(VM 1 FD 는 정확히 8바이트라 정상 파일에서는 항상 통과하고 비정상은 만들지 않았다).

잔여 위험
- 쌍 비교는 허용오차를 이 모듈이 쓰는 반올림(1 µAs, 4자리, 1 mAs)에 맞췄다. 다른 장비가 다르게 반올림하면 정상 파일에서 불일치 알림이 날 수 있다(알림이고 값은 바뀌지 않음, M2a3 와 같음).
