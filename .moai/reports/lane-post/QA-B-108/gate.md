# QA-B-108 게이트 — 마스크 밖 0 의 영향 측정과 대안 비교, B-107 미검증 4건 (#189, #180)

커밋 `ed4a161`, 미푸시. **제품 기본값은 바꾸지 않았다**(`MaskOutside::Zero`). 카드 §1.3 대로 결정은 리더 몫이다.

## 1. 주장

### (1) 이 선택이 닿는 경로는 후처리 하나뿐이다

`pyramidLevels = 0`(후처리 없음)으로 놓으면 네 대안의 출력이 **바이트 동일**하다. 영구 시험 `GsvgMaskOutside.WithoutPostStepsEveryVariantIsBitIdentical` 이 이것을 고정한다. 즉 "마스크 밖 0" 은 산란 추정·보정에는 영향이 없고, 이웃을 읽는 피라미드를 통해서만 마스크 안으로 들어온다.

MC 팬텀에서도 같다 — 후처리를 끈 상태에서 네 대안 전부 `memcmp` 0 이고, 회복/정답(primary) 비율이 전체 1.0389 · 경계 근처 0.9924 로 동일하다.

### (2) 영향 범위 — 경계로부터의 거리별 (합성 장면 1024²)

기준(a. 0)과의 상대 차이 중앙값. 링은 마스크 경계로부터의 거리(화소).

| 피라미드 | 대안 | ring 1 | ring 8 | ring 32 | ring 128 |
|---|---|---|---|---|---|
| 6단 | b. 가장자리 복제 | 0.1295 | — | — | 0.0025 |
| 6단 | c. 입력 그대로 | 0.0210 | — | — | 0.0004 |
| 6단 | d. 사각형 안에서만 | 0.1108 | — | — | 0.0024 |
| 4단 | (셋 다) | — | — | — | ring 64 에서 0.0004 |

- 6단에서 경계 화소는 **13%(복제) / 2%(그대로) / 11%(사각형)** 까지 달라진다. 128화소 안쪽에서 0.2~0.04% 로 잦아든다.
- 4단이면 64화소에서 이미 0.04% 다. **영향 범위는 피라미드 단수가 정한다.**
- 80²·256² 작은 영상에서는 피라미드 영향이 영상 전체에 미쳐 거리별 프로파일을 잴 수 없다(측정 불가로 기록).

### (3) 경계에서의 인위적 대비 (1024², 6단)

경계 바로 안쪽(ring 1)과 깊은 안쪽의 차이. 후처리를 끈 원래 장면의 값은 **0.3210** 이다.

| 대안 | 경계 단차 | 원래 대비 초과분 |
|---|---|---|
| a. 0 (현재) | 0.5670 | +0.246 |
| c. 입력 그대로 | 0.5335 | +0.213 |
| d. 사각형 안에서만 | 0.3910 | +0.070 |
| b. 가장자리 복제 | **0.3598** | **+0.039** |

**지금의 0 이 인위적 단차를 가장 많이 만든다.** 가장자리 복제가 가장 적다.

### (4) 물리적 사실과의 대조 (카드 §1.3)

조사야 밖은 신호가 0 이 아니라 **산란만 있는 낮은 신호**다. 0 은 실제로 존재하지 않는 값이며, 피라미드가 그 0 을 이웃으로 읽어 경계 안쪽 대비를 위로 밀어 올린다 — (3)의 +0.246 이 그 크기다.

물리적 사실이 지지하는 것은 **(b) 가장자리 복제**다. 조사야 밖의 실제 신호(낮은 산란)는 경계 안쪽 값보다 훨씬 낮지만 0 보다는 크고, 복제는 "밖에서 급격한 단차가 없다" 는 성질만 빌려와 인위적 단차를 최소화한다. 측정에서도 복제가 원래 대비에 가장 가깝다(+0.039).

(c) 입력 그대로 두기는 보정 전 값과 보정 후 값이 경계에서 맞닿아 또 다른 인위적 단차를 만든다(+0.213). (d) 사각형 안에서만 돌리기는 마스크가 사각형이 아닐 때 모서리에서 같은 문제가 남는다(+0.070).

**결정은 리더 몫이며, 기본값은 `Zero` 로 두었다.**

### (5) B-107 미검증 4건

**메모리** (3072², 커밋 차지, 준비 호출 뒤 기준선 대비 최댓값. 한계 512 MB)

| 설정 | 최대 메모리 |
|---|---|
| GlobalSum(기본) 6단 | 151.5 MB |
| **LocalSum 6단** | **217.1 MB** |
| **SmoothFloor 6단** | **223.9 MB** |
| GlobalSum 0단 | 144.8 MB |
| GlobalSum 4단 | 151.2 MB |
| GlobalSum 8단 | 151.8 MB |
| 마스크가 99.96% 를 제외 | **370.5 MB** |

- 상한 두 가지는 전 해상도 버퍼를 하나씩 더 잡아 +66 ~ +72 MB 다. 예측(75.5 MB)과 맞는다. 둘 다 한계 안이고 여유 288 MB 이상.
- **피라미드 단수는 메모리를 거의 바꾸지 않는다**(0단 144.8 ↔ 8단 151.8, 차이 7 MB). 하위 단계가 1/4씩 줄기 때문이다.
- 이 표의 기본값 151.5 MB 는 B-107 의 241 MB 와 다르다 — B-107 은 `gsvg.cpp` 경로 전체(`original`·`img` 복사 포함), 이 표는 `RunVirtualGrid` 단독 호출이다. 같은 값으로 비교하지 말 것.

**마스크가 거의 전부를 제외하는 경우** — 3072² 중 가운데 64×64 만 남기면 370.5 MB 다. B-107 §4 에서 "최악이면 이득 없음" 이라 적은 그대로, 보관 배열이 옛 `out` 크기(75.5 MB)에 육박한다. 한계 안이다. 동작은 정상이다: 제외된 9,433,088 화소가 전부 입력값을 유지했고, 안쪽 4,096 화소는 전부 바뀌었다.

**속도** (3072², 스레드 자동, 한가한 기계, 7회 중앙값)

| 경로 | B-105 (이전) | B-107 뒤 |
|---|---|---|
| 그리드 억제 | 493 ms | **480.7 ms** |
| 가상 그리드 | 488 ms | **494.8 ms** |

**B-107 변경의 속도 영향은 없다**(측정 흔들림 안). 제자리 쓰기와 이동은 복사를 줄이므로 느려질 이유가 없다는 B-107 §4 의 예상과 맞는다.

## 3. 기준선 귀속

- 경계 단차 0.3210 은 같은 장면을 **후처리 없이** 돌린 값이다(대안 비교와 같은 실행).
- 속도 "이전" 493/488 ms 는 QA-B-105 gate.md 의 값이고, 이번 480.7/494.8 은 `ed4a161` 과 같은 소스의 `build/ci-post` 에서 오늘 다시 잰 값이다.
- 메모리 측정 방법·기기는 QA-B-106 gate.md §2, QA-B-107 gate.md §3 과 같다(PrivateUsage, 0.5 ms 표본, 작업 집합은 쓰지 않음).

## 4. 미검증

- **MC 팬텀에서 후처리를 켠 상태의 정답 대비 비율**은 재지 못했다. MC 팬텀은 80² 라 피라미드 영향이 영상 전체에 미쳐(비율 0.05~0.53), 대안 사이의 정확도 비교로 쓸 수 없다. 카드 §1.2 의 "정답(MC primary)과의 비율 변화" 는 **후처리를 끈 조건에서만**(네 대안 동일, 1.0389) 확인했다.
- 합성 장면은 사각·원형 조사야 두 가지뿐이다. 실제 장비의 불규칙한 조사야 경계는 확인하지 않았다.
- 대안 b·c·d 의 속도와 메모리는 재지 않았다. b 는 추가 버퍼가 없고 d 는 작은 영상에서 돌리므로 더 쌀 것으로 보이나 측정하지 않았다.
- 3072² 보다 큰 영상, 반복 횟수를 바꾼 경우의 메모리.
- 억제 경로 384 MB 의 내역은 이번에도 세지 않았다(B-107 §4 그대로).

## 5. 잔여 위험

- 영향 범위가 피라미드 단수에 좌우되므로, 제품이 단수를 올리면 (2)의 표는 다시 재야 한다. 영구 시험은 "후처리 없을 때 동일" 만 고정하지 단수별 범위는 고정하지 않는다.
- `MaskOutside` 는 시험용 스위치로 넣었다. 리더가 기본값을 바꾸기로 하면 기존 기준 파일 12개가 전부 달라지므로, 그때는 새 기준을 만들고 무엇이 왜 달라졌는지를 따로 기록해야 한다.
- 마스크 극단(370 MB)은 한계까지 142 MB 남는다. 4096² 로 커지면 이 경로가 먼저 한계에 닿을 가능성이 있다(미검증).
