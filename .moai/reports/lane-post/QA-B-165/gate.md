# QA-B-165 (`#191`) — σ₁ 가설은 **반대로** 틀렸고, 상한이 막는 장면은 **못 만듭니다**

## 1. 주장

1. **사각 2 — 가설 반증. 그것도 예측과 반대 방향입니다.**
   **σ₁ 을 꺼도 봉우리가 안 움직이고**(0.42 → 0.42 mm), **σ₂ 를 끄면 8배 밖으로**
   나갑니다(0.42 → 3.36 mm). 카드의 두 예측이 **둘 다** 틀렸습니다. §2
2. **카드의 전제도 낡았습니다.** `σ₁ = 0.92–1.21 mm` 는 단위 오독이고 실측은
   **10.17 mm** 입니다 — 봉우리의 **24배**, 같은 자릿수가 아닙니다. §2
3. **사각 4 — 못 만듭니다.** 커널을 손대지 않은 **11개 설정 전부 음수 1차 0건**.
   대조군(×3 커널)이 **7613건**을 내므로 프로브가 눈먼 것이 아닙니다. §3
4. **그것이 답이고 실패가 아닙니다** — 안전 기능 검증은 영구히 합성 시험 몫이고,
   그 사실이 SPEC 에 들어갈 내용입니다. §3
5. 사각 1·3 은 손대지 않았습니다(입력 없음).

## 2. 사각 2 — 항을 **꺼서** 잰 결과

### 먼저 단위 (카드 §2 가 요구한 병기)

표는 **cm** 로 저장합니다 — CSV 머리말 *"r in cm at the detector plane"*, 그리고
`virtual_grid.cpp` 가 **cm 단위 피치로 나눕니다**. 구조체도
`double s[4] = {…};   // cm` 라고 적혀 있습니다.

측정한 gauss4 (5 cm / 60 kVp 노드):

```
VGMC165 kernel terms=4 sigma_mm: 10.17  29.37  58.58  112.09   (표는 cm; ×10 이 mm)
```

**σ₁ = 10.17 mm.** 이슈가 적은 `0.92–1.21 mm` 는 **cm 를 mm 로 읽은 것**이고,
봉우리(0.42 mm)는 σ₁ 의 **1/24** 입니다 — *"자릿수가 같다"* 가 성립하지 않습니다.
이 저장소가 같은 오독으로 SPEC 과 후속 카드를 낳은 적이 있고, `QA-B-134` 가 이미
정정해 둔 것입니다.

### 측정 — 두 갈래로

항을 끄면 **총 산란량도 같이 줄어듭니다.** 그래서 두 갈래로 갈랐습니다:

- **raw** — `a_i = 0`, 나머지 그대로 → **총량이 줄어듦**(진폭 효과 포함)
- **norm** — `a_i = 0`, 나머지를 `Σa` 가 보존되도록 확대 → **형상만 바뀜**

가설은 *형상*에 대한 것이므로 **norm 이 판정 줄**입니다.

| 끈 항 | σ_off (mm) | 갈래 | peak_at (mm) | median |
|---|---|---|---|---|
| — (기준) | — | — | **0.42** | 0.0554 |
| **σ₁** | 10.17 | raw | 0.21 | 0.1252 |
| **σ₁** | 10.17 | **norm** | **0.42 — 그대로** | 0.0896 |
| **σ₂** | 29.37 | raw | **3.36** | 0.4498 |
| **σ₂** | 29.37 | **norm** | **3.36 — 8배 밖** | 0.2579 |
| σ₄ (대조) | 112.09 | raw | 0.42 | 0.0584 |
| σ₄ (대조) | 112.09 | **norm** | **3.36** | 0.1707 |

### 두 예측 모두 틀렸습니다

| 카드의 예측 | 실측 | 판정 |
|---|---|---|
| σ₁ 을 끄면 봉우리가 **사라지거나 σ₂ 쪽으로 이동** | **그대로 0.42 mm** (norm) | **반증** |
| σ₂ 를 끄면 봉우리가 **거의 안 변함** | **0.42 → 3.36 mm, 8배** | **반증** |

**σ₁ 은 봉우리 위치를 정하지 않습니다.** 형상만 바꾼 norm 갈래에서 σ₁ 을 통째로
없애도 봉우리가 **정확히 같은 구간**에 남습니다. 반대로 σ₂ 를 없애면 크게
움직입니다.

### 다만 "σ₂ 가 정한다" 도 아닙니다

**σ₄ 를 끈 norm 갈래도 3.36 mm 로 갑니다.** 가장 넓은 항을 없애는 것이 좁은 항의
봉우리를 옮길 이유는 없으므로, 움직임의 원인은 *"어느 한 항"* 이 아니라
**항들 사이의 가중치 배분**입니다 — norm 이 남은 항들로 진폭을 재분배하기
때문입니다.

> **읽기**: 봉우리 위치는 **혼합비**를 따라가지 **가장 좁은 항의 폭**을 따라가지
> 않습니다. `QA-B-134` 의 폭 스윕(σ₁ 을 3배로 늘려도 안 움직임)과 여기의 끄기
> 실험이 **같은 결론에 다른 경로로** 도달합니다.

### 계측이 눈멀지 않았다는 증거 — 이번엔 실험 안에 있습니다

봉우리는 구간 중앙값 `0.07 / 0.21 / 0.42 / 0.84 / 1.68 / 3.36 / 6.72 / 13.44 mm`
로만 나옵니다. `QA-B-158` 에서는 *"3배 이동이면 구별된다"* 를 **계산으로** 논했는데,
이번에는 **같은 계측이 실제로 0.42 → 3.36 으로 여덟 배 이동을 세 번 찍었습니다.**
안 움직인 줄(σ₁ norm)은 **못 본 것이 아니라 안 움직인 것**입니다.

### 오차 **크기**는 모든 항이 바꿉니다

`median` 이 기준 0.0554 에서 0.058~0.45 로 모든 경우 올라갑니다. 즉 각 항은
**오차의 크기에 기여**하지만, **위치**를 정하는 것은 좁은 항이 아닙니다.
`factor` 는 일곱 경우 모두 32 로 불변입니다.

## 3. 사각 4 — 상한이 막는 장면을 **만들 수 없습니다**

### 무엇을 물었나 (아래 기존 시험과 다른 질문)

`OverEstimatedKernelsMakeTheCapProtect_191`(`QA-B-134`)은 커널 진폭을 2~10배로
**망가뜨린 뒤** 상한이 바닥을 지키는 것을 보입니다 — *"깨진 표를 받았을 때
작동하는가"* 에 대한 답이고, 그것은 예입니다.

**이 카드의 질문은 다릅니다**: *"표를 망가뜨리지 않고 이 팬텀이 거기 도달할 수
있는가."* 그래서 **호출자가 돌릴 수 있는 손잡이만** 돌렸습니다 — 반복 횟수,
설정이 주장하는 kVp, 공기 신호. **커널 표는 출고 상태 그대로**입니다(카드 §4 가
적합 재실행을 금지했고, 그것을 건드리면 질문을 구걸하는 셈입니다).
모든 줄은 `CapMode::None` 입니다 — **상한을 켜면 상한이 막는 것을 볼 수 없으니까요.**

| 손잡이 | 값 | negativePrimary | median r |
|---|---|---|---|
| iterations | 1 / 5 / 20 / 100 | **0 / 0 / 0 / 0** | 1.123 / 0.995 / 0.993 / 0.993 |
| kvp | 60 / 70 / 100 / 120 | **0 / 0 / 0 / 0** | 1.026 / 1.009 / 0.974 / 0.961 |
| airSignal | 25000 / 40000 / 75000 | **0 / 0 / 0** | 1.126 / 1.025 / 0.924 |
| **합계** | 11 설정 | **0 건** | |

### 그 0 이 측정임을 보이는 대조군

```
VGMC165 cap CONTROL x3 kernels: negPrimary=7613
```

같은 팬텀·같은 프로브에서 커널 진폭을 3배로 하면 **7613건**이 나옵니다.
**프로브는 음수 1차를 볼 수 있습니다** — 위의 0 은 프로브가 아니라 **팬텀에 대한
관측**입니다. (시험이 이 대조군을 `EXPECT_GT` 로 단언하므로, 훗날 프로브가 눈멀면
빨강이 납니다.)

### 처분 — 카드 §3 의 **둘째 칸**

**만들 수 없습니다.** 이유는 수치가 말합니다: `median r` 이 최악(`airSignal` 75000)
에서도 **0.924** 로, 1차의 92 % 가 남습니다. 음수가 되려면 추정 산란이 총 신호를
**넘어야** 하는데, 출고 커널의 SPR 로는 그 근처에도 못 갑니다 — 손잡이를 자릿수로
흔들어도(반복 1→100, 공기 신호 ±50 %) median 이 0.92~1.13 안에 머뭅니다.

> **이것은 실패가 아니라 결론입니다.** `REQ-GSVG-025` 의 보호 기능은 **이 팬텀
> 계열에서 원리적으로 관측되지 않고**, 검증은 합성 시험(`QA-B-112`·`113`)과
> 손상 주입(`QA-B-134`) 몫으로 **영구히** 남습니다. 지금의 공백 —
> *"걸린다는 확인됐고 막아 준다는 안 됐다"* — 보다 **이 문장이 SPEC 에 들어갈
> 내용**입니다.

## 4. 이 카드가 사각 1·3 에 대해 한 것

**아무것도 하지 않았습니다**(카드 §4). 다만 §2 의 결과가 **사각 1 의 설계에
영향을 줍니다**: 봉우리가 σ₁ 에 붙지 않으므로, *"σ₁ 으로 재야 할 거리를 예측한다"*
는 경로는 **닫혔습니다.** 계단 간격은 여전히 *재고 싶은 거리*로 골라야 하고,
`tools/mcsim/run_512_wide_steps.sh` 가 이미 그렇게(2.5 cm, 경계 거리 ~25 mm)
짜여 있습니다.

## 6. 미검증 · 잔여 위험

- **봉우리 위치의 해상도가 거칩니다**(8구간). **2배 미만의 이동은 인접 구간에
  묻힙니다** — "σ₁ norm 에서 안 움직였다" 는 *"두 배 미만으로도 안 움직였다"* 를
  뜻하지 않습니다
- **"혼합비가 정한다" 는 읽기이지 측정이 아닙니다.** 측정된 것은 세 항을 끈 일곱
  줄이고, **가중치를 연속적으로 바꿔 가며 봉우리를 추적하지는 않았습니다**
- **`norm` 의 재분배 규칙은 제가 고른 것입니다**(남은 항에 비례 배분). 다른
  규칙이면 다른 결과가 나올 수 있고, 그 민감도는 안 쟀습니다
- **사각 4 의 "못 만든다" 는 제가 고른 11개 설정에 대한 것입니다.** 손잡이를 더
  돌리면(예: 격자 비·픽셀 피치·후처리 조합) 도달할 수 있는지는 모릅니다 —
  *"원리적으로 불가능"* 이 아니라 **"이 범위에서 관측되지 않음"** 입니다
- 두 시험 모두 **`step` 팬텀 하나**입니다. `wedge` 는 안 돌렸습니다
- 사각 1·3 은 **여전히 열려 있습니다**
