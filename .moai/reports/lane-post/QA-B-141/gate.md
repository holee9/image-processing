# QA-B-141 (#155) — 전제는 **아직 참**이고, 상쇄가 버리는 양은 **전체의 45 %** 입니다

## 1. 주장 (Claim)

1. **(a) `#155` 의 전제는 여전히 참입니다.** 인용된 코드가 그대로이고 아무도 고치지
   않았습니다. 검색 범위와 대조군은 §2 에 적었습니다.
2. **(b) 상쇄는 실재합니다.** 광도를 **6가지**로 흔들어도 LUT 은 직선 램프에서
   **1 카운트** 이상 벗어나지 않고, 여섯 중 **어느 두 개를 골라도** 최대 차이가
   **1 카운트**입니다.
3. **대조군이 이 카드의 새 것입니다.** 기존 시험은 두 설정을 비교해 "안 움직인다" 만
   말했고, **대조군 없는 부재 단언은 측정이 눈멀어도 통과합니다.** 코드 자신의 3차
   모델을 역산해 "모델이 닿았다면" 의 LUT 을 만들어 거리를 쟀습니다 —
   **최대 29578 / 65535 (45 %), 평균 18668 (28 %)**.
4. **(c) 수식은 건드리지 않았습니다.** 표시 화소가 바뀌는 영역이고, 판정은 리더의
   것입니다.

## 2. (a) 전제 확인 — 검색 범위와 대조군

**검색 범위**: `modules/display/src/` 전체(5파일)에서 `GSDF|gsdf` 로 검색해 나온 파일은
`presentation_lut.cpp` **하나**입니다. 그 파일의 `xpe_gsdf_calibrate` 본문
(`:95-160`)을 읽었습니다.

**이슈가 인용한 다섯 줄이 그대로 있습니다:**

```cpp
float target_jnd = jnd_min + (static_cast<float>(i) / 1023.0f) * jnd_range;
...
float t = (target_jnd - jnd_min) / jnd_range;
float log_L = log_lmin + t * (log_lmax - log_lmin);
float ddl_f = ((log_L - log_lmin) / (log_lmax - log_lmin)) * 65535.0f;
```

`t` 는 자기를 만든 값에서 되복원되므로 `i/1023` 이고, `jnd_min`·`jnd_range`·
`log_lmin`·`log_lmax` 가 전부 약분됩니다. `:113-118` 의 3차 모델은 계산되고 버려집니다.
주석의 *"simple linear approximation of the inverse"* 도 그대로입니다.

**존재 대조군** (부재만 보지 않기 위해): 같은 파일에 **약분되지 않는** 경로가 있습니다 —
`lum_min <= 0`, `lum_max <= lum_min`, `jnd_max <= jnd_min` 의 보호 분기와 단조 증가
보정(`if (ddl < prev) ddl = prev`)은 실제로 출력을 바꿉니다. 즉 "이 파일에서 아무것도
출력에 안 닿는다" 가 아니라, **닿는 것과 안 닿는 것이 같은 함수 안에 있습니다.**

**시험 쪽 대조**: `ctest` 목록에 `GsdfCharacterization.*` 4건이 이미 있고(QA-B-57),
그 셋이 오늘도 초록입니다 — 즉 **고쳐졌다면 그 셋이 빨강이었을 것**입니다.

## 3. (b) 한 축 스윕 — 광도만 흔들기

`xpe_gsdf_calibrate` 에 넘기는 광도 배열만 바꾸고 나머지는 고정했습니다.
(JND 계수 3차식은 소스 상수라 호출자가 흔들 수 있는 축이 아닙니다 — §6.)

| 설정 | 범위 | 직선 램프와의 최대 편차 |
|---|---|---|
| sub-decade | 80–120 cd/m² | **1** / 65535 |
| 1 decade | 10–100 | **1** |
| 3 decades | 1–500 | **1** |
| 4 decades | 0.5–5000 | **1** |
| 6 decades | 0.01–10000 | **1** |
| dim pair | 0.05–0.5 | **1** |

**여섯 LUT 중 어느 두 개를 골라도 최대 차이 = 1 카운트**
(sub-decade 대 1 decade). 광도 측정값이 **여섯 자릿수(10⁻²–10⁴)** 를 오가도 출력은
같은 램프입니다.

> **안 움직입니다 → 상쇄가 실재하고, 그 모델은 지금 아무것도 하지 않습니다.**
> (카드 (b) 의 두 갈래 중 첫째)

## 4. 대조군 — 상쇄가 버리는 양

**부재 단언에는 대조군이 필요합니다.** "LUT 이 안 움직인다" 는, 측정이 눈멀어도 똑같이
통과합니다. 그래서 **같은 입력으로 움직이는 LUT 을 하나 만들어** 측정이 볼 수 있음을
보였습니다.

**무엇을 만들었나**: 코드 자신의 3차식을 **실제로 역산**한 LUT. 목표 JND 일정도, 최종
`log10 L → DDL` 매핑도 **그대로 두고**, 소스가 항등식으로 되복원하는 자리만 **진짜
역함수**로 바꿨습니다. 즉 **계산된 모델이 답에 닿게 하는 최소 편집**입니다.

**역산 가능 근거**(추측 아님): `p(x) = 71.498x³ − 94.593x² + 41.912x + 9.8212` 에 대해
`p'(x) = 214.494x² − 189.186x + 41.912`, 판별식 `189.186² − 4·214.494·41.912 = −173 < 0`
이라 실근이 없어 부호가 바뀌지 않고, `p'(0) = 41.912 > 0` 이므로 **순증가**입니다.
이분법 200회로 수렴합니다.

**측정 (1–500 cd/m², 진단용 모니터가 실제로 도는 범위):**

| 비교 | 최대 | 평균 |
|---|---|---|
| 현재 출력 ↔ 모델 반영 LUT | **29578** / 65535 (45.1 %) | **18668** (28.5 %) |
| 모델 반영 LUT ↔ 직선 램프 | **29578** | — |

최대 지점은 **index 158**. 두 줄의 최대가 같은 것은 현재 출력이 직선 램프와 **±1** 이기
때문입니다.

**읽는 법**: 측정이 눈먼 것이 아닙니다. 같은 입력에서 **전체 눈금의 45 % 만큼** 다른
곡선이 만들어집니다 — 상쇄가 버리는 것이 그만큼입니다.

## 5. (c) 고치지 않았습니다

제품 수식은 **한 줄도 바꾸지 않았습니다**. 대조군 LUT 은 **시험 안에서만** 만들어지고
제품 경로에 들어가지 않습니다.

**대조군은 적합성 기준이 아닙니다.** 코드가 이미 계산하는 3차식을 역산한 것뿐이고,
**DICOM PS3.14 가 그 곡선을 원하는지는 여기서 정하지 않습니다** — 표준의 표는 이
저장소에 없습니다(기존 파일 머리말이 기록한 사실이고, QA-B-56 이 "아무도 원전과 대조
안 한 수식으로 논쟁하는 비용" 을 적어 둔 그 자리입니다).

## 6. baseline 귀속 · 미검증 · 잔여 위험

**귀속**: 트리 `dev/postprocess`, `origin/main 15b9739` 병합 후. 커밋 `e6968b9`.

**미검증**

- **JND 계수 축은 못 흔들었습니다.** 3차식 상수는 소스에 박힌 리터럴이라 호출자가
  바꿀 수 없습니다. 카드가 "광도 **또는** JND 파라미터" 라 했고, **호출자에게 열린
  축은 광도 하나**입니다. 상수를 시험에서 바꾸려면 제품 코드를 건드려야 하므로
  (c) 에 걸립니다.
- **적합성은 재지 않았습니다.** 현재 곡선도, 대조군 곡선도 DICOM PS3.14 표와 대조하지
  않았습니다. 표가 저장소에 없습니다.
- **`xpe_apply_presentation_lut` 이 이 LUT 을 실제 화소에 어떻게 적용하는지**는 이
  카드에서 안 봤습니다 — 잰 것은 LUT 자체입니다.
- 대조군은 **1–500 cd/m² 한 점**에서만 쟀습니다. 다른 범위에서 45 % 가 더 커지는지
  작아지는지는 안 봤습니다.

**잔여 위험**

- 대조군 LUT 의 "최종 매핑은 그대로" 라는 선택 자체가 **하나의 해석**입니다. `log10 L`
  을 선형으로 DDL 에 싣는 것이 옳은지도 표준 문제이고, 다른 최종 매핑을 고르면 45 %
  라는 수가 달라집니다. **버려지는 양의 규모**를 말하는 데는 충분하지만, **정확한
  보정량**으로 인용하면 안 됩니다.
- 스윕의 단언은 `≤ 1` 입니다. 누가 모델을 잇되 **효과가 1 카운트 미만**이면 통과합니다.
  다만 대조군이 45 % 를 보여 주므로, 제대로 이으면 그 문턱을 크게 넘습니다.
