Idea: integer-generated 512x512 fixtures (no libm, same bytes everywhere) -> log, bilateral, CLAHE, USM -> FNV-1a 64 per stage.
The expected hashes are a table keyed by the MSVC tools major.minor (cl _MSC_VER / _MSC_FULL_VER at compile time of the TEST).

  - toolchain row present, hash differs      -> FAIL   (same compiler, different numbers: a real regression)
  - toolchain not in the table               -> GTEST_SKIP, message prints the three hashes of each fixture to paste into the table
  - non-MSVC build                           -> GTEST_SKIP
