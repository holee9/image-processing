# QA-B-142 (#155) — 표준 대조군: **45.1 % → 14.8 %**. 그리고 3차식은 **역순 전사**입니다

## 1. 주장 (Claim)

1. **식의 모양을 표로 갈랐습니다.** Eq 7-1 의 유리식 가설은 Table B-1 **열 점 전부**와
   인쇄된 네 자리로 일치합니다(최대 상대 편차 **0.042 %**, `L(1023) = 3993` 대 표준
   상한 4000).
2. **Eq 7-2 는 제 첫 가정이 틀렸습니다.** 유리식으로 놓으니 왕복 검산이 **최대
   1022 JND** 로 깨졌고, `log10 L` 의 **8차 다항식**으로 바꾸니 **0.092 JND** 로
   닫혔습니다. **판정한 것은 표와 왕복이지 출처의 권위가 아닙니다.**
3. **표준 대조군 대비 현재 LUT (1–500 cd/m²)**: 모듈 자신의 최종 매핑에서
   **최대 14.8 %**, 최종 매핑을 L 선형으로 바꾸면 **44.0 %**.
4. **QA-B-141 의 45.1 % 는 같은 최종 매핑에서 14.8 % 로 내려갑니다.** 그때 붙여 둔
   잔여 위험이 그대로 확인됐습니다 — 최종 매핑 선택이 수를 지배합니다.
5. **그 3배 차이의 원인을 찾았습니다.** 모듈의 3차식은 "단순화한 Barten 모델" 이
   아니라 **Eq 7-2 의 계수 A·B·C·D 를 자리를 뒤집고 부호를 번갈아 쓴 것**입니다.
6. **제품 경로는 건드리지 않았습니다.**

## 2. 표준 전사를 믿지 않고 검증한 방법

카드 §2 가 *"제 말로 믿지 마십시오 — Table B-1 이 정답입니다"* 라 했습니다. 그대로
했습니다. 식은 본문에 이미지라 **계수만** 텍스트로 읽을 수 있고, **모양은 후보를 세워
표로 갈랐습니다.**

### Eq 7-1 — 가설이 통과

`log10 L(j) = (a + c·ln j + e·ln²j + g·ln³j + m·ln⁴j) / (1 + b·ln j + d·ln²j + f·ln³j + h·ln⁴j + k·ln⁵j)`

| j | 계산값 | Table B-1 | 네 자리 반올림 |
|---|---|---|---|
| 1 | 0.049982 | 0.0500 | 일치 |
| 2 | 0.054679 | 0.0547 | 일치 |
| 3 | 0.059375 | 0.0594 | 일치 |
| 10 | 0.099066 | 0.0991 | 일치 |
| 20 | 0.175044 | 0.1750 | 일치 |
| 30 | 0.275237 | 0.2752 | 일치 |
| 40 | 0.401919 | 0.4019 | 일치 |
| 50 | 0.557382 | 0.5574 | 일치 |
| 60 | 0.743957 | 0.7440 | 일치 |
| 70 | 0.964040 | 0.9640 | 일치 |

최대 상대 편차 **0.0419 %** — 표준이 스스로 밝힌 0.3 % 안쪽입니다. 독립 확인으로
`L(1023) = 3993.33 cd/m²`, 표준이 말한 상한 4000 과 맞습니다.

### Eq 7-2 — **제 첫 가설이 틀렸고, 왕복이 잡았습니다**

카드는 7-1 의 모양만 가설로 주었고, **7-2 의 모양은 제가 지어냈습니다.** 7-1 과 같은
유리식(`A,C,E,G,I` / `1,B,D,F,H`)으로 놓고 왕복시켰더니:

```
j=1    -> L=0.04998 -> j'=-0.174   (오차 -1.17)
j=1023 -> L=3993.33 -> j'= 0.490   (오차 -1022.51)
```

**형태가 틀렸습니다.** `log10 L` 의 **8차 다항식** `A + B·y + C·y² + … + I·y⁸` 로
바꾸니:

```
j=1    -> j'=   1.026   (오차 +0.026)
j=1023 -> j'=1022.908   (오차 -0.092)
최악 0.092 JND / 1023
```

**두 검증 모두 단언으로 박았습니다**(`StandardEquationsMatchTableB1_155`). 잘못 옮긴
식이 "표준" 이라는 이름으로 비교에 흘러들면, 그 비교의 모든 숫자가 무의미해집니다.

> 리더가 *"제 인용이 아니라 표가 갈라 줍니다"* 라 하셨고, **실제로 표가 갈랐습니다** —
> 그리고 갈라낸 것은 리더의 인용이 아니라 **제 가설**이었습니다.

## 3. (a) 표준 대조군 대비 현재 LUT

대조군은 모듈의 **일정**을 그대로 둡니다 — 측정 범위 안에서 **JND 지수 등간격**
(그것이 GSDF 의 정의이고 모듈이 의도한 바입니다). 바뀐 것은 **JND↔광도 변환이
표준 식인가**뿐입니다.

**1–500 cd/m² (진단용 모니터 범위, QA-B-141 과 같은 점):**

| DDL 최종 매핑 | 최대 차이 | 전체 눈금 대비 | 최대 지점 | 평균 |
|---|---|---|---|---|
| `log10 L` 선형 (**모듈 자신의 매핑**) | **9708** | **14.8 %** | index 327 | 6292 (9.6 %) |
| `L` 선형 | **28840** | **44.0 %** | index 663 | 18527 (28.3 %) |

**QA-B-141 과의 비교** (같은 범위, 같은 최종 매핑 `log10 L`):

| 대조군 | 최대 | 평균 |
|---|---|---|
| 코드 자신의 3차식 역산 (QA-B-141) | 29578 (45.1 %) | 18668 (28.5 %) |
| **DICOM PS3.14 (이번)** | **9708 (14.8 %)** | **6292 (9.6 %)** |

**45.1 % → 14.8 %.** 실제 간극은 제가 앞서 보고한 것의 **약 3분의 1**입니다.

## 4. 왜 3배였나 — 3차식은 **역순 전사**입니다

모듈의 3차식(`presentation_lut.cpp:113-118`)과 DICOM Eq 7-2 의 계수를 나란히 놓으면:

| 모듈 | 값 | 표준 | 값 |
|---|---|---|---|
| `y³` 계수 | 71.498 | **A (상수항)** | 71.498068 |
| `y²` 계수 | −94.593 | **B (`y¹`)** | 94.593053 |
| `y¹` 계수 | 41.912 | **C (`y²`)** | 41.912053 |
| `y⁰` 상수 | 9.8212 | **D (`y³`)** | 9.8247004 |

**자리가 정확히 뒤집혀 있고 부호가 번갈아 붙어 있습니다.** 주석이 부르는
*"simplified Barten model"* 이 아니라, **표준 계수를 거꾸로 옮긴 것**입니다.

가장 깔끔한 확인은 `L = 1 cd/m²`(`log10 L = 0`)입니다 — 모든 거듭제곱 항이 사라져 두
식이 **상수항으로 환원**됩니다:

- 표준: `j = A = 71.498` (Table B-1 이 `L(70) = 0.964`, `L(71) ≈ 0.99` 라 하므로 **맞습니다**)
- 모듈: `j = 9.8212`

| L (cd/m²) | 표준 j | 모듈 3차식 |
|---|---|---|
| 0.05 | 1.00 | −362.28 |
| 1 | 71.50 | 9.82 |
| 50 | 387.40 | 158.62 |
| 500 | 705.94 | 839.57 |
| 4000 | 1023.16 | 2275.00 |

모듈의 곡선이 실제 GSDF 보다 **훨씬 크게 휘어 있고**, 그래서 QA-B-141 의 대조군이
간극을 과장했습니다.

**이 결함은 현재 도달 불가능합니다** — 그 3차식은 어차피 약분됩니다(#155 의 본론).
크기만 기록합니다. **고치면 두 가지가 동시에 바뀌므로**(상쇄 해소 + 계수 정정) 어느
쪽을 먼저 할지는 판정 사항입니다.

## 5. (b) 고치지 않았습니다 — 그리고 §5 의 조건

`presentation_lut.cpp` 는 **한 줄도** 바꾸지 않았습니다. 대조군은 시험 안에서만
만들어집니다.

**무엇을 고정하고 무엇을 바꿨는지** (카드 §5):

| 항목 | 상태 |
|---|---|
| JND 지수 등간격 일정 | **고정** (모듈과 동일, GSDF 정의) |
| 측정 범위 `[lum_min, lum_max]` | **고정** (모듈과 동일) |
| JND ↔ 광도 변환 | **바꿈** — 모듈의 3차식 → DICOM Eq 7-1/7-2 |
| DDL 최종 매핑 | **둘 다 보고** — `log10 L` 선형(모듈과 동일)과 `L` 선형 |

**최종 매핑은 여전히 미결입니다.** 14.8 % 와 44.0 % 의 차이가 그것 하나에서 나옵니다.
표준은 `j → L` 까지만 규정하고, **`L → DDL` 을 어떻게 놓을지는 디스플레이 특성의
문제**입니다. 그래서 **어느 쪽도 "정답" 으로 인용하면 안 됩니다** — 두 수는 규모의
상·하한으로 읽으십시오.
