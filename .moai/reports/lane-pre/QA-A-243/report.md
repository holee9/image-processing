## 3. 옛 기준 영상과의 차이

옛 영상(`m1-baseline/`, SHA-256 `42e78fac…`, 6장 전부의 gain)과 새 영상의 화소 차이, 같은 입력·같은 offset·같은 결함 맵에 gain 만 다르다 (`evidence/20_baseline_v2_stats.txt`).

| | 값 |
|---|---|
| 평균 차이 (새 − 옛) | +7.179 ADU (표준편차 55.332) |
| 평균 절댓값 차이 / 최대 | 40.18 ADU / 650.45 ADU |
| \|차이\| 분위수 | 50% 32.2, 90% 83.5, 99% 153.3, 99.9% 386.1, 99.99% 538.3 ADU |
| 상대 차이 (옛 값 기준, 하한 1 ADU) | 평균 1.81 %, 99% 5.83 %, 최대 21.5 % |
| 1 ADU 넘게 다른 화소 | 96.83 % (10 ADU 넘게 75.8 %, 100 ADU 넘게 4.73 %), 바이트가 같은 화소 9개 |

차이는 대부분 **완만한 기울기**다: 256×256 블록으로 평균한 차이의 표준편차가 49.9 ADU 로, 화소 단위 55.3 ADU 의 분산 중 약 81 % 가 큰 규모 구조다. 12×12 블록 지도에서 왼쪽 위는 −80 ADU 안팎, 오른쪽 아래는 +168 ADU 까지 간다. QA-A-242 가 말한 "gain 의 큰 규모 모양이 조건에 따라 다르다"가 그대로 이 영상 위에서 보인다.

## 4. 알아 둘 것: 실영상의 필드는 평평해지지 않는다

공기 중(팔 바깥) 배경의 256×256 블록 중앙값으로 보면, 보정 뒤에도 배경이 왼쪽 위에서 오른쪽 아래로 **47 % 올라간다** (옛 gain 으로는 34 %, 오프셋만 뺀 원시는 52 %). 평탄 영상 자체는 프레임에서 27 % 변하고 gain 이 그것을 나눠 없앤다. 남은 것은 평탄이 가지고 있지 않은 약 47 % 의 기울기다.

- 이 실영상은 평탄 4·5·6 의 필드와 다른 조건(거리·시준·관구 기하)으로 찍혔거나, 기울기가 물리적(힐 효과, 거리 제곱 감쇠)이다. 어느 쪽인지는 모른다.
- 새 영상(47 %)이 옛 영상(34 %)보다 이 배경을 **덜** 평평하게 만든다. 이는 이 실영상이 4·5·6 조건과 더 가깝다는 뜻이 아니고, 어느 gain 이 맞는지 모른다는 §5 의 한계와 같은 이야기다.
- 2단계(post)가 이 영상을 입력으로 받을 때 배경 기울기를 해부학 구조로 오해하지 않도록 README 의 한계 항목에 적어 두었다.

## 5. 한계 (README 와 같다)

- "평탄 4·5·6 이 한 조건"은 추정이다 (선량·관전압·거리 기록 없음). 평탄 1·2 가 다른 조건이라는 것도 추정이다.
- `wrist_lat` 자체의 촬영 조건을 몰라서 어느 gain 이 맞는지 모른다. 이 영상은 1단계 절차를 실영상에 적용한 결과이지 완벽한 평탄 보정이 아니다.
- 맵은 저장소의 암·평탄 영상에서 제품 생성기로 만든 것이고 운영 맵이 아니다.
- PNG 는 `.gitignore` 의 `*.png` 때문에 저장소에는 없고 공용 폴더에만 있다 (해시는 README 와 여기에 있다). 스크립트(`evidence/baseline_v2.py.txt`)로 `.raw` 에서 다시 만들 수 있다. 다른 환경에서 PNG 바이트가 같게 나오는지는 확인하지 않았으므로 기준은 `.raw` 다.
