## 2. 카드와 다른 점 (먼저 밝힌다)

- 카드: "이미 제외한 목록을 넘길 때는 명시적으로 0 을 준다." C API 의 구조체에서는 0 이 기본값(제외)과 같은 값이라 0 으로는 "제외하지 않음"을 말할 수 없다. 그래서 `skip_first_dark` 에 값 2(`XPE_BPM_V2_SKIP_NONE`)를 두었다: 0(기본)과 1 은 제외, 2 는 제외 없음, 3 이상은 거부. **평가 도구의 명령줄은 카드대로**다: `--skip-first-dark` 를 생략하면 기본(제외), `--skip-first-dark 0` 은 제외 없음(`SKIP_NONE`), `1` 은 제외.
- 카드: 다크 `Dark_07~14` 원시 목록 + 기본 제외. 심은 프레임(`inj_b`)에는 `Dark_08~14` 만 있다(주입이 입력 다크로 `sigma_t` 를 계산하므로 `Dark_07` 을 넣으면 다른 주입이 된다). 그래서 **깨끗한 영상 실행만 원시 목록 + 기본 제외**이고, 심은 영상과 절반 맵 두 개는 이미 자른 목록이라 `--skip-first-dark 0` 으로 넣었다. 두 경우 모두 사용된 다크는 `Dark_08~14` 7 장으로 측정 B 와 같다.
