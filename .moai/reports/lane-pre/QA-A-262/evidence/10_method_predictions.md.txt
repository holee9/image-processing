## 1. 새 오경보 중 밝은 잡음 31 (대조군 위 효율 0.6~0.7 띠 6개: 항목 100, 101, 103, 104, 106, 110)
측정: 계획 프레임(`inj_d`)의 밝은 프레임 18장과 다크 `Dark_08~14` 에서 R1 로 화소별 ratioG(그룹 5개), T, 적중 수를 얻는다. 31 화소는 도구의 "새 오경보" 규칙으로 재현한 집합(`QA-A-260/evidence/64_bright_noise_false_alarms.txt` 와 같은 31)이다.
- **H-edge** (띠 가장자리 화소에 몰림 = 국소 기대의 오염): 예측하는 것 — 켜진 화소가 (i) 띠 끝에서 8화소(17 창의 반) 이내 또는 (ii) 다른 항목·검출기 줄 마스크 화소에서 8화소 이내에 불균형하게 많다. 통계: 같은 항목들의 모든 화소 중 "가장자리 영역" 비율 대 켜진 화소 중 비율, 초기하분포의 정확한 단측 p. **지지 기준**: p < 0.01 이고 켜진 화소의 50 % 이상이 가장자리 영역. 아니면 기각.
- **H-model** (검출기의 배경 모형 ρ = 1 과 띠의 실제 ρ 가 다름): 응답 r 인 띠의 이득 보정 분산은 판독 분산 v0 이 1/r², 양자 잡음 κS 가 1/r 배 되므로 선량 S 에서 기대 ρ_g(r) = (v0/r² + κS_g/r)/(v0 + κS_g). v0·κ 는 배경 화소의 그룹 중앙 분산(ratio 로 나눈 vgBg)을 신호에 선형 적합해 얻고, r 은 항목 화소의 corrGain 중앙값에서(r = corrGain^−1/2) 얻는다. **지지 기준**: 항목마다 그룹별 측정 ρ_g(가장자리 영역을 뺀 항목 화소의 ratioG 중앙값)가 모형 ρ_g 의 ±10 % 안이고 그룹 3개 이상에서 측정 ρ_g > 1.15. 반대 가설(H0: ρ_g = 1)은 측정 ρ_g 중앙값이 1.15 이하일 때 지지.
- **H-tail** (유한 표본 꼬리): 항목마다 몬테카를로 20만 화소에서 ratio_g = ρ_g·χ²(ν_g)/ν_g (ν = 2,2,5,2,2; ρ_g = 측정값, 그룹 독립)를 만들어 도구와 같은 규칙(T > 임계, 적중 ≥ 3)을 적용해 기대 켜짐 수 = 비율 × 항목 화소 수를 구한다. 임계는 χ² 분포 13 자유도에서 목표 오경보 1 개에 해당하는 값(평가 도구의 `chiSquareQuantile` 와 같은 이분법). 비교: (a) ρ_g = 1 로 한 기대(귀무), (b) ρ_g 측정값으로 한 기대, (c) Codex #230 의 항목 집계 비용 ρ 로 한 기대(합 약 15.1). **지지 기준**: (b)의 합이 관측 31 의 0.5~2 배(15.5~62)이면 "ρ_g 모형 + 유한 표본 꼬리가 설명", 2 배 초과(> 62)로 관측이 크면 "추가 요인"(화소 간 이질성·국소 기준의 오차), 0.5 배 미만이면 이 근사가 31 을 설명하지 못함.
- **주변 참조 오차**: 켜진 화소의 국소 기대 ref 를 같은 띠 안 켜지지 않은 화소의 ref 와 비교(상대 편차의 분포), 줄 마스크로 제외된 화소 수.
- 예측(결과 전): H-edge 기각(켜진 화소는 띠를 따라 고르게 퍼진다), H-model 지지(ρ_g 가 1.2~2 사이이고 선량이 높을수록 1/r 쪽으로 오른다), H-tail (b) 의 합이 20~45. 세 가설의 조합("모형 불일치가 확률을 올리고 유한 표본 꼬리가 실제 화소를 켠다")이 가장 가능성이 높다.
- 분류: 모형 불일치가 지지되면 **알고리즘 개선 대상**(검출기 모형이 효율이 낮은 정상 띠의 정상 분산을 모른다), 모형 불일치가 없고 꼬리만이면 **데이터 한계/정의 차이**(목표 오경보 1 개는 ρ = 1 화소에만 보증), 가장자리 오염이면 **알고리즘 개선 대상**(참조 구성).

## 3. 보정 z 후퇴 118/178
측정: 같은 참조(깨끗한 세트)와 같은 화소 집합(truth 의 비대조군 비공유 화소 전체)으로 보정 입력 조합을 바꾼다. 세트 폴더 네 가지:
- A = 1판 세트 파일(1판 지도 + 1판 보정 경로), 참조 = 1판 깨끗한 세트 (QA-A-260 의 `44`)
- B = 2판 세트 파일(2판 지도 + 2판 보정 경로), 참조 = 2판 깨끗한 세트 (`45`)
- B′ = 2판 세트 파일, 참조 = **1판** 깨끗한 세트 → B 대 B′ 는 참조 효과
- C = 2판의 결함 평면을 1판 형식 파일(확장·영역 없음)로 바꾼 것, 참조 = 1판 깨끗한 세트 → B′ 대 C 는 **보정 경로 효과**(같은 지도, 같은 참조), C 대 A 는 **지도 효과**(같은 경로, 같은 참조)
각 쌍에서 "그룹×프레임 중앙값 z 가 더 큰" 수와 종류별(line/pixel/block) 수, 그룹 중앙값 z 의 차 분포를 낸다. 평가 범위(truth 비대조군 비공유 화소 전체)를 보고서에 명시하고, 검출된 화소로만 제한한 값은 R2 가 보정 출력과 지도를 갖고 있으므로 가능하면 함께 낸다.
- 예측(결과 전): 후퇴 118 의 대부분은 line 그룹(111)이고 **보정 경로 효과**(B′ 대 C)가 지도 효과(C 대 A)보다 크다 — 2판의 줄 보간(양옆 선형)이 1판의 이웃 중앙값보다 줄 화소에서 깨끗한 값에 덜 가까울 수 있다. 참조 효과는 작다(깨끗한 2판 세트의 보정 화소 2353 개가 비대조군 항목 화소와 겹치는 정도에 한한다).
- 분류: 경로 효과 우세 → **알고리즘 개선 대상**(보간 방식), 지도 효과 우세 → 검출 지도 차이(검출 범위), 참조 효과 우세 → **정의 차이**(판마다 다른 깨끗한 출력으로 정규화).
