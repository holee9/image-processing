해석: 효율 0.6~0.7 띠의 측정 ρ 는 약 1.4~2.0 으로 1/r(0.6 → 1.67)에 가깝다. 제품은 보정에 1/r² 을 쓰고 기대값은 배경(수직 중앙값이 배경 행 16개를 보므로 단일 행 띠의 ref 는 배경 수준)이라, 양자 잡음이 우세한 신호에서 분산이 1/r 로 남는 띠를 ρ = 1 로 가정한다. 켜진 화소는 띠를 따라 고르게 퍼져 있고(가장자리 몰림 없음) 줄 마스크로 제외된 화소는 0 이다. 켜진 화소의 ref 는 같은 띠 안 안 켜진 화소보다 중앙값 −9 % 낮다(선택 효과일 수 있어 원인으로 단정하지 않는다).
**분류: 알고리즘 개선 대상(배경 모형이 효율이 낮은 정상 띠의 정상 분산을 모른다) — 단 관측 31 중 약 9 개는 (b) 로 설명되지 않는 초과다(포아송 꼬리 p ≈ 0.04).** 고칠 방향(방법만): 기대 분산을 v0/r² + κS/r 형(양자 잡음은 1/r)으로 응답 r 의 함수로 두거나, 기대를 같은 응답 띠 안 화소로 구성한다.
예측 대조: H-edge 기각(맞음), H-model 지지(부분: 6개 중 3개), (b) 20~45(맞음, 21.95).
