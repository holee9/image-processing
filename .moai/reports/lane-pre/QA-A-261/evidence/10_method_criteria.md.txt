[2026-10-17 19:26 KST] QA-A-261 1번 — offset·gain 재점검(측정 진단): 방법과 판정 기준 (결과를 보기 전에 기록)

코드는 바꾸지 않는다. 읽는 것: cyan_test 원시 프레임(`Dark_07~16`, `Bright_17~36`), 지금 생성 도구의 기본 규칙(`Dark_07~14` 전체 입력, 첫 장 한 번 제외)으로 QA-A-260 이 만든 **깨끗한 1판 세트**의 `offset.xcal`·`gain.xcal`·`defect.xcal`(1판 평면)·`manifest.json`. 스크립트는 `30_diagnose.py.txt`(numpy 만 사용) 하나이고, 합성 프레임으로 산술과 분류기를 먼저 시험했다(`31_selftest_result.txt`: 음성 대조 둘은 문제 없음, 항목마다 양성 대조가 자기 항목만 문제로 분류). 실데이터 실행은 이 문서와 스크립트를 커밋한 뒤 한 번 한다.

## 입력과 정의
- 크기 3072×3072, 촬영 영역 = 여백 6,2,1,1(왼 6열, 위 2행, 오른 1열, 아래 1행) 밖을 뺀 안쪽, 유효 화소 = 촬영 영역에서 세트 결함 맵(1판)이 표시한 화소를 뺀 것.
- 쓴 다크 = `manifest.dark_policy.used`(`Dark_08~14` 7장, N=7), 안 쓴 다크 = `Dark_15`, `Dark_16`(평가용), 첫 다크 = `Dark_07`. 게인 프레임 = 세트의 게인 입력 `Bright_23~28`, 같은 선량 평가 프레임 = `Bright_29,30`(평균 신호가 게인 프레임의 2 % 이내인 게인 외 프레임), 다른 선량 = `17~19`(약 13.7k), `20~22`(약 16.6k), `31~33`(약 28.5k), `34~36`(약 38.9k).
- 통제(재현 확인, 분류에 쓰지 않음): 내 평균이 생성 도구의 offset 과 비트 동일(이미 7장에서 확인: 최대 차이 0), 내 게인 재계산이 도구의 gain 과 상대 1e-5 이내.
- 보정 식은 소스 규칙(`offset_correct` 스칼라: 실수 빼기, +0.5, 0 바닥, 65535 천장; 게인은 역수 곱)을 numpy 로 되풀이한 것이다. **라이브러리 함수를 호출해 잰 것이 아니다**(미검증 범위로 보고서에 적는다).

## 항목별 방법과 판정 기준 (문턱은 스크립트 상수와 같다)
**(a) 첫 다크 제외 효과** — 10장 다크의 프레임 평균, 첫 장과 쓴 7장 평균의 차. 쓴 7장 offset(`O7`)과 8장 평균 offset(`O8`)으로 안 쓴 다크 15, 16 에 대해 DarkBias 를 세 변형으로 잰다: V1 = 실수 보정 뒤 원시 프레임의 가장 어두운 10분위(SRS FUNC-035: `raw < percentile10(raw)`) 평균, V2 = 라이브러리 규칙(+0.5, 0 바닥) 뒤 같은 영역 평균, V3 = 유효 영역 전체 평균. IAP 값(첫 장 포함 +14.2/+8.5, 제외 +2.4/−3.4)을 가장 잘 재현하는 변형을 보고한다(재현 허용 ±0.5). 분류는 V1(FUNC-035 규칙 그대로의 변형)으로 한다: `O7` 에서 두 안 쓴 다크 모두 |DarkBias| ≤ 5(FUNC-016)이면 문제 없음, 아니면 문제 있음. `O8` 의 결과는 첫 장 제외가 한계를 지키는 이유인지 보여 주는 근거로 쓴다.

**(b) 다크의 움직이는 행·열 잡음이 offset 맵에 남긴 줄무늬** — 다크 프레임마다 유효 화소만으로 행 평균·열 평균을 내고(프레임 평균을 뺀 뒤) 프레임 사이 표준편차 σ_row, σ_col(한 줄 평균의 시간 잡음)을 구한다. offset 맵의 행·열 프로파일에서 101줄 이동 중앙값을 뺀 줄무늬 진폭(강건 표준편차)과 σ/√N 예측을 나란히 적는다. **분류 지표는 안 쓴 다크 15, 16 을 `O7` 로 보정한 결과의 줄무늬 진폭** ÷ 예측 σ·√(1+1/N) 이다(맵이 새 프레임에 더하는 줄무늬를 직접 본다). 행·열 중 큰 값이 1.5 미만이면 문제 없음, 2.0 이상이면 문제 있음, 그 사이는 판정 불가. (카드의 예시 기준 "D_n 이 σ_row/√N 예측의 2배 이상이면 문제 있음"을 맵 자체가 아니라 보정 결과에 적용한 형태다. 맵에 고정 줄무늬가 있는 것은 정상이며 offset 이 뺄 대상이다.)

**(c) offset 맵 화소 잡음의 √N 감소** — 주 지표(새 프레임 시험): 안 쓴 다크를 `O7` 로 보정한 값(자기 중앙값을 뺀)의 강건 표준편차 ÷ [쓴 7장의 화소별 시간 표준편차 중앙값(프레임 평균을 뺀 값) × √(1+1/N)]; 같은 식을 서로 독립인 가우스 프레임(같은 N)에 적용한 기준값으로 나눈 비. 0.90~1.15 이면 문제 없음, 1.30 초과이면 문제 있음, 그 사이는 판정 불가. 참고 지표(분류에 안 씀): 쓴 다크를 4장과 3장으로 나눈 평균 맵의 차이의 표준편차와 예측, 프레임 평균을 빼기 전과 뒤.

**(d) 게인 맵의 선량 의존성** — 게인에 쓰지 않은 모든 프레임(선량 5개 중 4개 + 같은 선량 29, 30)을 offset 보정(+0.5, 0 바닥) 후 게인으로 나눈 값을 프레임 평균으로 정규화한다. 선량 그룹마다 그룹 평균 영상에서 전역 표준편차/평균, 지역 값(31×31 상자 평균을 뺀 영상의 표준편차/평균, EMVA 1288 4.4 "Highpass Filtering" 과 같은 취지), 그룹 평균에 남은 시간 잡음(화소별 시간 표준편차/√그룹 장 수)을 구하고 제곱 차이의 제곱근을 "구조 잔차"(전역·지역)로 한다(EMVA 1288 4.1·8.1 "Spatial Variances, DSNU, and PRNU" 가 시간 잡음을 따로 빼는 방식과 같은 취지). 구조 전역 잔차가 어느 선량에서든 1.0 %(FUNC-017 FlatResidualPct 한계) 초과이거나, 선량 사이 최대/최소가 2.0 배를 넘으면서 최대가 0.3 % 를 넘으면 문제 있음, 아니면 문제 없음. 그룹 장 수가 1 이면 판정 불가.

**(e) 게인 맵의 움직이는 행·열 잡음 잔여** — (b)와 같은 방식. 게인 프레임의 상대 신호(프레임 평균으로 나눈) 행·열 평균의 시간 잡음 σ_flat 과 다크 참조 쪽 σ_dark/신호를 구하고, 게인 맵 줄무늬 진폭과 √(σ_flat²/6+σ_dark²/7) 예측을 나란히 적는다. **분류 지표는 같은 선량 평가 프레임 29, 30 을 보정한 결과의 줄무늬 진폭** ÷ √(σ_flat²(1+1/6)+σ_dark²/7). (b)와 같은 구간(1.5 미만 문제 없음, 2.0 이상 문제 있음).

**(f) 게인 다크 참조 mean** — manifest 로 참조가 offset 과 같은 7장인지(`dark_policy.used`, `one_list_for_all_stages`, `gain_dark_reference`) 확인하고, 참조(정수 반올림 평균)와 offset(실수 평균)의 차 최대, 참조를 실수 평균으로 바꿨을 때 게인 맵의 상대 변화 최대를 잰다. 1e-3 미만이면 문제 없음, 1e-2 이상이면 문제 있음, 그 사이는 판정 불가.

**(g) 포화·0 근처·게인 범위** — 포화(65535) 화소 수(다크·플랫 프레임별), 게인 프레임에서 순신호 ≤ 0 인 (프레임, 화소) 수, 게인 맵의 비유한 값·0.5 미만·2.0 초과 개수(촬영 영역 안; 결함 맵이 표시한 수와 표시 안 한 수), offset 단계에서 0 과 65535 로 잘린 화소 수. 비유한 값이 하나라도 있거나, 결함 맵이 표시하지 않은 범위 밖 게인이 100 개 초과이거나, 게인 프레임의 포화가 100 개 초과이면 문제 있음, 아니면 문제 없음.

**(h) 반올림** — (h1) 반올림만(`floor(x+0.5)−x`, 잘림 없음)의 분산이 쓴 다크의 화소 시간 분산의 5 % 미만이면 문제 없음. (h2) 0 바닥만의 평균 이동(보정한 안 쓴 다크 평균이 0 바닥 때문에 올라가는 양)이 0.5 이하이면 문제 없음, 초과이면 문제 있음("문제 있음" 은 0 바닥이 설계라는 사실을 부정하는 것이 아니라 암부 평균 측정(DarkBias 의 V2 변형)에 편향을 준다는 뜻이다). 플랫의 반올림 영향은 신호의 ppm 으로 적기만 한다. 최종 출력의 정수화는 보정 파이프라인 끝단 사양에 따르며 이번 항목은 offset 단계 반올림과 게인 나눗셈만 본다.

## 예측 (결과 전)
- (a) 변형 중 하나가 IAP 값을 ±0.5 안에서 재현하고, `O7` 은 두 다크 모두 |DarkBias| ≤ 5, `O8` 은 5 초과: 문제 없음(첫 장 제외가 한계를 지킨다).
- (b) 열은 문제 없음, 행은 확신 없음(공동 조사 P6 가 행 잡음을 지목했다). 행이 1.5 이상이면 이번 진단의 주된 발견이다.
- (c) 문제 없음(0.9~1.15); 프레임 평균 교대(약 5.8)는 (c) 참고 지표의 "빼기 전" 값만 부풀린다.
- (d) 구조 전역 잔차는 모든 선량에서 1.0 % 미만, 선량 사이 비는 2.0 배 안팎이라 경계: 문제 없음 또는 판정 불가.
- (e) (b)의 행과 같은 방향이다(게인 프레임도 같은 검출기의 행 잡음을 가진다).
- (f) 상대 변화 1e-4 안쪽(참조 반올림 ≤ 0.5 를 신호 약 2만으로 나눈 값): 문제 없음.
- (g) 포화 0, 게인 범위 밖은 결함 맵이 표시한 화소가 대부분: 문제 없음.
- (h1) 문제 없음(반올림 분산 1/12 ≈ 0.083 을 시간 분산으로 나누면 1 % 안쪽), (h2) 문제 있음(다크 보정값 평균이 0 근처라 0 바닥이 평균을 약 0.4σ 올린다).

## 범위와 한계 (미리 적는다)
한 검출기·한 세션의 프레임이다. 깨끗한 세트 하나(생성 도구 기본 규칙), 안 쓴 다크는 두 장, 다른 선량마다 3장(29, 30 은 두 장)이다. 측정은 numpy 로 소스 규칙을 되풀이한 것이라 라이브러리 호출과 같다는 직접 확인은 offset 맵(비트 동일)과 gain 맵(상대 1e-5 이내)에 한정된다. 근거 문헌은 EMVA 1288 Release 3.1(RC2 PDF 의 절 제목 4.1·4.2·4.4·8.1 확인, 식 번호는 PDF 본문을 읽지 못함), AAPM Report 150(보고서 존재와 일반 보정 절차만 확인, 절 번호 미확인), IEC 62220-1-1(규격 본문은 접근하지 못했고 오프셋 보정 뒤 잘리지 않은 잡음을 유지해야 한다는 DQE 측정 관행만 2차 자료로 확인).
