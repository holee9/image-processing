## 6. 바꾼 것 (`0eee2ed0`)
1. 채움 거리표(`FillDistance::buildDense`): 밀집 마스크에서 행 안 거리 h 를 구한 뒤 위아래 16행 최솟값(체비쇼프 거리의 분리)을 여러 스레드로 미리 만든다. 래스터 두 번 통과와 같은 값.
2. 채움 루프: 고정 분할 대신 1024 화소 묶음을 공유 계수기로 나눈다. 스레드 수는 그대로.
3. 고리 위·아래 행은 마스크를 16바이트씩 비교해 같은 x 오름차순으로 값을 모은다.
4. 줄 보간이 꺼져 있으면 `done` 표를 만들지 않는다. 마스크 합집합 개수·복사, 마스크 목록, 작업 버퍼 복사, 마지막 복사를 병렬화.
5. `xpe_parallel_chunks` 는 std::thread 대신 std::async 로 범위를 실행. 범위 분할은 그대로.
