# 줄무늬 지표(LineArtifactScore) 조사: 방법과 결론 기준 (결과 없음)

QA-A-241f 3번. 이 파일과 측정 하니스(`A241Measure.DISABLED_B6_StripeInvestigation`)는 **결과를 보기 전에** 커밋한다. 이 조사는 측정만 하고 판정이 아니다: B6 의 `LineArtifactScore` 합격 여부는 정하지 않고, 타일 크기와 비교 영상의 정의를 제안하는 절은 결론과 분리해 따로 쓴다 (정의는 리더가 사용자께 보고한 뒤 사용자가 정한다).

물음: 타일 128 에서 gain 보정 뒤 점수가 gain 전보다 1.58~1.73 배가 되는 것(241e)이 (가) 보정이 만든 **실제 줄무늬**인가, (나) gain 보정이 큰 규모 음영을 평평하게 만들어 분모(`std(tile_mean)`)가 줄어든 **지표의 성질**인가.

## 대상과 입력

241e 와 같다: 평탄 4·5·6 중 두 장으로 만든 gain 을 남은 한 장에 적용(세 조합), 출하 경로 `xpe_preprocess_pipeline_out`, 같은 offset·결함 맵·설정, 주 대상은 평탄 6 이고 4·5 도 같은 표를 낸다.

영상 네 가지 (모두 같은 원시 프레임에서):
- `최종`: 출하 경로 전체 (offset, gain, 결함 보정).
- `gain 우회`: `bypassGain` 만 켠 것 (offset 과 결함 보정은 함). 241e 의 판정용 비교 영상.
- `offset 만`: `bypassGain` 과 `bypassDefect` 를 켠 것 (결함 보정도 안 함). 241e 에서 평탄 4 가 3.58 이 된 비교 영상.
- `offset 만 · 결함 화소 제외`: `offset 만` 영상을 결함 맵(BPMap) 화소를 ROI 에서 뺀 채로 잰 것. "결함 화소를 같은 방식으로 처리한 경우" 이다.

ROI 두 가지:
- `A`: §5.3 ROI (gain 값이 유한하고 0 초과인 모든 화소). 241e 와 같다.
- `B`: `A` 에서 결함 맵 화소를 뺀 것. 네 영상 모두에 같은 `B` 를 적용한다 (영상마다 ROI 가 달라지지 않는다).

## 측정하는 것 (식은 241e 하니스의 `lineArtifactScore` 와 같은 정의: ROI 화소만의 모집단 표준편차, 겹치지 않는 타일, 화소가 없는 행·열·타일은 뺌)

1. **타일 16·32·64·128·256** 각각에서, 영상 네 개 × ROI 두 개에 대해 분자와 분모를 **따로**:
   - `std(row_mean)`, `std(col_mean)` (타일과 무관, 같은 값이 5개 타일 열에 반복), 분자 = 둘 중 큰 값
   - `std(tile_mean)` (분모), 타일 수
   - 점수 = 분자 / 분모
   - 비 = 최종의 점수 / 비교 영상의 점수, 그리고 "분자 비" (최종 분자 / 비교 분자)와 "분모 비" (최종 분모 / 비교 분모). 점수 비 = 분자 비 / 분모 비 이다. 점수 비가 1 을 넘는 이유가 분자가 커져서인지(분자 비 > 1), 분모가 작아져서인지(분모 비 < 1) 여기서 갈린다.
2. **행 평균·열 평균 프로파일 자체** (ROI `A`, 영상 `최종`·`gain 우회`): 3072 개 값을 텍스트로 저장하고, 보고서는 48 구간으로 줄인 텍스트 막대 그림과 요약(전체 std, 선형 추세를 뺀 std, 최대 편차)을 쓴다. 그림 파일(PNG)은 저장소에서 무시되므로 쓰지 않는다.
3. **잡음 기대값 대비 초과**: 화소 잡음 σ 를 이웃 화소 차이로 추정(`σ = std(x[i]−x[i+1])/√2`, 가로 이웃 쌍이 둘 다 ROI 인 쌍)하고, 행 평균이 순수 백색 잡음이라면 `σ/√(행의 ROI 화소 수 평균)`, 열도 같다. 행·열 평균의 **고주파 성분**(자기 값에서 중심 33칸 이동 평균을 뺀 것)의 std 를 이 기대값으로 나눈 "잡음 대비 비" 를 `최종`·`gain 우회`·`offset 만 · 결함 제외` 에서 낸다. 1 근처면 행·열 평균이 화소 잡음만으로 설명되고, 1 보다 훨씬 크면 행 또는 열 단위 구조(줄무늬)가 있다.
4. **대조군 두 개** (같은 크기 3072×3072, 평균 2000, σ 는 평탄 6 `최종` 영상의 추정 σ):
   - 대조군 1: 백색 잡음만 (줄무늬 없음). 같은 코드가 타일 크기별로 점수를 어떻게 내는지 본다. 순수 백색 잡음의 기대 점수는 행 평균 std σ/√3072 를 타일 평균 std σ/타일 로 나눈 값 = 타일/55.4 로 타일 크기에 비례해 커진다 (이 값과 맞는지 확인).
   - 대조군 2: 대조군 1 에 행마다 독립인 오프셋을 더한 것 (std = 3 × σ/√3072, 즉 잡음 기대값의 3 배인 행 줄무늬). 분자가 실제 줄무늬를 잡아내는지(양성 대조군) 본다.
   - 하니스는 대조군 1 의 점수가 기대값(타일/55.4)에서 표본 오차의 3 배 안이고(n 개 표본의 표준편차의 상대 오차는 약 1/√(2(n−1)) 이고 점수는 행 3072 개와 타일 수 개의 두 표준편차의 비라서 허용 오차는 3·√(1/(2·3071) + 1/(2·(타일 수−1))), 타일 256 은 타일이 144 개라 약 ±18 %, 타일 16 은 약 ±3 %), 대조군 2 의 분자가 대조군 1 의 약 3 배(2.5~3.5)일 때만 나머지 결과를 쓴다. 아니면 측정 도구가 틀린 것이다.

## 결론 기준 (결과를 보기 전에 정한다. 이 문턱값은 이 문서의 선택이다)

타일 128, 평탄 6, ROI `A`, 비교 영상 `gain 우회` 에서 (평탄 4·5 는 같은 기준으로 보고하되 결론은 평탄 6 으로 적는다):

- **"128 초과는 실제 줄무늬"**: 분자 비 ≥ 1.2 (보정 뒤 행·열 평균의 퍼짐이 20 % 넘게 커졌다) **그리고** `최종` 의 행 또는 열 고주파 성분의 잡음 대비 비 ≥ 1.5.
- **"지표의 성질"**: 분자 비가 0.9~1.1 (분자가 거의 그대로) **그리고** 분모 비 < 0.8 (분모가 20 % 넘게 줄었다) **그리고** 대조군 1 이 타일 크기에 비례하는 점수를 낸다 **그리고** `최종` 의 행·열 고주파 성분의 잡음 대비 비 < 1.5.
- 둘 다 아니거나 서로 다른 신호가 섞이면 **"판정 불가"** 로 적고 어느 쪽 근거가 모자란지 쓴다.

예측 (결과 전): 지표의 성질일 가능성이 높다. 근거: 화소 잡음만 있는 영상의 점수는 타일 크기에 비례하고(타일 128 이면 약 2.3), gain 전 영상은 큰 규모 음영(평탄 영상의 약 27 %)이 타일 평균의 퍼짐을 키워 분모를 크게 만든다. 확신은 없다 (gain 보정이 행·열 구조를 만들었을 수도 있다).

## 하지 않는 것

- 합격·불합격 판정, 타일 크기나 비교 영상 정의의 선택. 제안은 결론과 분리된 절에만, "제안" 이라는 이름으로, 사용자가 정한다는 단서와 함께 적는다.
- 241e 의 판정 수치를 바꾸지 않는다 (이 조사는 같은 입력에서 다른 것을 잴 뿐이다).
