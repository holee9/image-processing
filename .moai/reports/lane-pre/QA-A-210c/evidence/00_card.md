# QA-A-210c — 다항식 게인: 끝점 직선을 없애고 최종 대체를 1차 최소제곱으로 (리더 결정, #233)

보낸이: xpe-leader · 근거: QA-A-210(합성) + QA-A-210b(cyan_test 실데이터, `cf03f5b9`). 순서는 먼저 이 카드, 204c·209c 는 Codex #56 으로 보낸다(지금 gui 검토 중).

순서를 바꿔 210b 를 먼저 커밋한 것은 괜찮다 — 측정 카드였고 결과가 이 결정을 가능하게 했다.

## 실데이터가 보인 것

- 끝점 직선 갈래 48.9%(선량 축과 무관), 그 화소 전부 1차 기울기 음수, 풀드 R² −0.035 / +0.048(축에 따라)
- 그 "감소"의 크기(중앙값 3.2e-3)가 준위 간 흩어짐(2.9e-3)과 같다 — 데이터는 그 화소들에서 선량에 따른 감소가 아니라 **평평함 + 흩어짐**을 말한다
- 끝점 직선은 최소제곱해가 아니고 생성기 자신의 비감소 검사도 통과하지 못한다(SRS-CALIB-FUNC-027 의 단조 보장이 거짓인 갈래)

## 리더 결정: A (방향 무관 단조 + 최종 대체는 1차 최소제곱, 끝점 직선 폐기)

비감소를 강제할 물리적 근거가 데이터에 없다: 음의 기울기는 잡음 크기이고, 1차 최소제곱은 그 화소에서 거의 0 의 기울기를 낸다. 1차 함수는 방향과 무관하게 단조이므로 SRS 의 "monotone" 문구를 만족한다(SRS 는 방향을 정하지 않음 — 210 에서 확인). B(감소를 위반으로 처리)는 잡음을 결함으로 표시하게 된다.

1. 차수 줄임의 단조 검사를 **방향 무관**(비감소 또는 비증가)으로, 1차에서 멈출 때는 **1차 최소제곱해**를 저장. 끝점 직선 갈래 삭제
2. 시험: 합성 픽스처(210)와 실데이터 축소본(cyan_test 에서 작은 영역을 잘라 쓸 수 있으면) 모두에서 화소별 R² ≥ 0 (최소제곱 정의상 — 단언), 저장된 모든 다항식이 측정 선량 범위에서 단조(방향 무관), 이전에 2차 이상으로 채택되던 화소의 결과는 비트 동일. 반증: 끝점 갈래를 되살리면 R² ≥ 0 단언 빨강, 방향 검사를 비감소로 되돌리면 1차 채택 비율 시험 빨강
3. 실데이터에서 전/후: 갈래 비율, 풀드 R², 화소별 R² < 0 비율(0 이어야 함). `calibration_pass`(R² ≥ 0.999)는 여전히 0 일 것이다 — 그 사실을 보고하고 **게이트는 바꾸지 말 것**(이 데이터로 다항식 게인이 품질 게이트를 통과 못 하는 것은 별개 문제, 리더가 #233 에 기록)
4. `XPE_WARN_CALIB_POOR_FIT` 문구("increase dose levels or check detector stability")가 이 상황(입력이 평평함)에 맞지 않는다는 210 의 지적: 문구를 원인 중립적으로(예: R² 값과 "fit explains little of the per-level variation") 바꿀지는 레인 간 계약이라 **바꾸지 말고** 제안 문구만 보고서에
5. SRS-CALIB-FUNC-027 · REQ 문서에 "단조(방향 무관), 최종 대체 1차 최소제곱" 이 이미 쓰여 있는지 확인하고, 다르면 필요한 문안을 보고서에(문서 수정은 리더)
