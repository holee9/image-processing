### F339-1 — C2 를 식으로 닫음
- D_n = P_item − (P_before + P_after)/2 은 화소값의 선형결합이다: 대상 줄 k개×길이 L 의 화소에 가중 +1/(kL), 앞 줄·뒤 줄(각 L 화소)에 가중 −1/(2L). 이 가중 벡터를 w 라 하면 **Var(D_n) = wᵀΣw = Σ_i Σ_j w_i w_j C(x_i − x_j, y_i − y_j)**, σ_C2 = √Var(D_n).
- C(dx, dy) 는 같은 프레임 잔차의 2차원 자기공분산이다. 추정 방법(고정): e = S − 행평균 − 열평균 + 전체평균 을 ROI(여백 6,2,1,1) 안에서 계산하되, 2절의 제외 줄(정답 줄·결함 맵 줄 마스크 ±3)과 결함 맵 화소를 뺀 위치들만 쓴다. |dx| ≤ 3, |dy| ≤ 3 의 49칸을 표본 평균으로 추정하고, 그 밖은 0 으로 둔다. v = C(0,0).
- 방향(행 줄/열 줄), 두께 k, 길이 L 은 w 의 모양으로 들어간다. 영역: C 는 ROI 전체 한 개로 추정한다(영역별 C 는 쓰지 않는다).

### F339-4 — 주입 진폭을 후보와 무관한 공통 화소값으로 한정
