# QA-A-252 — 화소 결함 검출 2판: 알고리즘 정의와 측정 방법 (구현·측정 전에 고정, 먼저 커밋)

## 2. 알고리즘 (`xpe_bpm_generate_v2`)

입력은 1판과 같다: 다크 프레임(uint16, 오프셋 보정 전), 밝은 영상 프레임(uint16). 밝은 영상은 선량이 섞여 있어도 된다.

### 2.1 준비

- 다크: `skip_first_dark` (기본 1) 이 켜져 있으면 주어진 첫 프레임을 쓰지 않는다 (안정화 전). 남은 다크 수 `nd` 는 `min_frames_dark` (기본 5) 이상이어야 한다. 다크 평균 `D`.
- 선량 묶음: 밝은 영상 프레임마다 신호 = 프레임 평균 − 전체 다크 평균. 신호 순으로 정렬해 이웃 비가 `dose_group_ratio` (기본 1.25) 를 넘으면 새 묶음. 묶음 수 `G` 는 최대 8. 묶음 신호 `S_g` = 묶음에 속한 프레임들의 신호 평균. 묶음마다 화소별 순신호 `n_g = (묶음 프레임 평균) − D`.
- 모든 연산은 `float` 또는 `double` 로 하고 프레임을 하나씩 읽어 누적한다. 입력은 바꾸지 않는다.

### 2.2 특성 5개

| 번호 | 특성 | 정의 | 판정 |
|---|---|---|---|
| F1 | 다크 평균 편차 | 특성 영상 = `D` | 강건 z, 양쪽 |
| F2 | 다크 시간 잡음 | 프레임마다 (프레임 − D) 에서 그 프레임의 행 평균을 뺀 값 `e_f`, 화소별 분산 `s² = Σ e_f² / (nd − 1)` | 국소 중앙값에 대한 분산비, 위쪽 |
| F3a | 선량 응답 기울기 | 화소별로 `n_g = a·S_g + b` 를 묶음 `G ≥ 2` 개에 최소제곱 맞춤, 특성 영상 = `a` | 강건 z, 양쪽 |
| F3b | 선량 응답 직선성 | 같은 맞춤의 잔차 `e² = SSE / (G − 2)` (`G ≥ 3` 일 때만) | 국소 중앙값에 대한 분산비, 위쪽 |
| F4 | 평탄 편차 | 특성 영상 = `Σ_g n_g / Σ_g S_g` (밝은 영상의 상대 응답) | 강건 z, 양쪽 |

묶음이 1개면 F3a·F3b 는 쓰지 않고 F1·F2·F4 만, 2개면 F3b 만 뺀다.

### 2.3 강건 z (F1, F3a, F4)

1. 특성 영상 `F` 에서 행 성분과 열 성분을 뺀다: 행마다 중앙값을 빼고, 그 결과에서 열마다 중앙값을 뺀다. 이렇게 해서 offset·gain 으로 사라지는 줄무늬(고정 띠, 이득 띠)가 화소 결함으로 번지지 않게 한다. 전체 라인 결함도 같이 사라진다 (라인은 QA-A-253).
2. 국소 배경 = 창 `window` (기본 17, 홀수) 의 분리형 중앙값: 가로로 17칸 중앙값, 그 결과를 세로로 17칸 중앙값. 가장자리는 반사로 채운다. 창이 17 이라 한 변 8 화소 이하의 덩어리는 배경에 섞이지 않는다.
3. 잔차 `r = F − 배경`. 국소 척도 = `sigma_block` (기본 64) 화소 블록마다 `1.4826 · median(|r|)` 을 구하고, 블록 중심 사이를 쌍선형으로 보간한 값 `σ(x,y)` (아래로 `1e-6` 으로 자름).
4. `z = r / σ`. 결함 = `|z| > λ`.

### 2.4 분산비 (F2, F3b)

1. 특성 영상 `V` (F2 는 `s²`, F3b 는 `e²`).
2. 국소 기준 `R` = `V` 의 같은 분리형 중앙값 / `m_ν`, `m_ν` = 자유도 `ν` 인 카이제곱 변수를 `ν` 로 나눈 값의 중앙값 (영가설에서 `V/R` 이 `χ²_ν/ν` 를 따르게 하는 보정). F2 는 `ν = nd − 1`, F3b 는 `ν = G − 2`.
3. `t = V / R`. 결함 = `t > τ`.

### 2.5 임계값: 목표 오경보 수에서

화소 수 `N`, 특성마다 목표 오경보 수 `T` (기본 1.0) 에서 정한다. 영가설 아래 한 화소가 걸릴 확률이 `T/N` 이 되도록:

- 양쪽 z: `erfc(λ / √2) = T / N` 을 만족하는 `λ` (N = 9437184, T = 1 이면 λ ≈ 5.32).
- 분산비: 카이제곱 위쪽 꼬리 `P(χ²_ν/ν > τ) = T/N` 을 만족하는 `τ` (이분법으로 구함).

임계값과 그 근거(`N`, `T`, `ν`, 사용한 자유도, 특성마다 걸린 화소 수, 국소 척도의 중앙값)는 함수의 보고서 구조체로 돌려주고, 평가 도구가 JSON 으로 남긴다. 임계값은 데이터를 보고 조정하지 않는다. 영가설이 가우스·카이제곱이라는 가정이 데이터에서 안 맞으면 걸린 화소 수가 목표보다 많이 나오고, 그 차이를 보고서에 그대로 적는다.

### 2.6 결과

특성 중 하나라도 걸리면 결함 (합집합). 출력 맵 코드: 밝은 영상 쪽 특성(F3a, F3b, F4)만 걸리면 1, 다크 쪽 특성(F1, F2)만 걸리면 2, 양쪽이면 3 (1판 코드와 같은 자리). 선택 출력으로 화소마다 어느 특성이 걸렸는지 나타내는 비트 맵 (F1 = 1, F2 = 2, F3a = 4, F3b = 8, F4 = 16).

### 2.7 입력 검사

다크 부족, 밝은 영상 `min_frames_bright` (기본 6) 미만, 크기 불일치, 형식이 uint16 이 아님, 신호가 0 이하인 밝은 프레임, 묶음 9개 이상 → `XPE_ERR_INVALID_INPUT` (또는 형식은 `XPE_ERR_UNSUPPORTED_FORMAT`). 출력 버퍼가 uint8 이 아니거나 작으면 1판과 같은 오류.

## 3. 측정 (QA-A-251 과 같은 입력·주입·시드)

## 4. 단위 시험 계획

작은 합성 프레임에서: 임계값 공식 (`λ` 가 `erfc` 로 되돌려 목표 오경보 수가 됨), 깨끗한 프레임의 오경보 수, 심은 결함의 검출 (hot, dead, slope, noisy), 고정 띠·이득 띠가 걸리지 않음, 첫 다크 건너뛰기, 입력 검사, 같은 입력에서 같은 출력. 반증은 시험마다 변형 1건 이상.

## 5. 실행 범위

단위 시험과 위 측정 한 번. 한 번에 하나, 각 실행 뒤 남은 프로세스 0. 전체 스위트는 돌리지 않는다. push 하지 않는다.

## 6. 변경 (2026-10-16, 검출기를 측정하기 전에 기록)

F3b (선량 응답 직선성) 의 판정을 2.4 의 카이제곱 분산비에서 **로그 잔차 분산의 단측 강건 z** 로 바꾼다.

- 새 정의: 특성 영상 `L = ln(SSE / (G − 2))` 를 2.3 의 절차(행·열 성분 제거, 분리형 중앙값 배경, 블록 강건 척도)로 z 로 만들고 **위쪽만**(`z > λ`) 결함으로 본다. 임계값은 2.5 의 단측 가우스 꼬리 `P(z > λ) = T / N` 에서 구한다 (양쪽 `erfc` 가 아니라 `erfc(λ/√2)/2`).
- 이유: 선량 묶음 평균의 잡음이 묶음마다 다르면 가중하지 않은 잔차가 카이제곱을 따르지 않는다. 단위 시험의 합성 프레임에서 카이제곱 형태는 목표 1 개 대신 17~18 개를 걸었고, z 형태는 0 개였다. 이 근거는 합성 프레임에서만 얻었고 평가 데이터(cyan_test)에서는 보지 않았다.
- 바뀌지 않는 것: F1, F2, F3a, F4 의 정의, 임계값 원칙(목표 오경보 수에서 정하고 데이터를 보고 조정하지 않음), 3절의 측정 방법과 예측.
- 측정 시점: 이 변경은 검출기 측정 전에 기록하며, 2판 측정은 리더가 B16 합격 수치를 다시 고정했다고 알린 뒤에만 한다.

## 7. 변경 (2026-10-16, QA-A-252b, 재측정 전에 기록)

QA-A-252 의 첫 측정이 B16 기준을 못 맞춘 원인을 진단한 뒤(`.moai/reports/lane-pre/QA-A-252b/report.md`) 리더가 승인한 개정을 이 문서의 §2.3·§2.4·§2.5 에 반영한다. 개정안 전문과 예측은 `.moai/reports/lane-pre/QA-A-252b/evidence/70_method_revision_proposal.md` 다.

- **R1 행·열 성분:** 행 성분은 행과 위아래 `window` 줄 중앙값의 차이의 중앙값, 열 성분은 좌우 `window` 칸 중앙값과의 차이의 중앙값(§2.3 1단계 대체). 새 상수 없음.
- **R2 곱셈형 성분(조건부 승인, 합성 프레임 관문 통과):** 선량 기울기(F3a)와 평탄 편차(F4)는 차이 대신 비의 중앙값으로 성분을 뺀다. 관문 시험 `AGainBandIsRemovedEvenWhenTheGainAlsoChangesAlongTheColumn` 이 가산형에서 빨강(띠 위 131 개), 곱셈형에서 초록.
- **R3 다크 잡음:** 프레임마다 행 평균을 뺀 잔차에서 열 평균도 뺀다(§2.2 F2).
- **R4 밝은 영상 잡음 특성(F2b, 승인):** 같은 선량 묶음(2 장 이상)의 화소별 시간 분산을 §2.4 와 같은 절차(국소 중앙값 기준 분산비)로 구하고 묶음들을 자유도 합 `Σ(m_g − 1)` 의 카이제곱으로 합친다. 새 비트 `XPE_BPM_V2_FEATURE_BRIGHT_NOISE = 0x20`, 특성 개수 5 → 6, 출력 맵 코드 1(밝은 영상 쪽).
- **④ 임계값:** 유지(목표 오경보 수에서 계산, T-A). 가장자리(②)는 처음 넣지 않기로 했다가 사용자 결정(2026-10-16 19:00, main `3fb1cf70`)으로 **촬영 영역 밖 줄 제외**로 바뀌었다: 열 0~5, 행 0~1, 열 3071, 행 3071 은 결함 판정과 국소 통계에서 모두 빠지고 맵에는 코드 4(촬영 영역 밖)로 남는다. 개정안 전문과 예측은 `70_method_revision_proposal.md` §8.
- 평가 데이터 점수를 보고 정한 상수는 없다.
