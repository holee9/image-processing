"""QA-A-252g step 2 (Codex #214 findings 3, 6 and the acceptance items 4, 5, 7): the truth path (the noise-cost command) takes the exposure variation out too, with its OWN implementation (it shares
no code with the detector), and its interval no longer treats pixels x degrees of freedom as independent.

Normalisation: the net signal (frame minus the dark level D) of every verification frame is multiplied by f_k = S_ref / S_k, S_k the global dose of the frame = the MEDIAN of its net signal over the
unplanted interior pixels (planted items and 3 pixels around them are left out, so a defect cannot pull it), S_ref the mean of the S_k. Order: scale, then the deviation about the mean of the
scaled frames, then the row and column means of every frame out. The scale is one number per frame, estimated from about 10^6 pixels (relative error ~1e-3 of the dose, a negligible variance
of the variance); the per-pixel degrees of freedom stay frames - 1 (a pair of frames: the variance is (x1 - x2)^2 / 2, nu = 1). --raw-frames switches the scaling off (the labels of QA-A-252f).
Interval: the pixel costs of an item, in the order of the pixels along it, are cut into blocks of 64 consecutive pixels; the variance of the block means gives the effective degrees of freedom
2 c^2 / se^2 of the item mean (se^2 = variance of the block means / blocks); the interval uses the smaller of that and pixels x nu. The lag-1 autocorrelation is reported. The labels stay
PROVISIONAL (status column, console, score) until the spatial correlation is checked against an independent replicate."""

add = r'''/** The mean of the per-pixel variance ratios of an item, the lag-1 autocorrelation along its pixels and the effective degrees of freedom of the mean from blocks of consecutive pixels (0 = not determinable). */
struct BlockDof {
    double mean{0}, lag1{0}, dofEff{0};
    size_t blocks{0};
};

inline BlockDof blockEffectiveDof(const std::vector<double>& c, size_t block) {
    BlockDof r;
    const size_t n = c.size();
    if (n == 0 || block == 0) return r;
    double s = 0.0;
    for (double v : c) s += v;
    r.mean = s / static_cast<double>(n);
    double num = 0.0, den = 0.0;
    for (size_t i = 0; i < n; ++i) den += (c[i] - r.mean) * (c[i] - r.mean);
    for (size_t i = 0; i + 1 < n; ++i) num += (c[i] - r.mean) * (c[i + 1] - r.mean);
    r.lag1 = den > 0.0 ? num / den : 0.0;
    const size_t nb = n / block;
    r.blocks = nb;
    if (nb < 4) return r;
    std::vector<double> bm(nb, 0.0);
    for (size_t j = 0; j < nb; ++j) {
        for (size_t i = j * block; i < (j + 1) * block; ++i) bm[j] += c[i];
        bm[j] /= static_cast<double>(block);
    }
    double mb = 0.0;
    for (double v : bm) mb += v;
    mb /= static_cast<double>(nb);
    double vb = 0.0;
    for (double v : bm) vb += (v - mb) * (v - mb);
    vb /= static_cast<double>(nb - 1);
    const double se2 = vb / static_cast<double>(nb);
    r.dofEff = se2 > 0.0 ? 2.0 * mb * mb / se2 : 0.0;
    return r;
}

'''
