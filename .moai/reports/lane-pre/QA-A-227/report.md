## 2. 원인 위치와 경계가 들어온 이유

수정 전 코드(`ghost_correct.cpp`, 티어 3 루프):

```cpp
if (W >= 3u && H >= 3u) {
    const uint32_t x = static_cast<uint32_t>(i % W);
    const uint32_t y = static_cast<uint32_t>(i / W);
    if (x > 0u && x < W - 1u && y > 0u && y < H - 1u) {      // <- 여덟 이웃이 모두 있는 화소만
        ... 3x3 평균 (인덱스 (y+dy)*W + (x+dx)) ...
        corrected = mixKeep * corrected + mixLocal * localMean;
    }
}
```

- 바깥 가드 `W >= 3 && H >= 3`는 "3×3 이 성립하지 않는 작은 프레임"을, 안쪽 가드가 테두리를 뺀다.
- `git blame`/`git log -S`: 안쪽 가드는 **`31d38a57`(2026-04-19, "Ghost Correction 고도화")**에서 3×3 혼합과 함께 들어왔다. 그 앞의 `ee2c6077`(2026-04-16)에는 이 블록이 없다. `fdbdaed5`·`cfd02ae2`(CI 경고 수정)는 자료형만 바꿨고, `7e2da41b`(QA-A-218b)는 이웃 평균이 읽는 배열만 바꿨다.
- **의도였는지**: 커밋 메시지(핵심 변경 목록)에도, SRS·검증 가이드에도 테두리를 뺀다는 근거가 없다. 검증 가이드는 티어 3 을 "신호-의존 계수 + 3×3 공간 컨텍스트 혼합"이라고만 적고 테두리 예외를 두지 않았다. 코드에서 읽히는 이유는 인덱스 계산이다: `(y+dy)*W + (x+dx)`가 `x = 0` 에서 앞 행의 끝으로, `x = W−1` 에서 다음 행의 처음으로 되감긴다. 가드는 그 되감김을 피하는 **안전장치**로 읽힌다(추론이며 작성자에게 확인하지 않았다).

## 3. 수정

- 안쪽 가드를 없애고, 이웃을 `dy`, `dx` 루프에서 **프레임 안에 있는 것만** 센다(`yy`, `xx` 범위 검사). 평균은 기존처럼 센 개수로 나눈다. 인덱스 되감김이 없어졌다.
- **관례 선택**: 모듈에는 두 가지가 있다. 결함 보정 단계는 "유효한 이웃만"(창이 줄어듦), 실행 중 검출(`xpe_calib_runtime_detect` 계열 문서)은 "반사 패딩"이다. 이 루프가 이미 `count`로 나누는 구조(비유한 값을 건너뛰는 것)와 같은 쪽이어서 "유효한 이웃"을 택했다. 반사 패딩이 더 맞다고 보면 이 한 곳만 바꾸면 된다.
- 바꾸지 않은 것: 혼합 비중(0.7:0.3), 3×3 미만 프레임의 무혼합, 티어 1·2, 이력·시각·알림 동작.
- 헤더 문서에 티어 3 의 규칙을 적었다(`xpe_ghost_correct`).

## 4. 시험과 반증

**빨강 먼저**(`evidence/07_red_first_run.txt`): 수정 전 코드에서 새 시험 2건과 갱신한 기준 공식 1건이 실패하고 대조군(티어 1·2 구조, 주사 방향 독립)은 통과했다. 실패 크기: 3×3, 4×4, 5×7, 7×5, 9×9, 16×16, 3×16, 16×3 모두에서 같은 0.3×(원본−테두리) 단차(예: 최대 508.9 ADU)였고 2×2·1×1·2×9·9×2 는 원래 혼합 대상이 아니라 통과.

| 시험 | 고정하는 것 |
|---|---|
| `AUniformFrameComesOutUniformAtEverySize` | 균일 프레임이 **모든 크기**(최소 3×3, 홀수 5×7·7×5·9×9, 가늘고 긴 3×16·16×3, 혼합 대상이 아닌 2×2·1×1·2×9·9×2)에서 균일(최대−최소 0.01 ADU 미만) |
| `EveryPixelFollowsTheBlendOverTheNeighboursThatExist` | 같은 크기들에서 **모든 화소**가 독립 유도(double, 존재하는 이웃 평균)와 0.05 ADU 이내로 일치. 3×3 미만은 무혼합 |
| `ATierOneOrTwoFrameIsNotBlendedAnywhere` | 티어 1·2 는 이웃을 읽지 않음(공간 순서를 뒤집어도 같은 화소별 결과) |
| (갱신) `TheOutputIsTheTierThreeFormula…` | 기준 공식이 테두리 혼합을 포함하도록 갱신. 수정 전에는 이 갱신만으로 빨강 |
| (갱신, M4) `TheBlendLeavesNoRing…` | 결함 자체를 고정하던 M4 의 단차 시험을 "균일 프레임은 균일이고 혼합 출력 = 0.7×혼합없음 + 0.3×원본"으로 바꿈 |
