## 2. 시험 (15건)
`modules/preprocess/tests/test_verify_offset_signed.cpp`. 기대값은 라이브러리와 코드를 공유하지 않는 기준 구현(정렬한 사본으로 백분위, 순수 double 통계)으로 계산한다.
- 음의 bias(−4)가 UINT16 출력에서는 0 으로 보이는 경우, 혼합 프레임 기준 대조, 히스토그램 백분위 = 정렬 사본(크기 4종 × 퍼짐 3종, 동점 포함)
- 클램프율·0 출력율 경계(x = −1, 0, 0.25, 0.5, 1 및 반반), ROI 없음·변동 없음에서도 프레임 전체 비율은 유효
- 부등식은 성립하는 것만: **T-A** `m_c ≥ signed`, **T-B** `|output − m_c| ≤ 0.5`, **T-D** 정수 잔차에서 output = m_c ≥ signed, **T-E** 정규 잔차에서 클램프 상승량이 정규 공식과 일치(허용 0.08σ). **T-C** 반례(잔차 +0.2 → 출력 0 < signed 0.2)는 *성립하지 않음*을 단언한다
- 맵 SHA·크기, 구조체 크기 10종, 오류표 전 행, 두 스레드가 다른 맵으로 섞이지 않음, 파일 변형 = 버퍼 변형(만료 지난 파일 포함), 손상된 파일은 읽기 실패, 옛 함수와 비트 동일(경계 잔차 −0.5…2.5 포함)
- 결과: 15 passed. 기존 검증 함수 시험 64건도 그대로 통과.
