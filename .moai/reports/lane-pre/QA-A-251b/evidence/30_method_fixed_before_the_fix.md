# QA-A-251b — 평가 도구 수정 정의와 새 시험의 예측 (수정·재측정 전에 고정, 먼저 커밋)

이슈 #273. 근거: Codex #204 (lead `.moai/state/codex-archive/204.md`)와 카드 `QA-A-251b` 의 리더 결정 세 가지. 리더가 QA-A-251 의 통과 판정을 철회했다. 이 문서는 수정 방법과 재측정에서 바뀔 값의 예측을 수정 전에 적는다. `b180ba01` 의 정의서(§3)는 아래 항목만 바뀌고 나머지는 그대로다.

## 1. 수정 정의

| # | Codex | 수정 후 정의 |
|---|---|---|
| 1 | 발견 1 | **계산할 수 없는 값은 0 으로 쓰지 않는다.** 보정 오차 z 의 표본은 분모(깨끗한 출력의 11×11 국소 표준편차)가 0 이거나 세 출력(C, I, U) 중 쓰는 값이 유한하지 않으면 **무효**. 무효 사유 셋: `zero_sigma_equal` (분모 0, 분자 0: 0/0), `zero_sigma_error` (분모 0, 분자 ≠ 0: 실제 오차가 있는데 잴 수 없음), `nonfinite` (값이 유한하지 않음). 보정 켬(I)과 보정 끔(U)을 따로 집계한다 (한쪽만 무효면 다른 쪽은 버리지 않는다). 그룹의 유효 표본이 0 이면 수치(중앙값·95 백분위) 대신 JSON 에 `"uncomputable"` 을 쓰고 B16 판정에서는 불합격으로 친다. D_n 도 같다: 부분의 D 가 유한하지 않거나 예측 표준편차가 0 이하이거나 유한하지 않으면 그 부분은 `"uncomputable"` (비 대신), 초과 개수에 넣지 않고 따로 센다 |
| 2 | 발견 2 | **D_n 분모는 정의서 §3.6 대로**: σ_pix = (앞 이웃 라인 차분 잔차의 **표준편차**) / √1.5. 표준편차는 표본 표준편차 (n − 1 로 나눔; n ≥ 760 이라 모집단 표준편차와 차이는 0.07 % 이하). 예측 표준편차 = σ_pix · √(1/(kL) + 1/(2L)). MAD 기반 값 (1.4826 · MAD / √1.5)은 **보조 열**로만 쓰고 (`ratio_*_mad`) 판정·초과 개수에 쓰지 않는다 |
| 3 | 발견 3 | **참 결함 마스크와 대조군 마스크를 분리한다.** 새 오경보 = 심은 실행의 맵에서 결함이고, 깨끗한 맵에서는 아니고, **참 결함(대조군 제외) 항목의 정답 영역을 사방 2 화소 넓힌 영역 밖**인 화소. 따라서 대조군 띠 위에서 새로 생긴 결함 표시는 새 오경보에 들어간다. 그중 대조군 띠 위의 것은 `new_false_alarms_in_controls` 로 따로 센다. 기존 "대조군 항목의 화소 50 % 이상 = 오검출" 판정도 그대로 둔다. 둘 다 보고한다 |
| 4 | 발견 4 | 서로 다른 입력 경로의 파일 이름(basename)이 같으면 주입을 시작하기 전에 오류(종료 코드 2)로 끝낸다 |
| 5 | 발견 6 | 시험 보강 (§2) |

백분위수 정의 (시험의 알려진 정답용): 정렬한 값 `v[0..m-1]` 에서 `q` 백분위수 = `v[min(m-1, floor(q·(m-1) + 0.5))]`, 중앙값 = `v[floor(m/2)]`. 이 정의는 QA-A-251 의 구현과 같다.

Jaccard 의 "정답 영역 안/밖" 은 모든 항목(참 결함과 대조군) 기준을 그대로 둔다 (정의서 §3.4, 바뀐 것 없음).

## 2. 새 시험과 각 시험이 막는 것

수치 시험은 도구의 계산 부분을 헤더(`tools/xpe_bpm_eval_stats.hpp`)로 나눠 시험이 직접 부른다.

| 시험 | 알려진 정답 | 막는 변형 |
|---|---|---|
| z 의 중앙값·95 백분위 | 값 0..100 → 중앙값 50, 95 백분위 95 | 백분위 정의 변경, 비어 있으면 0 |
| 무효 표본 | 분모 0 + 분자 20 → `zero_sigma_error`; 0/0 → `zero_sigma_equal`; I 만 비유한 → I 무효·U 유효; 전부 무효인 그룹 → `uncomputable` | 0 으로 보고, I/U 합산, 사유 누락 |
| D_n 정확한 비 | 앞 이웃 라인이 `a·(−1)^x` 이면 잔차 표준편차가 알려진 값. 한 줄·두 줄·행·열 모두 `D / (σ_pix·√(1/(kL)+1/(2L)))` 를 독립 계산한 값과 1e-9 이내 | 분모 상수, MAD 사용, k 확장 오류, 행/열 뒤바뀜 |
| MAD = 0 인 이웃 라인 | 대부분 0 이고 한 곳만 큰 잔차 → 표준편차 기준 비는 유한, MAD 기준 보조 비는 `uncomputable` | MAD 를 판정에 쓰는 변경 |
| D_n 계산 불가 | 상수 이웃 라인 + D = 0 → `uncomputable`, 초과 개수에 안 들어감 | NaN 을 "3배 초과 아님"으로 셈 |
| 정확히 50 % | 자기 화소가 짝수인 라인의 정확히 절반 표시 → 검출, 하나 모자라면 미검출 | `>=` 를 `>` 로 |
| 대조군 부분 표시 | 한 대조군 띠의 40 % 표시 → 대조군 오검출 0, 새 오경보 = 표시한 화소 수, `new_false_alarms_in_controls` 같음 | 대조군이 두 게이트에서 빠짐 |
| 입력 이름 충돌 | 같은 이름 두 입력 → 종료 코드 2, 출력 디렉터리 없음 | 덮어쓰기 |
| JSON | `correct` 출력에 `nan`, `inf` 문자열이 없음 | 비유한 값 출력 |

각 시험마다 변형을 만들어 빨개지는지 본다 (반증).

## 3. 재측정 (같은 입력, 시드 251)

- 순서와 입력은 QA-A-251 의 `50_measure_steps.sh.txt` 와 같다 (다크 `Dark_08~14`, 게인 `Bright_23~28`, 결함 맵용 `Bright_17~28`·`31~36`, 평가 `Bright_29·30`).
- S2 주입은 다시 하고 결과(`truth.tsv`, `truth_ids.u16`)가 QA-A-251 과 바이트 같은지 확인한다. S1·S3 (보정 세트)는 바뀌지 않은 `xpe_calib_fixture_gen` 이 만든 것이라 해시(`44_artifacts_sha256.txt`)를 확인하고 다시 쓴다. S4 (절반 맵)와 S5·S6 은 수정한 도구로 다시 한다.
- 보고: QA-A-251 표와 나란히, 바뀐 값에 사유를 붙인다.

## 4. 예측 (재측정 전)

QA-A-251 의 S5·S6 출력을 보고 쓴다. 신뢰도를 적었고 결과가 아니다.

- E1 검출률 표 (`score` 의 detection 부분)는 QA-A-251 과 **완전히 같다**. 바뀌는 정의가 없다. 신뢰도 높음.
- E2 **새 오경보가 0 에서 약 18000 이 된다.** QA-A-251 에서 1판이 표시한 대조군 화소는 2695 + 3051 + 81 + 0 + 3050 + 3050 + 3047 + 3054 + 1 + 0 + 0 + 0 = 18029 이고 깨끗한 맵에는 없다. 참 결함과 공유된 화소만 빠지므로 17900~18100. `new_false_alarms_in_controls` 가 새 오경보의 거의 전부 (99 % 이상). 신뢰도 높음.
- E3 대조군 오검출 항목은 6 / 12 그대로.
- E4 절반 분할 Jaccard 는 0.8870 그대로 (바뀌는 정의 없음).
- E5 보정 오차 표: 어떤 그룹도 `uncomputable` 이 되지 않고, 유효·무효 수가 JSON 에 나온다. 무효 표본 수는 0 에 가깝다 (깨끗한 출력의 11×11 표준편차가 0 인 곳이 실영상에는 거의 없다): 그룹마다 무효 0. 중앙값·95 백분위는 QA-A-251 과 같다. 신뢰도 높음.
- E6 **D_n 비가 바뀐다.** 표준편차는 MAD 기반 값보다 같거나 크다 (이웃 라인에 이상값이 있으면 더 크다). 그래서 비의 절대값이 작아지고 3배 초과 개수가 같거나 줄어든다: 보정 켬 54개 중 초과가 QA-A-251 의 26 / 28 보다 많지 않다 (예상 15~26). 보정 끔도 11 / 17 보다 많지 않다. 깨끗한 출력은 0 그대로. 신뢰도 중간. 항목 밖 행·열의 초과 수 (289 / 63 등)도 같거나 줄어든다.
- E7 MAD 기반 보조 열은 QA-A-251 에서 쓴 값과 거의 같다 (같은 식). 신뢰도 높음.
- E8 입력 이름 충돌은 cyan_test 의 입력에 없으므로 재측정에 영향이 없다.
