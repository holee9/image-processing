## 0. 설계 전에 확인한 사실 (설계 입력이고 결과 측정이 아니다)
- 두 판의 주입 세트(`inj_set_v1`, `inj_set_v2`)는 offset·gain 파일의 해시가 같고(`9bb62b78…`, `e95ea9db…`), 깨끗한 세트 둘도 같다(`5569bacf…`, `a7ddadbd…`). 결함 보정 전 영상 U(= 주입 프레임에 offset·gain 적용, 결함 보정 끔)는 두 판이 비트 단위로 같다(프레임 29·30). 두 판의 차이는 결함 지도와 보정 알고리즘, 그리고 기준 출력 C(깨끗한 세트의 지도로 보정한 것)뿐이다.
- 검출기에 쓰이지 않은 밝은 프레임은 Bright_29·30 한 쌍뿐이다(주입 프레임 디렉터리는 17~36, 깨끗한 취득도 같다). 독립 반복 쌍을 늘릴 새 프레임은 없다.
- 주입 잡음은 프레임마다 독립 난수 × `level × sigma_t`(sigma_t = 2.914369 화소값; `xpe_bpm_eval.cpp` 693~694행)를 더한다. 270 의 정정 항목: 270 §1.2 의 "처음 낸 대조군(참 잡음 결함, 비트만 켜진 것)이 0개"는 데이터에 그런 화소가 없어서가 아니라 **내 필터가 틀려서**(`cls == 'defect'` 로 걸러 잡음 항목이 모두 빠짐)였다. 이 카드에서 바로잡아 다시 잰다(§3.3).
- 사전 계산 `20_sensitivity_precompute.py.txt` / `21_*.txt`(측정 전): 주입 분산 대비 밝은 영상 국소 분산의 비 s = 1 + (level × sigma_t)² / v_b 는 level 4 에서 1.03~1.08, level 2 에서 1.01, level 1 에서 1.002~1.005. 잡음 항목 205개 중 항목 단위 검정 통계량 (s−1)/SE ≥ 2 인 것은 1개(39 cross)뿐이다. 독립 쌍 한 쌍의 검정력(한쪽 5 % 수준): n = 31 에서 s = 1.1 / 1.5 / 2 / 3 이 0.11 / 0.52 / 0.87 / 0.99, n = 14 에서 0.09 / 0.33 / 0.62 / 0.89, n = 10 에서 0.08 / 0.27 / 0.52 / 0.81.

## 1. 정확성 대조군 (모든 표 앞에)
- **K1 (쓰기·읽기)**: 파이썬으로 결함 파일(버전 1 / 버전 2, 압축 없음, 헤더 152바이트 + 설정 JSON + 페이로드, sha256 은 설정 + 페이로드)을 쓰고, 라이브러리로 읽어 `xpe_defect_correct_ex` 보고가 원래 세트로 만든 값과 같아야 한다: 원래 v1 세트의 지도를 다시 써서 보정하면 `I_v1_*` 와 비트 단위로 같고, 원래 v2 세트의 지도·영역·줄 기록을 다시 쓰면 `I_v2_*` 와 같다. 같지 않으면 이후 결론을 쓰지 않는다.
- **K2 (기준)**: 같은 보정 세트의 기준 Cp = 깨끗한 취득 프레임에 **주입 세트의 offset·gain** 을 적용(결함 보정 끔). 주입되지 않은 화소에서 주입 프레임의 U 와 Cp 는 비트 단위로 같아야 한다(주입이 건드린 화소만 다르다).

## 2. C4 원인 분리 (실제 영상)
### 2.1 요인과 실행
고정: 입력 U(프레임 29, 30), 같은 라이브러리, 같은 z 정의(`|I − 기준| / 기준의 11×11 창 표준편차`, 그룹×프레임 178칸의 중앙값 = 정렬한 값의 `floor(m/2)`번째).
- 지도(mask): **M1** = 원래 1판 세트의 지도, **M2** = 원래 2판 세트의 지도 평면, **Mo** = 오라클(비대조군 참 항목이 덮는 모든 화소, 공유 화소 포함; 영상 영역은 전부 안쪽).
- 알고리즘(algo): **A1** = 버전 1 파일(줄 기록 없음)로 보정, **A2** = 버전 2 파일(영역 평면 + 줄 기록)로 보정. A2 의 줄 기록은 M2 에서는 원래 2판 기록, Mo 에서는 참 줄 항목에서 만든 기록(방향·인덱스·폭, 구간은 항목 사각형, 보정 방법 = 보간)이다.
- 기준(ref): **C_v1 / C_v2** = 원래 판별 기준(깨끗한 세트 + 그 판의 지도로 보정), **Cc** = 깨끗한 세트, 결함 보정 끔, **Cp** = 같은 보정 세트의 기준(K2).
- 실행: R1 = (M1, A1), R2 = (M2, A2) [원래 두 판; 기준 C_v1 / C_v2 이면 118/178 이 재현되어야 한다(대조군 Z0')], R3 = (M2, A1), R4 = (Mo, A1), R5 = (Mo, A2). 각각 기준 C_v1, C_v2, Cc, Cp 로 z 를 구한다.
### 2.2 분해 (같은 칸 178개, 두 경로)
원래 차이 Δ = z(R2; C_v2) − z(R1; C_v1) 를 세 항으로 쪼갠다. 경로 P: ① 기준 바꿈 E_ref = z(R1; C_v2) − z(R1; C_v1), ② 지도 바꿈(A1 고정) E_map = z(R3; C_v2) − z(R1; C_v2), ③ 보간 바꿈(M2 고정) E_alg = z(R2; C_v2) − z(R3; C_v2). 합 = Δ(정확히). 경로 Q(순서 반대): ① 보간 바꿈(M1 고정은 불가능하므로 이 경로는 쓰지 않고) 대신 **오라클 경로** = z(R5) − z(R4)(보간 효과, 지도 고정 Mo), z(R3) − z(R1)(지도 효과, A1 고정), z(R2) − z(R3)(보간 효과, M2 고정)를 따로 보고한다.
### 2.3 판정 규칙
- 칸 118개의 항별 중앙값과 원래 Δ 의 중앙값을 보고한다. 항의 중앙값이 원래 Δ 중앙값의 **50 % 이상**이면 그 요인이 "주된 원인"이다. 둘 이상이 50 % 이상이거나 아무것도 못 넘으면 "혼합/미상"으로 쓴다.
- 보간 요인은 두 경로(M2 고정, Mo 고정)에서 같은 방향이어야 인정한다. 지도 요인은 M1→M2 와 M1→Mo 가 같은 방향이어야 인정한다.
- 기준 Cp 를 쓴 칸의 z 중앙값이 주입되지 않은 화소에서 0 이어야 한다(K2). 그렇지 않으면 Cp 결과는 쓰지 않는다.
### 2.4 예측 (측정 전; 확신 중간)
- E_ref 의 중앙값은 |0.01| 미만이다(깨끗한 세트 두 판의 지도가 주입 위치를 거의 건드리지 않는다).
- E_map 은 gain_loss·efficiency_loss 줄에서 0.03 미만이다(두 판이 모두 99.9~100 % 잡는다); noisy 줄에서는 1판이 줄을 잡지 않으므로 0 이 아닐 수 있다.
- E_alg 가 원래 Δ 의 50 % 이상이다(gain_loss·efficiency_loss 줄에서 +0.08 이상).
- 기준 Cp 를 쓰면 z 의 바닥이 크게 내려가 줄 화소 중앙값이 1.0 아래가 된다(바닥 1.62 는 두 보정 세트의 차이에서 온다).
### 2.5 팬텀 (무구조·엣지·경사)
512×512 합성 영상, 평균 10000, 백색 가우시안 잡음 sigma = 30(고정 시드), 같은 알고리즘(A1 = 버전 1 파일, A2 = 버전 2 파일 + 줄 기록)을 라이브러리로 돌린다. 행 줄 폭 1·2 와 열 줄 폭 1·2, 줄 화소는 값 0 으로 덮은 뒤 보정한다. 영상 유형: (a) 평탄, (b) 줄 위치에 중심을 둔 계단 엣지(위 9000, 아래 11000, 전이 폭 4 화소), (c) 줄을 가로지르는 선형 경사(기울기 10 화소값/화소), (d) 줄에서 2 화소 떨어진 평행한 밝은 선(+2000, 폭 1). 측정: 줄 화소의 오차(보정값 − 잡음 없는 참값)의 평균(편향), 표준편차(분산), 엣지 보존 = 줄에서 1~2 화소 떨어진 비결함 화소가 바뀐 정도(보간이 줄 밖을 건드리는지; 건드리면 1), 줄 화소 1000개 이상 평균.
예측: (a) 편향 |평균| < 0.05 sigma 둘 다, 표준편차 A2 = 0.71 sigma ±5 %(두 이웃 평균), A1 이 A2 이하; (b) A2 의 |편향| ≤ 0.1 sigma 이고 A1 의 |편향| 은 A2 보다 큼; (c) 둘 다 |편향| < 0.1 sigma; (d) 줄 밖 화소는 바뀌지 않음. 틀린 예측은 보고서에 그대로 적는다.
### 2.6 나쁜 보간 양성 대조 (이 지표가 잡는가)
A2 출력에서 오라클 줄 화소만 다음으로 바꾼다(기준 C_v2 와 Cp 두 가지로 z): B1 한쪽 이웃만 복사(첫 줄 앞 이웃), B2 먼 이웃(3 화소 바깥 두 화소 평균), B3 상수 편향 +0.1 sigma_local, B4 +0.25 sigma_local. 지표: 줄 칸 138개 중 "나쁜 쪽이 A2 보다 큼"인 칸 수와 줄 화소 전체 z 중앙값 이동량. **검출 규칙**: 칸 수 ≥ 80 %(110/138)이고 이동량 ≥ 0.05(관측된 차이 0.06~0.16 의 하한) 이면 이 지표는 그 결함을 잡는다. 예측: C_v2 기준에서는 B1·B2 가 잡히고(분산 증가) B3·B4 는 이동량 < 0.01 로 못 잡는다(잔차 sd 가 sigma 의 2배 이상이라 작은 편향이 중앙값을 거의 안 바꾼다); Cp 기준에서는 B3·B4 도 잡힌다.

## 3. 양성 대조군 감도 (R244-3)
### 3.1 효과 크기와 검정력 (계산, §0 의 사전 계산)
주입 잡음의 분산비 s 는 1.002~1.08 이고 한 쌍의 검정으로는 항목 단위에서도 검출되지 않는다(205개 중 1개). 따라서 270 의 양성 대조군 실패는 "한 쌍이 잡음을 못 보는 감도 한계"로 설명되지만(R244-3 의 요구대로 이제 계산으로 뒷받침), 이 설명은 측정으로 다시 확인한다(§3.2).
### 3.2 합성 양성 대조 (같은 절차, 알려진 s)
Bright_29·30 의 주입 프레임 쌍에서 270 의 6개 띠 화소를 무작위로 같은 개수(14, 10, 3, 2, 1, 1)로 골라, 선택한 화소의 한쪽 프레임에 분산 (s−1)·v_b 의 가우시안 잡음을 더해 알려진 비 s 를 만든 뒤, 270 과 같은 절차(켜진 화소의 평균 d 와 같은 띠 나머지의 평균 d 의 차를 띠 부트스트랩 SE 로 나눈 합산 z)로 검출한다. s = 1.1, 1.5, 2.0, 3.0, 반복 200회(시드 고정). **검출 규칙**: 합산 z ≥ 2. 예측(검정력 표의 n = 31): s = 1.1 에서 검출률 0.05~0.20, 1.5 에서 0.40~0.65, 2.0 에서 0.80~0.95, 3.0 에서 0.97 이상. 270 에서 관측한 켜진 31개의 합산 비 0.80 은 이 시험의 같은 절차이고, 그 값을 이미 알고 있었다는 점을 밝힌다(측정 전 알고 있던 숫자).
### 3.3 같은 특성의 양성 대조 (밝은 잡음 비트)
참 잡음 항목(비대조군, 종류 noisy, 클래스 line·pixel)의 화소에서 밝은 잡음 비트가 켜진 비율과, 켜진 화소가 두 절반 지도에 동시에 켜진 비율(270 의 정상 띠 위 31 은 0 / 31). 270 의 필터 오류를 고친 정의.
### 3.4 판정 규칙
이 데이터(독립 쌍 한 쌍)로 31개의 정상 여부를 가를 감도가 있다고 하려면 **목표 이상(정상 띠 비용 상한을 넘는 s)에 대해 검정력 ≥ 0.8** 이어야 한다. 정상(띠 비용 ≤ 1.9)과 결함(비용 ≥ 2)의 경계는 띠 평균 대비 s ≈ 1.05~1.1 이므로, 그 크기에서 검정력(n = 31 에서 0.11)이 0.8 에 못 미치면 "이 데이터로는 판정 불가"로 끝낸다. 예측: 판정 불가.
