========== Map infomations ==========

PositionMap.raw : 3x3 초과한 픽셀들이 저장 되는 map 

AED_BPM.raw : AED 모드에서 취득된 bright를 이용해서 만든 BPM 

Stitch_BPM.raw : stitch 모드에서 취득된 bright를 이용해서 만든 BPM 

BPM_with_Filter.raw : Al filter 없는 데이터로 만든 BPM 

BPM_without_Filter.raw : Al filter 있는 데이터로 만든 BPM 

DotDefectBPM.raw : Dot defect만 검출하여 만든 map 

BT_BPM.raw : aging test 에서 생성된 BPM 

TOTAL_BPM.raw : BPM_with_Filter + BPM_without_Filter + BT_BPM + Unsaturated Pixel + previous BPM + Mura 

TOTAL_BPM_original.raw : BPM_with_Filter + BPM_without_Filter

Total_Defect_Map.raw :  BPM_with_Filter + BPM_without_Filter
