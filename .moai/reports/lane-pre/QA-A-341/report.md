근거 사실: `image-processing/.moai/reports/lead/flat-criterion-draft-20261117.md`(2판, F1~F5). 현재 FlatResidualPct = 보정 후 유효 게인 화소의 표준편차/평균 × 100(`xpe_verify_metrics.cpp:574-602`, `:659-661`), normalized_gain 한계 0.5 %(`:126`). 이 지표는 시간 잡음과 공간 잔여(고정 무늬)를 함께 잰다. **기존 기준(0.5 %)과 기존 FAIL 기록은 그대로 둔다.** 이 설계서는 지표·기준을 바꾸자는 결정이 아니다.

## 0. 연구 질문
- 보정 후 평탄 영상의 **공간 잔여(고정 무늬) 몫**을 시간 잡음 몫과 분리해 잴 수 있는가. 분리한 값이 알려진 크기의 고정 무늬를 넣었을 때 그 크기를 되찾는가.

## 1. 측정할 양 — 후보 하나 (F)
- 같은 선량의 독립 평탄 프레임 두 장 A, B 를 같은 보정 세트로 보정한 출력 a, b (화소 집합 P, 2절).
- 각 장을 자기 평균으로 나눠 정규화: a' = a / mean_P(a), b' = b / mean_P(b) (두 장의 선량 차를 없앰).
- 평균 영상 m = (a' + b')/2, 차 영상 d = a' − b'.
- Var(m) = σ_s² + σ_t²/2, Var(d) = 2σ_t² (두 장의 시간 잡음이 독립·같은 분산일 때) 이므로
  **σ_s² = Var_P(m) − Var_P(d)/4**, **σ_t² = Var_P(d)/2**.
- 보고하는 양: **FlatPatternPct = 100·√max(σ_s², 0)**, **FlatTemporalPct = 100·σ_t**(한 장 기준), 그리고 기존 FlatResidualPct(a 한 장, 제품 정의 그대로)를 나란히.
- 가정: (i) A, B 의 시간 잡음은 서로 독립이고 분산이 같다, (ii) 고정 무늬는 두 장에 같다, (iii) 정규화가 선량 차만 없앤다(선량에 따른 무늬 모양 변화는 없다), (iv) 시간 잡음과 고정 무늬는 서로 독립. 공간 상관이 있어도 위 분산 분해는 성립한다(분산만 쓰므로).
- σ_s² < 0 이 나오면(표본 변동) 0 으로 자르지 말고 원값도 함께 보고한다; FlatPatternPct 는 그때 0 으로 적고 "음수 추정" 표시.

## 2. 입력 고정
- 보정: 그 세트 자신의 보정 세트(오프셋·게인·결함 맵), 출하 파이프라인 기본 설정 출력(QA-A-335 `02_out_sha.py.txt` 와 같은 호출, gain_semantics normalized_gain 으로 해석).
- 화소 집합 P: 제품 지표와 같은 "유효 게인 화소"(`xpe_verify_metrics.cpp` 의 `isfinite(gain) && gain > 0`)에서 결함 맵 화소와 여백 6,2,1,1 밖을 뺀 것. 제품 FlatResidualPct 는 제품 정의 그대로(이 집합 축소 없이) 따로 계산해 나란히 적는다.
- 두 장 선택 규칙: 세트의 판정 밝은 프레임 두 장(QA-A-340 잠금 목록의 평가 프레임 쌍; 보정 생성에 쓰지 않은 장). 두 장의 원시 평균 비가 1 ± 0.02 밖이면 "선량 불일치"로 판정 불가(설계 상수 2 %, 측정에서 유도하지 않음).
- 클리핑·포화: 보정 출력이 0 으로 잘린 화소 비율 또는 원시 65535 화소 비율이 P 의 0.1 % 를 넘으면 판정 불가(설계 상수).
- 중복: 두 원시 프레임이 바이트 동일하거나 Var_P(d) = 0 이면 판정 불가.
- 비유한 화소는 P 에서 미리 뺀다(평균 계산 전).
- 저선량: 판정 신호(두 장 원시 평균 − 오프셋 맵 평균의 평균)를 함께 적고, 결과를 신호 구간 <5,000 / 5,000~15,000 / >15,000 화소값으로 나눠 보고한다. 구간 사이 외삽은 하지 않는다.

## 4. 효과 크기 (QA-A-340 교훈: 측정 대상 척도로 정함)
- 주입하는 것은 **고정 무늬**(두 장에 같은 무늬), 크기는 **FlatPatternPct 와 같은 단위(평균 대비 %)** 로 정한다: c ∈ {0.25, 0.5, 1.0} % (기존 한계 0.5 % 의 절반·같음·두 배).
- 주입: a'_inj = a' · (1 + g), b'_inj = b' · (1 + g), g 는 평균 0·표준편차 c/100 인 무늬. 무늬 두 종류(각각 따로): (i) 화소 독립 정규, (ii) 저주파(가로·세로 각 주기 3~8 의 코사인 합을 표준편차 c/100 으로 맞춘 것). 씨 341.
- 기대값: 주입 후 σ_s² ≈ σ_s0² + (c/100)²(무늬와 원래 잔여가 독립이라는 가정). 회수량 = √max(σ_s,inj² − σ_s0², 0).
- 회수 판정(설계 상수): |회수량 − c/100| ≤ 0.2·c/100 인 프레임 비율을 c·무늬별로 보고한다. 이 비율로 지표를 채택하거나 기각하는 규칙은 이 설계서에 두지 않는다(보고만).
