## 1. 측정할 양 — 후보 하나 (F)
- 같은 선량의 독립 평탄 프레임 두 장 A, B 를 같은 보정 세트로 보정한 출력 a, b (화소 집합 P, 2절).
- 각 장을 자기 평균으로 나눠 정규화: a' = a / mean_P(a), b' = b / mean_P(b) (두 장의 선량 차를 없앰).
- 평균 영상 m = (a' + b')/2, 차 영상 d = a' − b'.
- Var(m) = σ_s² + σ_t²/2, Var(d) = 2σ_t² (두 장의 시간 잡음이 독립·같은 분산일 때) 이므로
  **σ_s² = Var_P(m) − Var_P(d)/4**, **σ_t² = Var_P(d)/2**.
- 보고하는 양: **FlatPatternPct = 100·√max(σ_s², 0)**, **FlatTemporalPct = 100·σ_t**(한 장 기준), 그리고 기존 FlatResidualPct(a 한 장, 제품 정의 그대로)를 나란히.
- 가정: (i) A, B 의 시간 잡음은 서로 독립이고 분산이 같다, (ii) 고정 무늬는 두 장에 같다, (iii) 정규화가 선량 차만 없앤다(선량에 따른 무늬 모양 변화는 없다), (iv) 시간 잡음과 고정 무늬는 서로 독립. 공간 상관이 있어도 위 분산 분해는 성립한다(분산만 쓰므로).
- σ_s² < 0 이 나오면(표본 변동) 0 으로 자르지 말고 원값도 함께 보고한다; FlatPatternPct 는 그때 0 으로 적고 "음수 추정" 표시.

### F341-3 — 주입 식 완성
- 주입은 정규화된 a', b' 에 같은 무늬 g 를 곱한다: a'_inj = a'·(1+g), b'_inj = b'·(1+g). g 는 P 위에서 평균 0, 표준편차 c/100(1판 4절의 두 무늬).

- 저주파: u(x, y) = Σ_{p=3}^{8} [cos(2π·p·x/3072 + φx_p) + cos(2π·p·y/3072 + φy_p)], x·y 는 전체 영상 좌표(0..3071, x 가로·y 세로), 가중 1, 위상 φx_p·φy_p 는 [0, 2π) 균등(12개).
- 두 무늬 모두 P 위에서 중심화(평균을 뺌)한 뒤 P 위 표준편차(ddof = 0)로 나눠 단위화한다. g = (c/100)·u.
- 난수: 프레임 쌍 i(잠금 목록 순서, 0부터)마다 `numpy.random.default_rng([341, i, 0])` 에서 위상 12개 → 화소 독립 장 순서로 뽑고, 부트스트랩은 `default_rng([341, i, 1])` 를 쓴다.
- 회수 비율의 분모 = 유효 쌍 수(판정 불가가 아닌 쌍). 기준 σ_s0² < 0 인 쌍과 주입 불가(주입 뒤 판정 불가 조건에 걸린 쌍)는 따로 세고 분모에서 뺀다.

### R3 — 예외와 계산 규약
- 판정 불가(그 쌍 전체): mean_P(a) 또는 mean_P(b) ≤ 0 이거나 비유한, P 가 비었거나 |P| < 10⁶ 화소(설계 상수), 2판의 0.1 % 조건.
- 부트스트랩: 블록 풀이 0 이면 그 쌍의 구간만 판정 불가(점추정은 유지). 복제에서 평균 ≤ 0 이거나 비유한이면 그 복제는 무효로 세고, 무효가 200 중 10 개(5 %)를 넘으면 그 쌍의 구간은 판정 불가. 무효를 뺀 복제로 최근순위 2.5·97.5 백분위를 낸다.
- 분산·공분산은 모두 ddof = 0.
- 구간 표시: **부호 있는 σ_s² 의 구간을 주 결과**로, 0 에서 자른 FlatPatternPct 구간을 보조로 함께 적는다.
- 한계 추가: 64×64 블록은 그보다 긴 파장의 공간 무늬(저주파 무늬 포함)의 상관을 다 담지 못하므로 구간이 좁게 나올 수 있다.
