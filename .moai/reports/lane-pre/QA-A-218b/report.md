# QA-A-218b — 고스트 티어 3 의 3×3 이웃 평균이 원본 이웃을 읽는다 (Refs #233)

기준: dev/preprocess `b4334545`(QA-A-218) 위, 217(cafb92d8)의 `backup` 평면 위. 코드: `ghost_correct.cpp` `ghost_tier3`(읽는 원천 교체 2줄 + 주석), `CMakeLists.txt`, 시험 `test_ghost_tier3_orientation.cpp`(3건). 푸시하지 않음. 혼합 0.7:0.3 의 유지·제거(C)는 #238 로 분리되어 **건드리지 않았다**.

## 결론

1. 티어 3 의 3×3 이웃 평균이 이제 **들어온 프레임**(`gh->backup`, 217 이 호출 동안 보관하는 사본)을 읽는다. 제자리 갱신 때문에 윗줄·왼쪽 화소가 보정된 값으로 읽히던 것이 사라졌다. 메모리 추가 없음.
2. **방향 의존이 사라졌다**: 좌우·상하·180°·전치로 뒤집어 처리하고 되돌린 출력이 원래와 같다(최대 차 1.5e-3, 허용 0.1 — 아래). 이전에는 41~91 % 화소가 달라졌다.
3. **티어 1·2 출력 비트 불변**(24프레임 해시 전부 일치). 티어 3 출력은 바뀌었다(의도).
4. **합성 잔상 RMS 는 나빠지지 않고 좋아졌다**: 3345 → 2009.

## 변경

`ghost_tier3` 에 `const float* const src = gh->backup.data();` 를 두고 이웃 합산의 `px[ni]` 두 곳(유한 검사·합산)을 `src[ni]` 로 바꿨다. 루프의 나머지(`raw = px[i]`, `px[i] = …`)는 그대로. `backup` 은 `xpe_ghost_correct` 가 티어 호출 직전에 입력으로 채우고 호출이 끝날 때까지 바뀌지 않는다(217).
