# 줄무늬 기준(행·열 성분 / 순수 잡음 기대값 ≤ 3)의 정의 (결과 없음)

QA-A-241g. 이 파일, 프로토콜 문구 초안(`01_protocol_text_draft.txt`), 측정 하니스(`A241Measure.DISABLED_B6_StripeNoiseRatio`)는 **세 장의 실측 결과를 보기 전에** 커밋한다. 이 커밋 뒤에 정의를 바꾸면 보고서에 "사후 수정" 으로 따로 적는다.

## 사용자 결정과 기록해야 할 사실

2026-10-05 사용자 결정: `LineArtifactScore` 의 "gain 전보다 10 % 넘게 늘지 않기" 를 잡음 기준 절대 기준으로 바꾼다. 행·열 성분이 순수 잡음일 때의 기대값의 **K = 3 배 이하**. 이 기준(K = 3 과 타일 크기 대신 쓰는 정의)은 241e·241f 의 측정(최종 영상의 행·열 성분이 이웃 차이 잡음 기대값의 2.2~2.7 배)을 본 **뒤에** 정해졌다는 사실을 프로토콜에 기록한다. 이 정의의 식·매개변수는 이번 측정 전에 이 문서에서 고정한다. 값 3 은 사용자가 정했고 이 문서가 고르지 않았다.

## 정의

입력: 보정이 끝난 영상 `Y` (float32, 출하 경로 최종 출력), 폭 `W` × 높이 `H`, ROI. ROI 는 §5.3 과 같다: gain 값이 유한하고 0 초과인 모든 화소 (중앙 자르기·가장자리 제외·결함 화소 제외 없음).

1. **프로파일.** `r[y]` = 행 `y` 의 ROI 화소 평균, `c[x]` = 열 `x` 의 ROI 화소 평균. ROI 화소가 하나도 없는 행·열은 프로파일에서 뺀다. `n_r` = 프로파일에 든 행들의 ROI 화소 수 평균, `n_c` = 열들의 ROI 화소 수 평균.
2. **고역 통과.** 프로파일 `p` (길이 `L`)의 각 위치 `k` 에서 `h[k] = p[k] − mean(p[a..b])`, `a = max(0, k−16)`, `b = min(L−1, k+16)` (중심 33 칸 이동 평균, 가장자리에서는 창을 자르고 그 칸 수 `m_k = b−a+1` 로 나눈다). 줄무늬 성분 `S` = `h` 의 모집단 표준편차 (평균을 뺀다). 행은 `S_row`, 열은 `S_col`.
3. **화소 잡음 추정, 같은 영상에서.**
   - `σ_h` = 가로 이웃 쌍(`Y[y][x]`, `Y[y][x+1]`, 둘 다 ROI)의 차이의 모집단 표준편차 / √2. 행 줄무늬는 한 행의 모든 화소에 같은 값이 더해지므로 가로 차이에서 지워진다. 그래서 행 성분의 기대값에는 `σ_h` 를 쓴다.
   - `σ_v` = 세로 이웃 쌍(`Y[y][x]`, `Y[y+1][x]`, 둘 다 ROI)의 차이의 모집단 표준편차 / √2. 열 줄무늬는 세로 차이에서 지워진다. 열 성분의 기대값에는 `σ_v` 를 쓴다.
4. **순수 백색 잡음일 때의 기대값.** 화소 잡음이 독립이면 행 평균의 잡음 표준편차는 `σ_h/√n_r` 이고, 위 고역 통과가 그것을 `√g` 배로 줄인다 (`g = mean_k(1 − 1/m_k)`, `L` 개 위치에 대한 평균. 내부는 `1 − 1/33`, 가장자리는 창이 짧아 더 작다). 따라서 `E_row = σ_h · √g_row / √n_r`, `E_col = σ_v · √g_col / √n_c` (`g_row` 는 행 프로파일의 길이 `L_row` 로, `g_col` 은 `L_col` 로 계산).
5. **지표.** `StripeNoiseRatio_row = S_row / E_row`, `StripeNoiseRatio_col = S_col / E_col`, `StripeNoiseRatio = max(두 값)`. 1 은 행·열 평균이 화소 잡음만으로 설명된다는 뜻이고, 줄무늬 성분이 잡음 기대값의 배수만큼 크면 그 배수가 된다.
6. **판정.** `StripeNoiseRatio ≤ 3` 이면 통과. 세 장(평탄 4·5·6) **모두**에서 판정한다 (최소 신호 2000 ADU 조건은 `FlatResidualPct` 에만 적용된다). ROI 는 위 §5.3 ROI (이하 ROI A)에서 판정한다. 하나라도 3 을 넘으면 B6 는 실패다.
7. **같이 보고하지만 판정에 쓰지 않는 것**: (가) 결함 맵 화소를 뺀 ROI B (모든 평탄에 같은 ROI), (나) `bypassGain` 만 켠 영상(음영이 남아 있는 영상. 점수가 매우 크게 나오는 것이 정상이고 기준을 이 영상에 적용하지 않는다), (다) 행·열 따로의 값과 `S`, `E`, `σ`.

## 입력 (241e·241f 와 같다)

평탄 4·5·6 중 두 장으로 만든 gain 을 남은 한 장에 적용(세 조합), 제품 생성기가 `dark.raw` 한 프레임으로 만든 offset, `BPMap.map` 결함 맵, 출하 경로 `xpe_preprocess_pipeline_out`, 설정 `{"bypassTemp":true,"bypassNonlinearity":true,"bypassBinning":true}`, 한 세션 ID. `bypassGain` 영상은 결과가 float32 이다 (결함 보정이 살아 있어서). 출력 형식은 `out->format` 으로 확인하고 uint16 이면 넓혀서 읽는다 (241f 의 `widenIfUint16`).

## 합성 대조 (통과해야 실측한다; 하니스가 먼저 실행한다)

3072 × 3072, 평균 2000, 화소 잡음 σ = 18.5 (값은 척도만 정한다), 고정 시드. `a` 는 줄무늬 진폭의 배수: 행마다 독립인 오프셋의 표준편차가 `a · σ/√3072`.

| 번호 | 영상 | 기대 | 허용 |
|---|---|---|---|
| C1 | 백색 잡음 | 행·열 비 모두 ≈ 1 | 0.95 ~ 1.05 |
| C2 | C1 + 행 줄무늬 a = 2.5 / 3.2 / 5 | 행 비 ≈ √(1+a²) = 2.69 / 3.35 / 5.10, 열 비 ≈ 1 | 행 비 ±6 %, 열 비 0.95 ~ 1.05. **판정 `≤ 3` 이 a = 2.5 에서는 통과, 3.2 에서는 실패** |
| C3 | C1 + 열 줄무늬 a = 2.5 / 3.2 / 5 | 열 비 ≈ √(1+a²), 행 비 ≈ 1 | 같음. 판정도 같은 방향 |
| C4 | C1 + 큰 규모 음영 (가운데가 100 ADU 높은 2차 곡면) | 비 ≈ 1 (고역 통과가 음영을 지운다) | 0.95 ~ 1.10 |
| C5 | C1 에서 무작위 0.25 % 화소를 ROI 에서 뺀 것 | 비 ≈ 1 (ROI 수 처리) | 0.95 ~ 1.05 |
| C6 (참고, 판정 아님) | 가로로 상관된 잡음 (AR(1), ρ = 0.3, 같은 σ) | 방법의 사각을 보인다: 예측 행 비 ≈ √((1+ρ)/(1−ρ)²) = 1.63 (이웃 차이가 잡음을 `√(1−ρ)` 배로 작게 잡기 때문), 열 비 ≈ 1 (세로로는 독립이라 σ_v 가 맞다) | 예측과 ±10 % 이면 사각이 예측대로라는 확인 |

C1~C5 중 하나라도 허용을 벗어나면 측정 도구가 틀린 것이고 이후 결과를 쓰지 않는다. C6 는 보고용이다. 허용 폭은 표본 오차(3072 개 표준편차의 상대 오차 약 1.3 %)의 3 배 안팎으로 골랐다.

## 예측 (결과 전에 적는다)

241f 의 값(이웃 차이 가로 잡음, 보정 인자 없음)은 평탄 6 행 2.46 / 열 2.25, 평탄 4 행 2.62 / 열 1.95, 평탄 5 행 2.65 / 열 2.29 였다. 새 정의는 기대값에 `√g ≈ 0.985` 를 곱하고 열에 `σ_v` 를 쓰므로 값이 약 1.5 % 커지고 열은 조금 달라질 수 있다. 예측: ROI A 에서 세 장 모두 `StripeNoiseRatio` 가 2.4~2.8 이라 **3 이하로 통과하지만 여유가 작다** (가장 큰 것은 평탄 5 의 행, 약 2.7). ROI B 에서는 241f 에서 평탄 6 의 행 값이 3.15 였으므로 3 을 넘는 장이 있을 것이다 (판정에는 쓰지 않는다). 확신은 없다.

## 하지 않는 것

- 기준 3 을 바꾸지 않는다. 통과 폭이 작다는 이유로 K 나 창 길이(33), 타일 대체 정의를 조정하지 않는다.
- 제품 코드를 바꾸지 않는다 (측정 하니스와 증거만).
