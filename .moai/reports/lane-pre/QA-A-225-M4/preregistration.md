# QA-A-225 M4 — 티어 3 혼합(0.7:0.3) 끄기 비교의 사전 등록 (Refs #241 #238)

이 문서는 **비교를 돌리기 전에** 판정 규칙을 고정한다. 이 문서를 담은 커밋이 비교 코드·이음새·결과 커밋보다 먼저다(git 이력으로 확인). 결과가 나온 뒤 이 문서의 규칙을 바꾸지 않는다. 바꿔야 한다면 바꾼 내용과 이유를 결과 보고서에 **이탈**로 따로 적는다.

## 0. 이 비교가 하는 일과 하지 않는 일

- 하는 일: 티어 3 이 보정 결과에 섞는 이웃 평균의 가중치를 시험 전용 이음새로 0.3(출하 값)과 0(혼합 없음)으로 바꿔, 같은 입력에서 측정값이 어떻게 달라지는지 **재고 출력**한다.
- 하지 않는 일: **#238 을 결정하지 않는다.** 실장비 데이터 전까지는 측정 근거로 기록만 한다(리더 결정, 2026-10-03). SRS-CALIB-FUNC-020 의 90 % 선(D1)은 사용자 결정으로 보류 중이며 이 비교는 합격선을 정하지 않는다. NFR-206(나이퀴스트에서 MTF ≥ 0.98)이 현행 요구인지는 확인되지 않았으므로(설계 메모 4.2 S3) 0.98 은 **참고 기준선**으로만 쓴다.

## 1. 등록 전에 이미 알고 있던 것 (정직한 선행 지식)

| 항목 | 내용 | 출처 |
|---|---|---|
| 티어 3 식 | `corrected = 0.7·corrected + 0.3·(원본 프레임의 3×3 평균)`, **내부 화소(x, y 모두 테두리가 아닌 곳)에만** 적용 | `ghost_correct.cpp`(코드를 읽음) |
| 혼합이 지연을 되돌린다는 구조 | 3×3 평균은 보정 **전** 원본이라 제거된 지연의 30 %가 내부에 남음 | 설계 메모 4.1 |
| 테두리-내부 단차 | 균일 프레임에서 티어 3 의 내부가 테두리보다 `0.3·(원본 − 테두리 값)` 만큼 큼 | M3 보고서 4절(파이썬 실측 1193 ADU) |
| 잡음 감소 | 티어 3 내부 표준편차가 원본의 약 0.75 배 | M3 실측 ×0.75~0.76 |
| M1 의 티어 3 행 | 임의 설정에서 티어 3 의 보존·제거율이 티어 1 과 다름(보존은 24가지 중 16가지에서 티어 1 보다 낮음) | M1 보고서 5절 |
| 해석식 | 아래 5절의 세 값은 식으로 먼저 계산해 두었다 | 이 문서 |

즉 결과의 **방향**은 일부 예상하고 있다. 사전 등록의 목적은 방향을 숨기는 것이 아니라 **문턱과 읽는 규칙을 결과 전에 고정**하는 것이다.

## 2. 변형과 조건

- 변형: 혼합 가중치(이웃 평균의 비중) `m` ∈ {**0.3**(출하 값), **0**(혼합 없음)}. 이웃 평균이 아닌 원래 보정값의 비중은 `1 − m`.
- 이음새: `XPE_CACHE_TEST_HOOKS` 가 정의된 시험 실행 파일(`xpe_preprocess_oom_tests`)에만 있다. 출하 DLL 에는 선언도 호출도 없다(212d·221c 와 같은 원칙). 기본값 0.7/0.3 의 출력이 출하 코드와 같음을 **다이제스트 비교**로 보인다(보고서에 두 실행 파일의 값).
- 보정기: 티어 3 만(혼합은 티어 3 에만 있다). 설정 세 가지: (A) `0.02/3/0.003/30`, (B) T1 @27 % ±0.1 % 로 도출한 설정, (C) T2 @27 % ±0.1 % 로 도출한 설정(도출 절차는 M3, 같은 시드·같은 코드).
- 시퀀스: M1·M3 와 같은 생성기(T1 Starman LTI, T2 유한 트랩), 같은 길이(5 + 200 + 50), 노출 수준 2·27·92 %, 잡음 σ ∈ {0, 5 ADU}(시드 7), 계단 하강 27 % → 5 %(200 + 100 프레임, 잡음 0).
- 프레임: 16×16 float32. 하나의 `m` 에 대한 값은 같은 입력 프레임에서 잰다.

## 3. 측정 항목

각 항목은 `m = 0.3` 과 `m = 0` 에서 모두 잰다.

| 코드 | 항목 | 정의 |
|---|---|---|
| **M-rem** | 계단 하강의 부호 있는 잔차 | 27 % → 5 % 뒤 k = 1, 50 번째 프레임의 `(프레임 평균 − 참 수준)/참 수준 × 100`. 클램프가 가리지 않는다. 설정 3 × 진실 2 × k 2 = **12 행** |
| **M-blank** | E2E 빈 프레임 제거율 | M1 의 `GhostRemovalPct(k)`, k = 1, 10, 50. 노출 수준 3 × 잡음 2 × 진실 2 × 설정 3. **보고만**(판정 규칙에 쓰지 않음: 클램프에 취약하다는 것이 M1·M3 의 결론) |
| **M-ret** | 신호 보존 | M1 정의. **보고만** |
| **M-ring** | 테두리-내부 단차 | T1 27 % 노출의 150 번째 프레임(잡음 0, 균일)에서 `내부 평균 − 테두리 평균`을 ADU 와 테두리 평균 대비 %로. 설정 3 |
| **M-nyq** | 나이퀴스트 응답 | **첫 프레임**(이력 0 이라 보정이 항등)에 평균 10000 ADU, 진폭 ±1000 ADU 의 열 교대 줄무늬와 체커보드를 넣고, 내부 화소에서 (출력 진폭)/(입력 진폭). 줄무늬 1, 체커보드 1 |
| **M-noise** | 잡음 감소 | **첫 프레임**의 평탄 프레임(평균 10000, σ = 5, 시드 7)에서 내부 화소의 표준편차(출력/입력) |

## 4. 판정 규칙 (결과 전에 고정)

각 기준의 판정은 `m = 0.3`(혼합 유지)을 `m = 0`(혼합 제거)과 비교한 결과다.

| 기준 | 읽는 규칙 | 판정 |
|---|---|---|
| **K1 제거** (M-rem, 12 행) | 행마다 `Δ = |잔차(m=0.3)| − |잔차(m=0)|` (퍼센트포인트). `Δ ≥ +1.0` 이면 그 행은 "혼합이 나쁨", `Δ ≤ −1.0` 이면 "혼합이 좋음", 그 사이는 "차이 없음" | 좋음 0행 이고 나쁨 6행 이상 → **K1 = 혼합이 나쁨**. 좋음 6행 이상 이고 나쁨 0행 → **K1 = 혼합이 좋음**. 그 밖 → **K1 = 혼합 또는 차이 없음** |
| **K2 단차** (M-ring, 3 설정) | `|단차(m=0.3)| − |단차(m=0)| ≥ 0.1 %`(테두리 평균 대비) 이면 "혼합이 나쁨" | 3 설정 모두 나쁨 → **K2 = 혼합이 나쁨**, 그 밖 → **K2 = 혼합 또는 차이 없음** |
| **K3 나이퀴스트** (M-nyq) | 줄무늬와 체커보드 둘 다 `응답(m=0.3) < 응답(m=0) − 0.02` 이면 "혼합이 나쁨". 참고로 0.98 대비 위치도 함께 적는다(요구 여부 미확인) | 둘 다 나쁨 → **K3 = 혼합이 나쁨**, 그 밖 → 혼합 또는 차이 없음 |
| **K4 잡음** (M-noise) | `비(m=0.3) < 0.9·비(m=0)` 이면 "혼합이 좋음" (잡음 10 % 이상 감소) | 좋음 → **K4 = 혼합이 좋음**, 그 밖 → 차이 없음 |

**종합 라벨** (하나만):

- **A — 혼합을 뒷받침하는 측정이 없고 비용만 있다**: K1 이 "혼합이 좋음"이 아니고, K2·K3 가 모두 "혼합이 나쁨"이다. K4 가 "혼합이 좋음"이면 그 크기를 **유일한 이익**으로 적는다.
- **B — 혼합을 뒷받침하는 측정이 있다**: K1 = "혼합이 좋음".
- **C — 혼합**: 위 둘 어느 쪽도 아니다.

라벨은 **이 입력과 이 조건에서의 측정 요약**이다. 어떤 라벨이 나와도 #238 을 결정하지 않으며(0절), 합격선을 만들지 않는다.

## 5. 먼저 계산해 둔 해석값 (결과와 대조하는 시험의 단언 근거)

3×3 평균의 가중: 중심 1/9, 이웃 8 개 각 1/9. 혼합 후 계수: 중심 `(1−m) + m/9`, 이웃 각 `m/9`.

| 값 | 식 | m = 0.3 | m = 0 |
|---|---|---|---|
| 열 교대 줄무늬 응답(내부) | `(1−m) + m·(1/3)` (3 열 평균 = (+A −A +A)/3 = A/3) | **0.8** | **1** |
| 체커보드 응답(내부) | `(1−m) + m/9` | **0.7333** | **1** |
| 평탄 잡음의 표준편차 비 | `sqrt(((1−m)+m/9)² + 8·(m/9)²)` | **0.7394** | **1** |
| 균일 프레임의 단차 | `m·(원본 − 테두리 값)` | `0.3·(원본 − 테두리)` | **0** |

시험은 이 값들을 **단언**한다(식의 확인이지 합격선이 아니다). 비교 결과(K1~K4)와 라벨은 단언하지 않고 출력한다.

## 6. 이탈 규칙

- 결과를 본 뒤 문턱(1.0 포인트, 0.1 %, 0.02, 0.9)이나 행 구성을 바꾸지 않는다.
- 구현 중 사전 등록한 조건을 지킬 수 없는 일이 생기면(예: 시험 실행 파일이 어떤 행을 만들 수 없음) 그 사실과 실제로 한 일을 보고서의 "이탈" 절에 적는다.
- 라벨 A·B·C 중 무엇이 나와도 같은 형식으로 보고한다.
