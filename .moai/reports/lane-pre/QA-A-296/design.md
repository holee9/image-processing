## 1. 포화값 [2판 전면 정정]

### 1.1 변수 정의 (필수 1)
- `r_i` = 파이프라인에 들어온 원입력(호출자 버퍼의 uint16 값, 온도·offset·비선형 이전).
- `z_i` = 온도·offset·비선형을 거친 이득 단계 입력.
- `g_i` = 스칼라 이득 맵 값(로드 때 범위 밖 값은 1.0 으로 바꾸고 결함 목록에 올린다).
- 포화 판정은 **`r_i ≥ L` 에서만** 한다. `z_i` 로는 판정하지 않는다.

### 1.2 마스크 생성 시점·수명·aliasing (필수 1)
- 별도 마스크 버퍼를 만들지 않는다. 포화 처리는 `pipeline_core` 안에서, 스칼라 이득 단계가 `OK` 로 끝난 직후 **한 곳**에서 일어나며 거기서 호출자 입력 `img->data`(= `r`)를 읽는다.
- 근거(코드 확인): 작업 버퍼가 필요한 경로(`widen`)는 호출자 프레임을 복사해서 쓰고, 그렇지 않은 경로는 단계마다 자기 버퍼를 만든다. `img->data` 는 파이프라인이 끝나기 전에 쓰이지 않는다(`pipeline.cpp` 마지막 복사). 이 읽기는 **파이프라인 호출 안에서만** 유효하다는 것이 계약이다.
- 단독 호출 `xpe_gain_correct`/`_in` 에는 포화 처리가 없다(원입력 `r` 을 모른다). 변하지 않는다.
- 입력이 uint16 이 아니면(float 입력 등) 포화 처리는 적용되지 않고 §1.4 의 경보 규칙을 따른다.
- 출력 버퍼가 입력과 같아도(제자리) 문제가 없다: 읽기는 이득 단계가 끝난 시점이고, 그때까지 `img->data` 는 호출자 값 그대로다(작업 버퍼 경로) 또는 별도 버퍼가 출력이다.

### 1.3 설정 키와 캘 파일 기록 [2판: 평면 키]
- 파이프라인 키 `saturationLevel`: 정수 `1..65535` 또는 문자열 `"off"`. 그 밖의 값(0, 70000, 소수, 다른 문자열, 대소문자 다른 `"OFF"`)은 `XPE_ERR_CONFIG_INVALID`. 중복 키는 기존 규칙대로 거부.
- 이득 파일 config 블록의 **최상위 평면 키** (config 읽기 도구가 최상위 스칼라만 읽으므로 1판의 중첩 객체 대신 평면 키로 바꿨다):
  `saturation_status`("determined"|"undetermined"), `saturation_level`(정수 1..65535, determined 일 때만), `saturation_method`("histogram_top_pile/1"), `saturation_min_count_frac`, `saturation_min_ratio`, `saturation_max_above_frac`, `saturation_frames_used`, `saturation_frames_total`, `saturation_decided_at`(UTC ISO 8601).
- 파일 형식 버전은 올리지 않는다(config 블록은 임의 JSON 객체).

### 1.4 우선순위, "없음", 적용 범위 [2판: 필수 2·3, Q4]
- 우선순위: 명시 설정 > 파일 기록 > 없음.
- **포화 처리와 S_out 상한은 스칼라 이득 경로에서만 켠다.** 다항식 이득, 이득 없음, `bypassGain`, 입력이 uint16 이 아닌 경우에는 끈다. 이때 `saturationLevel` 이 `"off"` 가 아니면 호출당 경보 1건(`XPE_WARN_SATURATION_NOT_APPLIED`, 이유 포함)을 낸다. 다항식 경로에 단조성이나 CV=0 을 주장하지 않는다(다항식은 `x/g(x)` 가 감소할 수 있다 — Reviewer 예: g=x²).
- 스칼라 경로에서 수준이 없으면(설정 없음, 파일 기록 없음 또는 undetermined): 포화 처리 끔(현재 출력과 비트 동일), 호출당 경보 1건 `XPE_WARN_SATURATION_UNSET`. `"off"` 는 의도한 끔이므로 경보 없음. 경보는 파이프라인 호출당 최대 1건이며 하위 함수에서 중복 발행하지 않는다(경보 이름으로 구별).
- 임의 기본값(12800·65535)은 넣지 않는다.

### 1.5 손상된 캘 파일 [2판: 필수·Q3, 리더 결정 4]
- 키가 없는 옛 파일과 `undetermined` 는 "없음"으로 읽는다.
- 형식 손상(문자열 level, 정수 아님), 범위 밖(0, 65535 초과), 비유한값, 상태 모순(`determined` 인데 level 없음, `undetermined` 인데 level 있음, 알 수 없는 status)은 **이득 파일 로드 오류**(`XPE_ERR_CONFIG_INVALID`)이며 기존 로드 상태를 바꾸지 않는다. 명시 설정이 있어도 손상된 파일을 정상으로 숨기지 않는다.

### 1.6 출력 규칙과 S_out [2판: 필수 2]
- 유효 이득 집합: 로드된 스칼라 평면 전체(결함으로 분류된 화소는 이미 1.0 으로 바뀌어 있다). `S_out = L / median(g)`, `median` 은 평면의 정렬 n/2 번째 값(짝수 개 평균 아님), 로드 때 한 번 계산한다. 카드 문구의 C 는 **C′**(BrightAvg 평균 규칙, 변경 없음)이며 `g = B/C′` 이므로 `L·C′/median(B)` 와 같은 식이다.
- 유효하지 않은 `median`(0, 비유한, 평면 없음) 이면 `S_out = 0` 으로 보고 포화 처리를 건너뛴다(출력 범위 초과는 `L/median ≤ 65535/0.1` 로 float 안에서 안전).
- `r_i ≥ L` 인 화소 → `S_out`. 그 밖의 화소 → `min(z_i/g_i, S_out)`.
- 결함 단계와의 우선순위: 포화 처리가 먼저, 결함 보정이 나중이다. 결함 화소는 포화여도 결함 보정이 값을 정한다. 이 순서 때문에 결함 화소의 이웃이 바뀌면 결함 화소 값이 바뀔 수 있다(의도).

### 1.7 단조성의 범위 [2판: 필수 3]
- 보장은 **스칼라 이득 경로, 고정된 `g_i>0`, `z` 가 `r` 의 비감소 함수일 때** 한 화소에서 `r → 이득 단계 출력` 이다: `min(z/g, S_out)` 은 `z` 의 비감소, `r=L` 에서 `S_out` 으로 올라가거나 같다.
- `r → z`(온도·offset·비선형)의 단조성은 보장하지 않는다. 시험은 비선형을 우회한 구성에서 단언한다. 최종(결함 보정 뒤) 출력의 단조성은 주장하지 않는다.
- 다항식 경로: 포화 처리를 끄므로 단조성 주장 없음.

### 1.8 회귀 모집단과 cap [2판: 필수 4, 리더 결정 1]
- **비트 동일 대상**: `r < L`, `z/g ≤ S_out`, 결함(결함 맵 ∪ 이득 분류)이 아닌 화소.
- **의도한 영향 집합**: `r < L` 이고 `z/g > S_out` 인 화소(cap 에 걸림). 비트 동일을 요구하지 않고, 장당 개수와 변화량(최소·중앙·최대)을 따로 센다. 포화 화소(`r ≥ L`)와 결함 화소 및 그 이웃은 각각 따로 센다. 기대값을 낮춰 초록으로 만들지 않는다.

## 2. 포화값 결정 (캘 생성) [2판: 필수 5]
- 규칙 판 `histogram_top_pile/1`, 프레임별로 적용한다(프레임을 합산하지 않는다).
  - 입력: 프레임의 uint16 값. 알려진 결함 화소는 히스토그램에서 뺀다(생성 시점에 로드된 결함 맵이 있고 크기가 같을 때만; 없으면 빼지 않는다). 분모 `total` = 센 화소 수(결함 제외 뒤). `total = 0` 이면 이 프레임은 후보 없음.
  - 위쪽에서 아래로 값 `v` 를 훑는다(`v ≥ 65`; 아래 64칸이 항상 존재). 점유된 값마다: (1) `v` 보다 큰 화소 수 > `max_above_frac·total` 이면 중단(맨 위 몰림 없음). (2) 개수 `c ≥ min_count_frac·total` 이 아니면 다음 값으로. (3) `c ≥ min_ratio·max(1, 아래 64칸 중앙값)` 이면 `v` 가 후보. 중앙값은 64개를 정렬한 31·32번째 평균이다(numpy.median 과 같음). 가장 위에서 처음 만족한 값 하나가 후보이며 동률 문제가 없다.
  - 프레임 간: 후보가 있는 프레임이 ≥1 이고 그 후보들이 **모두 같은 값**이면 `determined`(그 값). 후보가 서로 다르면 `undetermined`. 후보 있는 프레임이 0 이면 `undetermined`. 후보 없는 프레임이 섞여 있는 것은 허용한다(포화까지 노출하지 않은 프레임). `frames_used` = 후보가 있는 프레임 수, `frames_total` = 전체.
  - 임계값 유효 범위: `min_count_frac ∈ (0,1]`, `min_ratio ≥ 1`, `max_above_frac ∈ [0,1]`; 범위 밖 값은 무시하고 기본값을 쓴다(기록에는 실제 사용한 값이 들어간다). 기본값은 2G 자료에서만 맞춘 값이다.
  - `decided_at` 은 생성 시각(UTC). 자동 L 갱신은 하지 않는다.
- 취득 절차: "포화까지 노출한 bright 1장 이상"이 필요하다는 문장을 `modules/preprocess/docs/` 쪽 새 문서에 쓴다(Q6 수용: 더러운 `docs/calibration/*` 는 건드리지 않는다. 정식 캘 문서 연결은 리더가 정한다).
- **실행 시 감시 [2판]**: "제한된 경보 휴리스틱"이다. 포화 처리가 켜진 호출에서 16행마다 한 행의 히스토그램(결함 맵 화소 제외)에 같은 규칙(`max_above_frac` 만 0.5% 로 완화)을 적용해 설정값과 다른 값에 몰림이 보이면 경보만 낸다. 값을 바꾸지 않고, 몰림을 반드시 찾는다는 보장은 하지 않는다: 16행 간격과 같은 주기의 줄무늬, 작은 밝은 영역은 놓칠 수 있고, 표본이 적은 작은 프레임은 몰림 기준(≥50개)을 못 채워 침묵한다. 시험으로 표본 누락과 오경보(설정값과 같은 값에 몰릴 때 경보 없음)를 확인한다.

## 3. 줄 결함 보간 [2판: Q7]
- 대상: 버전 1 결함 맵(결함 맵 ∪ 이득 분류 목록)의 **가로로 연속한 길이 ≥ 8 의 결함 구간**. 세로는 구현했으나 **기본 끔**(리더 결정 5). 같은 자료로 고르고 같은 자료로 평가한 수치(세로 41.484 < 50.857, 가로 48.275 ≤ 48.28)는 독립 검증이 아니며, `kMinRun=8` 도 독립 확인 대상으로 둔다. QA 독립 재현 뒤 리더가 켤지 정한다.
- 구간별로 줄 건너편(위·아래, 최대 8칸, 결함 화소는 건너뜀)의 가장 가까운 정상 화소 둘에서 선형 보간한다(소수 유지, 내림 없음). 한쪽만 있으면 그 값을 쓴다. 양쪽 다 없으면 건드리지 않고 기존 경로가 처리한다.
- 선행 패스가 처리한 화소는 `visited` 로 표시하고, 그 뒤 기존 경로는 표시된 화소를 **재군집하지 않는다**: 표시된 화소는 군집 탐색의 이웃으로도 들어가지 않으므로 이미 채운 줄 화소가 `cluster.positions` 에 다시 들어가지 않는다. 읽기는 정상 화소만이고 쓰기는 결함 화소만이라 제자리 호출에서도 안전하다.
- 키 `defectLineInterpolation`: `"off"`(옛 동작), `"rows"`(기본), `"rows_cols"`. 단독 호출 `xpe_defect_correct`(옵션 없음)는 옛 동작 그대로다.
- 시험: 폭 1·3 줄, 8 미만 구간·고립·군집 불변(비트 비교), 프레임 가장자리, 가로세로 교차(세로 켠 경우), 세로 기본 끔, 소수 유지, 잘못된 키 거부, 각각 반증 팔.

## 4. 속도
- 프로파일 완료(측정: `evidence/profile_stage4_measured.txt`). 전체 ~90 ms = 이득 18~27 + 결함 53~55 + 기타 5. 결함 단계는 영상 밖 띠(이득 분류 화소 ~36.8만)의 군집 처리가 40~50 ms.
- 최적화는 출력 비트 동일을 유지한다. 후보: 군집 판정을 이웃 검사로 치환(BFS 제거), 화소별 채움 병렬화, 이득 단계 검증 벡터화·병렬화. 각 단계는 비트 비교로 확인한다.

## 5. 하지 않는 것
