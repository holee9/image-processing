## §0. 대각 차분의 √2 보정 유도 (카드 1항)

두 화소 차 `n1 - n2` 의 분산은

```
Var(n1 - n2) = Var(n1) + Var(n2) - 2·Cov(n1, n2)
```

백색 잡음이면 **0이 아닌 모든 변위에서 Cov = 0** 이다. 변위가 1화소(수평·수직)든
√2화소(대각)든 상관없다. 따라서 `Var = 2σ²`, 곧 보정계수는 대각에서도
**축 방향과 똑같이 1/√2** 다. 화소 간 거리가 √2 라는 사실은 보정에 들어오지 않는다.

이 유도는 **백색 잡음 가정에 의존한다.** 잡음이 상관되어 있으면 ρ(1) ≠ ρ(√2) 이므로
네 방향의 보정계수가 서로 달라야 한다. 실제 검출기 프레임이 백색인지는 이 카드에서
확인하지 못했다(§4 참조). §5 에 반증으로 이 유도를 시험했다.

## §4. Gaps — 관측하지 않은 것

1. **운영 추정기는 바꾸지 않았다.** `ComputeGlobalSigma` 는 여전히 min(h,v) 다. 이 카드의
   Bm4 는 실험 TU 안에만 있고, DLL 경로에서는 한 번도 실행되지 않았다
2. **3072² 에서 재지 않았다.** §2-3 의 3072² 수치는 화소수 9배 단순 외삽이며 측정이 아니다.
   캐시 거동이 달라 실제로는 더 나쁠 수 있다
3. **시간은 프레임당 1회 측정**이다. 워밍업·반복·중앙값 없이 단발이라 ±수 ms 는 잡음이다.
   1.95배라는 배수 자체는 7프레임 모두에서 일관되지만, 자릿수 이상의 정밀도는 없다
4. **checker2 의 2.05× 는 원인만 지목하고 고치지 못했다.** 네 방향 전부 오염된 프레임에서
   min 이 무엇을 해야 하는지는 이 카드 범위 밖이다
5. **실제 검출기 프레임은 여전히 하나도 쓰지 않았다.** 7종 전부 모사다.
   A-47 의 단서 — "생성기가 표현하지 못하는 구조에 결함이 숨는다" — 는 그대로 남아 있다
6. **잡음의 백색성을 확인하지 않았다.** §0 유도의 전제이며, 상관 잡음이면 네 방향의
   보정계수가 서로 달라야 한다
7. α·β 기본값은 건드리지 않았다(카드 범위 밖)

## §5. 반증 — 빌드 결과 포함

**가설**: "대각은 화소 거리가 √2 이므로 축 방향보다 더 큰 보정이 필요하다."

**조작**: `estDiffMadMin4` 의 대각 두 패스에만 추가로 1/√2 를 곱했다
(`consider(madOf(d) * 0.70710678f);`, 2곳).

**빌드 결과** (`a50-falsify-build.log`):
```
[1/2] Building CXX object modules\preprocess\CMakeFiles\xpe_struct_frames.dir\tools\xpe_struct_frames.cpp.obj
[2/2] Linking CXX executable bin\xpe_struct_frames.exe
BUILD_EXIT=0
```
컴파일·링크 모두 실제로 다시 돌았다 — 낡은 바이너리가 통과를 위장한 경우가 아니다.

**측정 결과** (`a50-falsify.log`, Bm4 열):

| frame | 정상 | 반증판 |
|---|---|---|
| uniform | 1.00x | **0.71x** |
| scatter | 0.99x | 0.70x |
| edge | 1.39x | 0.98x |
| lines | 1.00x | 0.96x |
| checker2 | 2.05x | 1.45x |
| checker8 | 1.15x | 0.92x |
| diag | 1.00x | 0.71x |

**판정: 가설은 거짓.** 구조가 전혀 없는 uniform 에서조차 σ 를 29% 낮게 읽는다. 백색
잡음에서는 대각도 축과 같은 1/√2 라는 §0 유도가 맞다. 그리고 이 오류는 **조용하다** —
낮게 읽힌 σ 는 바닥을 낮춰 과검출로 나타나며, 추정기 자체는 아무 신호도 내지 않는다.
(A-48 에서 리더가 "√2 보정을 빠뜨리지 말라"고 못박은 것과 같은 함정의 반대 방향이다.)

**복원 확인**: `a50-restore-build.log` exit 0, 컴파일+링크 재실행, `a50-restore-check.log`
에서 uniform 이 1.00x 로 돌아왔다.

## §7. Residual-risk — 남는 위험

1. **min 을 4개로 늘리면 하향 편향이 커진다.** 여러 표본의 최솟값은 구조가 없어도
   기대값이 내려간다. uniform 에서 1.00× 가 유지된 것은 표본이 100만 개라 각 방향의 MAD
   분산이 극히 작기 때문이다. **작은 프레임이나 ROI 단위로 쓰면 같은 보장이 없다** —
   방향 수를 늘릴수록 이 위험은 커진다
2. **모사가 실제를 대표하는지는 여전히 모른다.** diag 가 고쳐졌다는 것은 "45° 줄무늬라는
   *내가 만든* 구조가 고쳐졌다"는 뜻이다. 실제 해부학적 구조가 네 방향 모두에 걸치면
   checker2 쪽에 가깝게 행동할 것이다
3. **백색 잡음 전제가 깨지면 §0 유도가 깨진다.** 상관 잡음에서는 대각 보정이 축과 달라야
   하고, 그때 Bm4 는 방향마다 다른 계수를 요구한다. 실제 프레임 없이는 확인 불가
4. **C4 의 1% 상한 위반이 α·β 결정을 되돌릴 수 있다.** (α=0.95, β=1.2) 권고는 Bm 기준으로
   나왔다. Bm4 를 넣으면 그 권고가 *필수 조건*이 된다 — 두 결정이 이제 분리 불가다
5. 3072² 실측 없이 외삽한 시간으로 성능 판단을 하면 틀릴 수 있다
