## 1. 방향 (게이트 선이 행인가 열인가)
- 저장소 안의 근거는 문서뿐이다: `docs/calibration/xray-detector-calibration-prd.md` 의 "Row Defect — TFT gate line 고장"(815행)과 "Gate line 고장 → 전체 행(row) defect"(3249행). 데이터 파일 형식(README)은 행 우선(row-major) 저장이라고만 하며 하드웨어 방향을 말하지 않는다. 검출기 사양서는 찾지 못했다 → 게이트 방향 = 행은 **문서의 가정이고 하드웨어로 확인하지 못했다.**
- 데이터에서 보이는 방향: 다크의 프레임별 행 평균 시간 잡음과 열 평균 시간 잡음의 크기를 비교한다(261: σ_row 0.898, σ_col 0.193 pixel values). 이 분해에서 같은 비교를 모든 프레임에 한다. 행이 열보다 3배 넘게 크면 "움직이는 줄 잡음은 행 방향"이라고 적는다(방향 사실). 하드웨어 원인은 가설로만 쓴다.

## 2. 분해 (프레임마다, 합이 전체와 맞게)
대상: 공식 FlatResidualPct 를 잰 보정 영상 `Bright_17~36` 20장(현재 게인 맵 = 그룹 C = 23~28, 깨끗한 1판 세트 `clean_set_v1`; DLL 의 `xpe_gain_correct` 출력). 정규화: Y/평균(Y) − 1 =: y (평균 0). 전체 분산 V_tot = 표본 분산이 아니라 모집단 분산 var(y)(ddof=0)로 분해하고, 공식 값(ddof=1)과는 N/(N−1) = 1 + 1.06e-7 배만 다르다는 것을 표에 확인으로 적는다(공식 FlatResidualPct² 와 V_tot·N/(N−1) 의 상대 차 < 1e-6 을 단언).

**순서 A (기본)** — 직교 사영을 차례로 뗀다, 합이 정확히 맞는다:
1. 행 평균 a_i (3072개) → 행 성분 R. 2. 그 나머지의 열 평균 b_j → 열 성분 C. (이 둘은 직교하는 가산 분해: 사각형 격자 위의 행·열 분산 분석이다.)
3. 나머지의 64×64 블록 평균 m_b (48×48개) → 저주파 성분 L.
4. 나머지 화소장 e: 결함 집합 D 에 속한 화소의 e² 합/N = 결함 성분 Dfx, 속하지 않은 화소의 e² 합/N = 백색 성분 W. D = (깨끗한 1판 결함 맵 ∪ 깨끗한 2판 결함 평면의 0 이 아닌 화소) ∪ (그 프레임에서 |e| > 6 × 1.4826 × MAD(e) 인 외톨이 화소). 세 부분 집합의 화소 수와 기여를 따로 적는다(맵에 든 것 / 맵에 없는 외톨이).
합: R + C + L + Dfx + W = V_tot 가 프레임마다 1e-12 이내로 맞아야 한다(단언).

**순서 B (순서 의존성 확인)** — 블록 평균(저주파)을 먼저 뗀 뒤 나머지의 행, 열, 결함, 백색. 두 순서의 성분 값을 나란히 적고, 성분마다 범위(최소~최대 %)를 적는다. 단 순서 B 에서는 행 성분이 블록 평균을 뗀 뒤의 행 평균이다.

**움직이는 것과 고정된 것 (행·열·저주파·백색 각각)**: 같은 선량 그룹 안의 프레임들(그룹 A=17~19, B=20~22, C=23~28, C-eval=29·30, D=31~33, E=34~36; 263 과 같은 그룹)에서, 성분 c 의 프레임 k 값 c_k(행이면 행 프로파일, 열이면 열 프로파일, 저주파면 48×48 블록 평균, 백색이면 결함이 아닌 화소의 e)와 그룹 평균 c̄ 의 차의 에너지로
- 움직이는 성분(프레임 k) M_c,k = (n/(n−1)) · ‖c_k − c̄‖² / N  (프레임 하나의 비편향 추정, n = 그룹 장 수; 에너지는 분산 단위로 N 으로 나눈 값),
- 고정 성분 F_c,k = V_c,k − M_c,k (음수가 나오면 음수 그대로 적는다: 추정 잡음).
백색 성분은 같은 방식으로 "시간 백색"(M)과 "고정 화소 무늬"(F, 이 데이터에서는 게인 맵 잡음 σ/√6 이 들어간다)로 나눈다. 결함 성분은 나누지 않는다. 그룹 C(23~28)는 게인 맵을 만든 프레임이라 고정 성분이 맵과 상쇄되어 표시된다(자기 표본, 평가 값으로 쓰지 않고 표에서 표시한다).
감도 확인 한 가지를 미리 정한다: 그룹 A 는 첫 프레임 `Bright_17` 이 불안정하다는 263 사후 분석이 있으므로, 그룹 A 의 움직이는 성분을 `18, 19` 두 장만으로도 계산해 병기한다(그룹 평균을 두 장으로).

**양자 잡음 예측**: 그룹마다 오프셋을 뗀 원시 프레임의 화소별 시간 분산(행·열 평균을 뺀 것; 262 의 vg 와 같은 정의)의 중앙값 nominal_g 에 v0 + κ·S_g 를 최소제곱으로 맞추고(S_g 는 그룹의 평균 순신호), 게인 보정 뒤 상대 분산의 예측 = (v0 + κ·S_g)/S_g² 를 측정한 시간 백색 M_W 와 비교한다. 두 값이 20 % 이내로 맞으면 "시간 백색 = 양자 잡음 + 판독 잡음 예측과 일치"라고 적는다.

**진폭 표 (카운트 단위)**: 움직이는 행 성분 σ_row,k = √(M_R,k · N / W) (행 평균 하나의 표준편차, 상대 단위) × 평균 순신호 S_k 를 화소값으로. 다크에서는 화소값 그대로. 선량과 무관하게 일정하면 가산형(판독 전자회로 기원), 신호에 비례하면 곱셈형(선량·이득 기원)이라는 사실 구분에 쓴다. 신호에 대한 제곱 합 적합 σ² = a + b·S² 의 a, b 를 적는다.

## 3. 다크
같은 분해를 `Dark_07~16` 에 한다(보정 = 원시 − offset 맵의 부호 있는 부동소수점 차이, 0 바닥 없음; offset 은 깨끗한 1판 세트의 것=Dark_08~14 의 평균). 분산 단위는 화소값². 움직이는/고정 분리의 그룹은 `Dark_08~16` 9장(첫 다크 `Dark_07` 제외, 259 의 정책)이고 `Dark_07` 은 따로 표시한다. 자기 표본: `Dark_08~14` 는 offset 을 만든 프레임이라 고정 행·열이 0 으로 눌린다 → 평가 값은 `Dark_15, 16`(안 쓴 두 장)과 `Dark_07`(첫 다크)이고 8~14 는 참고로 표시한다. 결함 집합은 밝은 프레임과 같은 규칙.

## 4. 합성 대조 (먼저 돌려 단언)
768×768, 4장 한 그룹. 알려진 성분을 넣는다: 고정 행 σ 0.0020, 움직이는 행 σ 0.0030, 고정 열 σ 0.0015, 움직이는 열 σ 0.0010, 고정 저주파(격자 주기 384, 진폭 0.002), 움직이는 저주파(진폭 0.0008), 결함 40화소(+0.05), 시간 백색 σ 0.008, 고정 화소 무늬 σ 0.003. 단언: 각 성분 분산이 넣은 값(백색의 행·열 누출 σ²/폭을 더한 것)과 상대 15 % 이내, 합이 전체와 1e-12 이내. 음성 대조: 백색 잡음만 → 행·열·저주파·움직이는 성분 합이 전체 분산의 1 % 미만. 순서 B 에서도 같은 단언. 양성 개별 대조: 움직이는 행만 넣은 영상에서 움직이는 행 성분이 전체의 90 % 이상.

## 5. 예측 (결과 전)
- P1 방향: 다크의 움직이는 행 σ 가 움직이는 열 σ 의 3배 이상(261: 0.898 대 0.193).
- P2 **움직이는 행의 몫은 작다**: 프레임별 FlatResidualPct 분산의 2 % 미만(그룹 B~E), 그룹 A 도 `Bright_17` 외에는 5 % 미만. 근거: 다크의 움직이는 행이 0.9 화소값이고 `Bright_17` 의 신호가 2,735 화소값이면 상대 0.033 %, 분산 몫 약 0.07 %. `Bright_17` 은 첫 프레임 효과(263 사후 분석: 초과분의 44 % 가 행 성분)로 행·열·저주파 몫이 5~15 % 로 크다.
- P3 시간 백색의 몫: 그룹 A 75~90 %, B 80~90 %, C-eval 75~85 %, D 55~70 %, E 40~55 %. 양자 잡음 예측과 20 % 이내 일치.
- P4 고정 화소 무늬(백색의 고정 부분, 게인 맵 잡음)의 몫: A 3~8 %, B 8~12 %, C-eval 10~15 %, D 20~30 %, E 30~45 %(263 의 고정 0.24 % 일정과 선량이 올라 총 분산이 준 효과).
- P5 결함(맵 + 외톨이)의 몫: 3 % 미만.
- P6 다크의 움직이는 행 σ 와 밝은 프레임(안정한 그룹 B~E)의 σ(화소값)가 서로 ±50 % 이내(가산형). 신호에 비례하면 반증.
- P7 순서 의존성: 성분마다 범위가 0.5 %p 이내, 행 대 저주파는 2 %p 이내.

## 6. 판정 규칙 (사실 분류)
- 프레임의 (움직이는 행 + 움직이는 열) 몫 < 5 %: "게이트 방향 줄 잡음은 이 프레임의 FlatResidualPct 의 주된 원인이 아니다", 20 % 이상: "주된 원인의 하나".
- 시간 백색 몫이 가장 크면: 한계는 양자 잡음에서 오고 프레임 수·선량으로만 줄어든다(보정으로 줄지 않음; 평가 정의 문제).
- 고정 화소 무늬는 게인 프레임 수로 줄어드는 성분(√ 법칙; 이번 카드에서 재지 않음).
- 결함 성분이 5 % 이상이면 결함 처리가 원인.
각 성분에 "게인 보정으로 줄일 수 있는가 / 프레임별 행 보정 같은 다른 처리가 필요한가"를 적는다. 추정은 "가설"로 표시한다.

## 7. 표준 방식과의 대조 (리더 20:05 요청: TG-150 식 34~37, EMVA 4.0 식 32)
원문은 직접 내려받아 열어 확인했다(AAPM TG-150 PDF 80~82쪽, EMVA 1288 Release 4.0 General 13~14쪽). 인용은 아래 식이고 모두 PDF 텍스트에서 읽었다.
- **TG-150 §4.3.9 방법 A**: 식 (34) 행·열 프로파일 P_n^row = 한 행의 모든 화소 평균, P_m^col = 한 열의 모든 화소 평균. 식 (35) D_n = P_n − (P_{n−1} + P_{n+1})/2. 식 (36) SD_row, SD_col = 프로파일의 표준편차(분모 N−1). 식 (37) 상관 없는 잡음의 예측 SD_row = N̄_IR/√N_rows, SD_col = N̄_IR/√N_cols (원문 표기를 그대로 따르면 N_rows·N_cols 는 한 프로파일을 이루는 평균 개수의 이름이다. 3072 × 3072 에서는 어느 쪽으로 읽어도 √3072). N̄_IR 은 식 (26): ROI 화소 표준편차 제곱의 평균의 제곱근. ROI 는 §4.3.2 가 "작은 ROI(1~2 cm)를 영상 전체에 겹치지 않게 깔라"고 하며 화소 간격을 모르므로 **64 × 64 화소 블록 48 × 48 개**로 정한다(블록 크기는 데이터를 보기 전에 정한다). 원문은 이 값이 "예측을 크게 넘으면 상관 잡음"이라고만 하고 **한계값은 없다**(§4.3.9 "currently unavailable").
- **EMVA 4.0 §4.3**: 식 (32) s²_y = s²_y.row + s²_y.col + s²_y.pixel. 식 (33) 평균 행·평균 열·평균. 식 (34)(35) 열·행 공간 분산은 평균 행·평균 열의 분산에서 s²_y.pixel/M 과 σ²_y/(LM)(열), s²_y.pixel/N 과 σ²_y/(LN)(행)를 뺀 것. 식 (36)(37) 세 식의 선형 연립. 식 (38)(39) **정확한 풀이**(M = N = 3072). 식 (31): L 장 평균 영상의 공간 분산은 σ²_y/L 를 뺀다. σ²_y 는 식 (57): 화소별 시간 분산의 평균(L−1 로 나눔).
- 이 카드에서 하는 일: (a) 프레임마다 TG-150 의 P, D_n, SD_row, SD_col 과 예측 SD_row, SD_col 의 **비**를 낸다. D_n 은 |D_n|/σ_D(σ_D 는 평가 도구의 줄 지표와 같은 정의: 상관 없는 잡음 예측)의 최대와 3 초과 개수를 낸다. 대상은 단일 보정 평탄 영상 20장(게인 보정 출력)과 다크 `Dark_07~16`(부호 있는 offset 보정). (b) EMVA 의 식 (39) 를 **그룹 평균 영상**(L = 그룹 장 수, σ²_y 는 그룹의 화소별 시간 분산의 평균)과 **단일 프레임**(L = 1, σ²_y 는 같은 그룹의 것)에 적용하고, 위 분해의 행(R)·열(C)·화소(L+결함+백색) 분산과 나란히 놓아 어긋남을 숫자로 적는다. EMVA 4.0 은 저주파 성분을 별도 항으로 두지 않아(8.1 은 상위 통과 필터로 억제한다) 이 분해의 저주파 L 은 EMVA 의 pixel 항에 들어간다: 이 차이를 어긋남의 알려진 원인으로 미리 적는다.
- 예측: P8 다크의 SD_row/예측 ≥ 10, SD_col/예측 ≤ 3 (261: σ_row 0.898 대 예측 N̄/√3072 ≈ 0.05). 평탄 영상은 저선량(그룹 A·B)에서 SD_row/예측 1.3~2.5, 고선량(D·E)에서 1.0~1.5, `Bright_17` 은 그룹 A 의 나머지보다 크다. P9 EMVA 식 (39) 의 row, col 은 이 분해의 R, C 와 총분산의 1 % 이내로 같고(누출 항 차이), pixel 은 L + 결함 + 백색과 총분산의 5 % 이내.
- 중요한 구분(미리 적는다): TG-150 의 비(상관의 유무)와 분산 예산의 몫(FlatResidualPct 에 대한 기여)은 다른 질문이다. 비가 크더라도 몫이 작을 수 있다. 둘 다 적는다.

## 범위와 한계 (미리 적는다)
한 검출기·한 세션·선량 5단계이고 그룹당 2~6장이라 움직이는 성분의 비편향 추정은 변동이 크다(그룹 C-eval 은 2장). 방향은 문서 근거와 데이터 비교이며 하드웨어 사양으로 확인하지 못했다. 게이트 방향 줄 잡음의 위상(프레임 안에서 행이 읽히는 시각에 따른 선량 변화)은 보지 않는다.
