## 2. 사용자 질문에 대한 사실 답
"검증 영상의 FlatResidualPct 는 라인성 노이즈인가, defect 인가?" — **둘 다 아니다.** 첫 프레임 `Bright_17` 을 뺀 19장에서 FlatResidualPct 분산의 98.3~99.7 % 는 화소별 백색 잡음이고(시간 64~97 % + 고정 화소 무늬 3~35 %), 줄·열·저주파 구조는 합쳐 0.3~1.7 %, 결함 화소는 0.03 % 다. 행·열·저주파·결함 성분을 전부 뗀다고 해도 공식 값은 `Bright_20` 에서 0.7844 → 0.7831 %, `Bright_29` 0.6428 → 0.6417 %, `Bright_31` 0.4867 → 0.4857 %, `Bright_34` 0.4127 → 0.4099 % 로 바뀔 뿐이다(표 1 의 행·열·저주파·결함 합으로 계산).
단일 프레임 FlatResidualPct 1 % 한계를 넘는 프레임(`Bright_17~19`)은 저선량이라 시간 백색 잡음(양자 잡음)이 분산의 76~97 % 를 차지해서 넘는다. 이것은 보정으로 줄지 않는다(프레임 수·선량으로만 준다).

## 3. 방향 (게이트 선이 행인가 열인가)
- 문서 근거: 저장소 PRD 가 "Row Defect — TFT gate line 고장", "Gate line 고장 → 전체 행(row) defect"(`docs/calibration/xray-detector-calibration-prd.md` 815, 3249행)로 쓴다. 리더가 확인한 문헌(Xerox US6734414, Siemens US7965333)도 영상의 행 = 게이트 선, 데이터 선 = 열이다. 데이터 파일 형식(README)은 행 우선 저장만 말하고 하드웨어 방향을 말하지 않으며 검출기 사양서는 찾지 못했다 → **하드웨어 확인은 못 했다.**
- 데이터에서 보이는 방향(사실): 다크의 움직이는 행 진폭이 **0.898 화소값**, 움직이는 열 진폭이 **0.121** 로 7.4 배 차이다. TG-150 비(SD/예측)도 다크에서 행 15~16, 열 1.9~2.3 이다. 프레임마다 움직이는 상관 잡음이 행 방향에 있다.

## 8. 합성 대조 (먼저 돌려 단언, `evidence/31_selftest_result.txt`)

## 10. 미검증 (Gaps)
- 한 검출기·한 세션이다. 그룹당 2~6장이라 움직이는 성분의 비편향 추정은 변동이 크다(C-eval 은 2장).
- 게이트 방향은 문서와 데이터의 방향 비교이며 하드웨어 사양으로 확인하지 못했다. 움직이는 행의 원인(전자기 간섭·바이어스 변동 등)은 이 데이터로 구분하지 못했다.
- 프레임 안에서 행이 읽히는 시각에 따른 선량 변화(`Bright_17` 의 매끈한 구조의 원인 후보)는 보지 않았다.
- 결함 집합은 깨끗한 세트의 맵 + 6σ 외톨이이고, 맵 밖의 약한 결함은 백색에 섞인다.
- 사후(방법에 없던) 분석: 표 3 의 누출 보정 진폭과 그룹 A 를 뺀 적합, 그룹 A 의 `Bright_18`·`19` 변형 외에는 없다.
- TG-150 의 ROI(64×64)는 화소 간격을 몰라 정한 값이다.
