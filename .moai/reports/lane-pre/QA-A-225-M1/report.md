## 2. 무엇을 단언하고 무엇을 단언하지 않는가

단언하는 것(모두 기계적 사실):

- 생성기가 자기 정의를 만족한다. T1 은 닫힌 형태로 검사한다: `h(0) = b0 + Σb_n = 1`, `h(j>0) = Σ b_n e^(−a_n j)`로 양수이며 감소, 정상상태 이득 `1 + Σ b_n/(e^(a_n) − 1)`. T2 는 "노출이 커질수록 첫 빈 프레임의 상대 지연이 줄어든다"는 설계 주장.
- 지표 코드가 대조군에 대해 맞는 답을 낸다: 보정 없음 = 제거율 0 %, 참 노출을 돌려주는 오라클 = 100 %·보존 1, 모든 값을 0 으로 만드는 보정기 = 빈 프레임 제거율 100 %이면서 보존 0, 모든 프레임에 +100 ADU 를 더하는 보정기 = 제거율 0 %(같은 경로의 암 기준이 상쇄), `LagRaw(k=1)`이 생성기에서 직접 계산한 값과 일치, 보존 구간(50번째 프레임부터)이 직접 평균과 일치.
- 하네스가 결정적이다(잡음은 시드 고정). 모듈 호출이 전부 성공하고 출력이 전부 유한하다.
- 교정되지 않은 핸들(QA-A-226)은 모든 프레임을 그대로 두므로 제거율이 정확히 0 %다.
- 양성 대조(자기 모델)는 일부러 독립이 아니다: 모듈의 재귀로 만든 지연을 같은 설정이 100 % 되돌린다. "지표 코드가 100 %를 말할 수 있다"는 뜻이지 모듈에 대한 증거가 아니다.

단언하지 않는 것: 모듈의 `GhostRemovalPct`·신호 보존·계단 잔차가 얼마여야 하는지. D1 이 정해지기 전에는 어떤 값도 합격선으로 굳히지 않는다.

## 3. 독립성과 생성기의 한계

- 생성기는 모듈 소스를 가져오지 않고 모듈의 `alpha`·`tau`로 지연을 만들지 않는다(설계 메모 R4).
- **T1**: Starman 외 2012(Med Phys 39:6035) 식 (1)의 이산 LTI 임펄스 응답, **참 노출**로 구동. `a_n`/`b_n`은 TDS-CALIB-001 4.4.2 가 "Varex 4030CB"로 적은 값이다. 합성한 첫 빈 프레임 지연은 **3.0851 %**이고 노출 수준과 무관하다(LTI 라서). 논문 Table 3 의 보정 전 27 % 값 2.8 %보다 높다. TDS 의 `b_n·a_n`이 논문 값인지는 **미확인**이다(설계 메모와 같은 결론).
- **T2**: 논문의 식이 아니라 이 프로젝트의 정식화다. 추세만 쓴다. 측정한 첫 빈 프레임 지연은 2 % 1.8953 %, 27 % 1.4532 %, 92 % 0.9051 %로 노출이 커질수록 줄어든다(방향은 논문 Table 3 의 3.7/2.8/2.4 %와 같고 크기는 작다).
- T3(멱함수)와 T4(실장비)는 없다. 저장소에 노출 → 빈 프레임 시퀀스가 있는 실데이터가 없다(설계 메모 2.3).

## 5. 읽는 법 — 값이 말하는 것 (해석은 제 읽기이며 판정이 아니다)

1. **빈 프레임 제거율은 보존이 0.31~0.90 인 보정기도 100 %로 읽는다.** 잡음 0 의 모듈 36행은 k=1·10·50 모두 제거율이 정확히 100.00 %이고, 같은 36행의 신호 보존은 정상 노출에서 0.9020 이하다. 신호 보존이 0.995 이상인 모듈 행은 72행 중 **0건**이다. 모듈이 출력을 0 이하에서 0 으로 자르고 빈 프레임의 참값이 0 이라 과보정이 보이지 않는다. 설계 메모 2.2 의 결론이 QA-A-226 이후의 모듈과 명시 설정으로 다시 확인됐다. 빈 프레임 지표를 단독 합격 근거로 쓰면 `control:zeros`(보존 0)도 통과한다.
2. **계단 하강은 그 과보정을 드러낸다.** 새 수준이 0 이 아니라 클램프가 가리지 않는다. 임의 설정 12행 모두 k=1 에서 새 수준 대비 **−57.2 % ~ −100 %**의 부호 있는 잔차를 낸다(보정 전은 T1 +17.19 %, T2 +7.96 %). 즉 이 설정들은 지연을 지우는 대신 신호를 깎는다.
3. **잡음 σ = 5 ADU 에서는 0 이하 클램프가 암 프레임을 정류한다.** 잡음 σ = 5 의 모듈 36행에서 k=50 제거율은 −340.73 %에서 99.09 % 사이이고 36행 중 16행이 음수다. 원인은 이 보고서에서 확인하지 않았다(가설: 잡음이 있는 암 프레임의 클램프 정류와 과보정이 DarkRef 와 빈 프레임을 서로 다르게 편향시킨다). T2 의 k=50 은 `LagRaw`가 0.0056 % 로 작아 제거율의 분모가 작다는 점은 관측이다.
4. **교정되지 않은 핸들은 정확히 0 %**: 보정 없음 대조군과 같은 값이다(QA-A-226 의 통과 동작이 지표로도 보인다).
5. **티어별 차이**(설정·진실·수준·잡음의 24가지 조합을 세었다): 티어 2 의 보존은 24가지 모두에서 티어 1 보다 낮고, 티어 3 은 16가지에서 낮고 8가지에서 높다. 가장 크게 깎인 행은 T1·92 %·잡음 0·0.1/1/0.01/20 설정의 티어 2(보존 0.3063)다. 티어 2 가 일관되게 더 깎는 것은 노출 가중치(최대 1.5 배 이상)와 맞는 방향이지만, 원인을 이 보고서에서 따로 확인하지는 않았다.
