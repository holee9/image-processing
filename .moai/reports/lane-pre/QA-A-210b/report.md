# QA-A-210b — 실제 보정 데이터에서 게인 다항식 생성 측정 (Refs #233)

측정 카드(수정 없음). 기준 커밋 `63559d35`. 증거: `evidence/02_measure.txt`(출력 전문), `evidence/10_m210b.py`(측정 스크립트), `evidence/01_data_stats.txt`.

## 1. 입력 (실제 데이터)

`image-processing/tests/test_data/cyan_test/`(Cyan FPD, 3072×3072 = 9,437,184 화소): `calfiles/CalSet_{14037,17285,20985,30868,42677}.raw` 5개 준위 + `MasterDark.raw`. CalSet 은 암전류 위에 얹힌 원본이다(MasterDark 평균 11020.6, CalSet 평균 13887.8…40509.0). 선량 값은 저장소 어디에도 없으므로(CalData_6 README 와 같은 사정) 두 가지 축으로 재었다.

| 선량 축 | 값 |
|---|---|
| (가) 암전류 보정 평균 신호(ADU) | 2867.2 / 5931.5 / 9283.1 / 18485.6 / 29488.4 |
| (나) 파일 이름의 숫자(README 4.2 가 선량으로 쓴 값) | 14037 / 17285 / 20985 / 30868 / 42677 |

게인 맵은 제품이 만들었다(`xpe_calib_generate_gain`, 준위당 1프레임, 평균 1.000000, 범위 0.696–1.157). 다항식은 제품의 `xpe_calib_generate_gain_polynomial` 이 만들었고, 갈래별 화소 수는 같은 정책의 독립 numpy 복제로 셌다. **대조군**: 복제의 R² 가 제품이 파일에 쓴 `fit_r_squared` 와 일치한다(차이 1e-10, 3차는 float 정밀도로 1e-7).

## 2. 결과

| | (가) 2차 | (가) 3차 | (나) 2차 |
|---|---|---|---|
| 제품 `fit_r_squared` | **-0.0352** | **-0.0347** | +0.0481 |
| 최고 차수 최소제곱 채택 화소 | 6.87% (2차) | 1.65% (3차) + 5.78% (2차) | 6.90% |
| 1차 최소제곱 채택 | 44.19% | 43.63% | 44.17% |
| **끝점 직선 갈래** | **48.94%** (4,618,176) | **48.94%** | **48.94%** |
| 끝점 화소 중 1차 최소제곱 기울기 음수 | 100% | 100% | 100% |
| 화소별 R² < 0 | 33.2% (전부 끝점 화소) | 33.2% | 34.1% |
| 끝점 화소만의 합산 R² | -0.303 | -0.303 | -0.142 |
| 최고 차수 화소만의 합산 R² | 0.420 | 0.735 (3차) | 0.420 |

- 끝점 갈래의 비율(48.9%)은 선량 축에 의존하지 않는다(가·나 동일). R² 의 값은 축에 따라 달라진다(-0.035 ↔ +0.048).
- 끝점 화소 전부가 음의 기울기인 것은 정의상이다: "비감소" 검사를 통과하지 못했다는 것이 곧 1차 최소제곱 기울기가 음수라는 뜻이다(기울기가 0 이상이면 1차에서 채택된다).
- 음의 기울기의 크기: 선량 범위 전체에서 줄어드는 양 |기울기×범위| 은 중앙값 3.2e-3, 95% 9.9e-3, 최대 3.0e-2 (게인 평균 1). 같은 화소들의 준위 간 흩어짐(자기 평균 둘레 rms)은 전 화소 중앙값 2.9e-3, 95% 5.9e-3. **감소량이 준위 간 흩어짐과 같은 크기**다.

## 3. 해석 (측정으로 말할 수 있는 만큼)

1. 실제 데이터에서도 QA-A-210 의 합성 픽스처와 같은 구조다: 화소의 절반이 끝점 직선으로 가고, 그 화소들의 모델은 최소제곱해가 아니라서 풀드 R² 가 0 근처 또는 음수가 된다. 합성(51%)과 실제(48.9%)가 비슷하다.
2. 게인 맵을 화소 평균으로 정규화하기 때문에 준위 간 변화는 거의 모두 (프레임 잡음 + 미세한 에너지 의존)이고 그 크기는 3e-3 수준이다. 끝점 화소의 "감소"는 이 변화와 같은 크기이므로, 데이터는 이 화소들에서 "선량에 따라 게인이 변한다"는 증거를 거의 주지 않는다.
3. 이 입력에서 `calibration_pass`(R² ≥ 0.999)는 어느 축에서도 0 이다. 즉 이 데이터셋으로는 게인 다항식 보정이 품질 게이트를 통과하지 못한다.

## 4. 미검증 (Gaps)

- **준위당 프레임이 1장**이라 프레임 잡음을 따로 재지 못했다. "잡음과 같은 크기"는 준위 간 흩어짐과의 비교이지 잡음 추정이 아니다. 잡음을 재려면 같은 준위의 반복 프레임이 필요하다(`Bright_17..36` 이 반복인지는 이 카드에서 확인하지 않았다).
- **진짜 선량은 모른다.** (가)는 신호 평균, (나)는 파일 이름의 숫자 — 둘 다 대리값이다. 이 둘이 같은 갈래 비율을 내므로 갈래 결론은 축에 둔감하지만 R² 값은 아니다.
- 결함 화소(`BPM.raw`)를 제외한 측정은 하지 않았다(전 화소).
- CalData_6 은 이 워크트리에 원본이 없고 선량이 없어 쓰지 않았다(README 정정 2026-09-19). 다른 검출기·다른 수의 준위에서의 비율은 미측정.
- 생성기 정책을 바꾸는 것(끝점 직선 폐지 등)은 이 카드 범위 밖이다. 이 측정은 그 결정의 근거 자료다.
