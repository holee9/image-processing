## 2. 구현 (정의 문서와 같음) — 그리고 "새 상수 없음"의 정정

정의: 선량 그룹마다 순신호 평균 y_g, 반복 수 m_g, 공칭 분산 v⁰_g(기존 `groupNom`). 화소 비의존 가중 w_g = m_g/v⁰_g 로 직선을 맞추고(닫힌 형태), 가중 잔차제곱합 Q′ 를 그 화소 자신의 풀링 순수 오차 φ(공칭 대비 시간 분산 비)로 나눈 로그-F 비 T = ln(Q′/(G′−2) + 1e-9) − ln(max(φ, 0.1)) 를 기존 `kKindLinearity` 입력(`rowStretches` 의 이웃 대비 강건 z)으로 쓴다. 줄 검출 실행(`job`)에서만 계산하며 화소당 double 3개 + float 1개가 추가된다.

**앞서 "새 상수는 없다"고 쓴 것은 틀렸다(Codex #227). 문턱 λ 는 기존 목표 오경보 예산에서 나오는 그대로지만, 아래 상수는 통계값을 바꾸는 정책이다.** 모두 구현 전에 정의 문서에 고정했고 이번 데이터 결과를 보고 고르지 않았다.

| 상수 | 값 | 근거 | 시험이 고정하는가 |
|---|---|---|---|
| φ 하한 | 0.1 | 시간 분산이 공칭의 10 % 아래인 화소(죽은 화소·상수열)가 분모를 0 에 가깝게 만들어 곡률을 만들어 내지 못하게 하는 방어. 선택의 통계적 유도는 없다(경험적 정책) | **아니오 (U9 생존).** 순수 함수 시험은 `lack_of_fit_feature` 의 하한을 고정하지만 호출부의 상수 0.1 은 변이(1e-12)가 시험을 통과한다. 하한 아래의 저잡음 줄에서의 민감도는 시험하지 않았다(합성 양성의 최저 잡음 κ×0.25 는 φ ≈ 0.3 로 하한 위) |
| 풀링 자유도 최소 | 5 | 자유도 2 인 그룹이 많아 분산 추정이 불안정, F 의 분산이 유한하려면 ν > 4 | 예(U7 적중) |
| 순수 오차 그룹 수 최소 | 3 (G′ ≥ 3) | 직선 적합의 자유도 G′−2 ≥ 1 | 부분적(U8 은 동등 변이: 함수 쪽 문이 같은 일을 함) |
| 포화 수준 | 그룹 평균 원값 ≥ 65500 | 클리핑이 곡률처럼 보이는 것을 막음 | 예(U5 적중) |
| 로그 보호 | + 1e-9 | Q′ = 0 에서 −∞ 방지 | 순수 함수 시험(유한 확인) |

공개하는 공백: 풀링은 "선량별 분산의 모양은 공칭과 같고 크기만 화소마다 다르다"는 가정이다. 효율 r 줄의 분산 r²v0 + κ r S 는 이 주입에서 공칭 대비 비가 선량마다 0.597~0.600(r=0.6)으로 거의 상수라 영향이 작았지만, 모양이 크게 다른 줄은 시험하지 않았다(이분산 음성 형태 하나만 있음).
