QA-A-258 1번 — 정의와 예측 (코드·시험·측정보다 먼저 커밋한다)

근거: Codex #226 발견 5~7, NIST e-Handbook 의 lack-of-fit(§4.4.6)과 가중 최소제곱(§4.1.4.3). B16 기준표는 바꾸지 않는다. 이 문서의 숫자는 구현·시험 결과를 보기 전에 고정한다.

## 1. 정의

**대상.** 줄 검출기의 직선성 원인(`XPE_BPM_LINE_CAUSE_LINEARITY`)을 판정하는 특성 하나. 화소 검출기의 `DOSE_LINEAR` 특성(화소 지도용), 응답·기울기·잡음 원인, 판 1 경로, 줄 구간을 찾는 창 통계(`rowStretches` 의 이웃 대비 강건 z 와 문턱 λ)는 바꾸지 않는다. 문턱은 기존 목표 오경보 예산(`target_false_alarms`)에서 나오는 그대로이고 새 상수를 고르지 않는다.

**기호.** 화소 i, 선량 그룹 g = 1..G(그룹당 프레임 수 m_g, 신호 S_g = 그룹 평균 순신호), 그룹 평균 n_{g,i} (다크 수준 D_i 를 뺀 값). 순수 오차(같은 선량 반복의 시간 분산): s²_{g,i} = 노출 정규화한 프레임의, 행·열 평균을 뺀 값의 그룹 평균 주변 변동(ν_g = m_g − 1 자유도). 이 값은 코드에 이미 있는 `vg` 와 같고 선량 간 곡률을 포함하지 않는다.

**공칭 분산(선량별, 화소 비의존).** v⁰_g = `groupNom[g]` (그룹 g 의 국소 중앙 기대 분산의 중앙값, 기존 값). 평균의 공칭 분산 = v⁰_g / m_g.

**가중과 적합.** 가중치는 화소에 의존하지 않는 w_g = m_g / v⁰_g. 화소마다 y = a·S + b 를 이 가중으로 맞춘다(닫힌 형태: 화소 의존 합 Wn=Σw n, Wsn=Σw S n, Wnn=Σw n² 와 스칼라 합 W0, W1, W2 만으로 계산, 정규방정식 det = W2·W0 − W1²). 가중 잔차제곱합:

  Q′_i = Wnn − a·Wsn − b·Wn.

**화소의 순수 오차 풀링(자유도 ν = Σ ν_g).** φ_i = ( Σ_g ν_g · s²_{g,i} / v⁰_g ) / ν. 공칭 대비 이 화소 자신의 시간 분산 비. 즉 이웃이 아니라 **그 줄 자신의** 순수 오차이고, 선량마다 추정한 분산 s²_{g,i}(자유도 2 인 그룹이 많아 불안정)을 하나의 비로 풀링한 것이 풀링 정책이다. 풀링은 "선량별 분산의 모양은 공칭과 같고 크기만 화소마다 다르다"는 가정이며, 모양이 다른 경우(효율 저하: 분산이 r²v0 + κ r S)에는 아래 §3 의 영향이 있다.

**통계.** Q_i = Q′_i / φ_i 가 아니라 로그 F 비로 둔다:

  T_i = ln( Q′_i / (G′ − 2) + 1e-9 ) − ln( max(φ_i, φ_min) ),   φ_min = 0.1.

G′ = 순수 오차가 있는 그룹 수(반복 2 이상). 이 T_i 가 기존 `rel` 특성(로그 잔차 분산 − 2 ln|기울기|) 자리에 들어가 `kKindLinearity` 로 `rowStretches` 에 들어간다. 로그 차이이므로 상수 이동에 불변이고 이득 띠도 분모의 φ 에서 같이 나눠진다(기존의 −2 ln|a| 보정은 불필요).

**분포에 대한 입장.** Q 를 정확한 χ²(G′−2)라고 단정하지 않는다. 공칭 가중이 맞고 시간 분산이 공칭의 배수 φ 라면 Q′/φ 는 대략 (G′−2)·F(G′−2, ν) 형태의 로그-F 이며, 추정 분산·이분산·공간 상관 아래에서의 꼬리는 §3 의 귀무 합성 시험으로 확인하고 문턱은 기존 예산에서 정한다. 새 문턱 상수는 없다.

**실패 처리 (모두 "직선성 증거 없음", 0 으로 중립화. 가짜 곡률로 읽지 않는다).**
- G′ < 3 (순수 오차가 있는 선량 그룹이 3 개 미만): 줄 직선성 특성 전체를 쓰지 않는다(옛 통계로 되돌아가지 않는다). 풀링 자유도 ν < 5 도 같다(분산 추정이 너무 불안정).
- 화소의 풀링 분산 φ_i 가 유한하지 않거나 ≤ 0 : T_i = 0. φ_i 는 φ_min = 0.1 로 아래에서 자른다(죽은 화소·0 분산이 분모를 0 에 가깝게 만들어 곡률을 만들어 내지 못하게).
- 포화: 어떤 그룹의 평균 원값이 65500 이상이면 그 화소는 T_i = 0.
- 선량 퇴화: det ≤ 1e-9·W0·W2 이면 특성 전체를 쓰지 않는다.
- 비유한 Q′: T_i = 0. 음수 Q′(수치 오차)는 0 으로 자른다.

**메모리.** 줄 실행(`job`)에서만 화소당 double 3 개와 float 1 개를 추가한다. 화소 지도 경로는 그대로다.

## 2. 검증 시험의 설계 (정답을 읽지 않는 별도 생성기와 오라클)

시험 파일 `tests/test_bpm_lines_lof.cpp`. 생성기는 주입 도구와 무관하게 시험 안에서 평균 응답 f(S)와 시간 분산 v(S)를 정해 프레임을 만든다(256×256, 다크 8장 raw 목록 + 밝은 영상 5개 선량 그룹). 기대값은 오라클이 독립적으로(그램-슈미트 직교화, 구현의 닫힌 형태와 다른 방법) 계산한다: 잡음 없는 곡선의 가중 선형 투영 잔차 λ_nc = min_{a,b} Σ_g (m_g/v_g)(f(S_g) − a S_g − b)².

**음성 대조 (직선 평균 응답 → λ_nc = 0).** 형태 5: 효율 0.6(분산 r²·v0 + κ r S), 효율 0.44, 이득 0.7(분산 r²(v0 + κ S)), 밝은 영상만의 오프셋 +150, 이분산(분산 v0 + κ S (1 + S/30000)). 선량 설계 2: {3,3,6,3,3} 와 {2,3,4,5,6}. 시드 10. 총 100 실행. 각 실행은 한 행(전체 길이)과 한 열(전체 길이)에 서로 다른 형태를 넣는다.
- **예산 (고정):** 심은 행·열을 덮는 줄 그룹에 직선성 비트가 켜진 실행이 100 중 **2 건 이하**. 그리고 심은 줄 밖을 포함해 직선성 그룹의 총수가 실행당 평균 1 이하(목표 오경보).
- **수정 전 코드가 이 시험에서 빨개야 한다**(시험이 실제 실패를 재현하는지의 확인): 효율 0.6 형태에서 옛 통계가 직선성을 켜는 실행이 30 % 이상. 그렇지 않으면 합성 생성기가 실제 현상(양자 잡음 줄)을 못 담은 것이므로 생성기를 고치고 다시 한다(결과를 본 뒤 예산을 바꾸지 않는다).

**양성 대조.** nonlinear c ∈ {0.4, 0.2} (주입의 정의 f(S) = S·(1 − c·S/30000)), 시간 잡음 κ 배수 ∈ {0.25, 1, 4}, 형태 5: 전체 행, 전체 열, 부분 행(96 화소), 두 줄 쌍(인접 두 행), 교차(행+열). 시드 4. 총 30 조합 × 4 = 120 실행.
- 오라클 λ_nc (선량 {2836.65, 5871.31, 9193.33, 18297.17, 29178.97}, 프레임 수 {3,3,6,3,3}, v = 9 + 0.3·κ배수·S): c=0.4: 16,835 / 4,259 / 1,068; c=0.2: 4,209 / 1,065 / 267 (κ 배수 0.25 / 1 / 4). 설계상 가장 약한 경우도 267 (G′−2 = 3 이므로 기대 로그-F ≈ ln(267/3) ≈ 4.5).
- **기대 검출력 (고정):** 120 실행 중 심은 줄 구간의 90 % 이상을 덮는 직선성 그룹이 있는 실행이 **114 이상(95 %)**, 어떤 조합도 4 시드 중 3 미만이 아니다. 허용 후퇴 없음(후퇴가 있으면 결과로 문턱을 바꾸지 않고 설계로 되돌아가 원인을 본다).

**변이 시험(다른 축 분리).**
- 선형 + 고잡음(읽기 잡음 ×4, κ ×4): 잡음 원인은 켜지고 직선성은 꺼져야 한다.
- 비선형 + 저잡음(κ ×0.25): 직선성이 켜지고 잡음 원인은 꺼져야 한다.
- 잡음만 큰 줄(잡음 결함)은 지금처럼 잡음 원인으로 검출된다(후퇴 없음).

**순수 함수 단위 시험.** 닫힌 형태 가중 적합(`weighted_lack_of_fit`)을 오라클(그램-슈미트)과 무작위 입력 1000개로 비교(상대 오차 1e-9), 곡선이 없으면 Q′ ≈ 0 인 것, 실패 처리 각 경우의 중립화를 단언한다.

**변이(반증) 시험.** (a) 가중을 균일로 바꾸기 → 이분산 음성 또는 양성이 깨짐, (b) φ 를 나누지 않기(Q′ 만 쓰기) → 효율 음성이 깨짐, (c) 순수 오차를 선량 간 SSE 로 추정하기 → 양성이 깨짐(곡률이 분모에 흡수), (d) 옛 통계로 되돌리기 → 효율 음성이 깨짐, (e) 포화 중립화 삭제, (f) φ_min 삭제. 각 변이가 어떤 시험을 빨갛게 하는지는 실행 전에 `evidence` 의 변이 설정에 예측으로 적는다.

## 3. 알려진 한계 (미리 적는다)

- 풀링은 선량별 분산의 **모양**을 공칭과 같다고 가정한다. 효율 r 줄의 분산은 r²v0 + κ r S 라 모양이 다르다(공칭 대비 비가 선량마다 r²~r 사이에서 변함: 0.6 일 때 0.597~0.600, 0.44 일 때 0.437~0.440 — 쇼트 잡음이 지배하는 이 주입에서는 거의 상수). 모양 차이가 큰 가상의 줄에서는 Q′/φ 의 기대가 1 에서 벗어나며, 이것은 음성 시험(이분산 형태)의 예산으로 본다.
- 평균 응답이 곡선인데 잡음이 매우 크면(λ_nc 가 G′−2 근처) 검출력이 없다. 설계 최악 267 은 그보다 훨씬 크다.
- 줄의 공간 상관과 겹친 창은 독립 화소 수로 꼬리를 과장하지 않는다: 문턱은 기존 `rowStretches` 의 경험적 영분포 폭(경험 null width)에서 나오며 이번 변경으로 그 방법은 바뀌지 않는다.
- 현재 주입 데이터(252f)에서 정상 효율 0.6 띠의 위치·강도·정답을 이미 보았다. 그러므로 같은 데이터 재측정은 "개발 회귀"이며 독립 검증이 아니다. 별도 고정 합성 시드 하나로도 한 번 잰다(측정 단계, 리더의 "측정 시작" 신호 뒤).

## 5. 정정 (16:32, 구현 전·새 통계의 어떤 결과도 보기 전): 시험 규모

옛 통계로 시험 한 벌을 돌려 보니 256×256 영상 한 장의 검출이 약 0.37 초라 100 + 120 영상은 약 80 초가 걸린다(CI 에서 5 번 돈다). 그래서 §2 의 설계는 그대로 두고 규모만 둘로 나눈다.
- 전체 규모(§2): `DISABLED_FullBudgetOfOneHundredImages`(음성 100, 예산 2 건 이하·그룹 총수 100 이하), `DISABLED_FullPowerOfOneHundredTwentyImages`(양성 120, 114 이상·모든 조합 3/4 이상). 평소에는 안 돌고 `--gtest_also_run_disabled_tests` 로 직접 돌린다. 구현 뒤 한 번 돌려 결과를 보고서에 싣는다.
- CI 부분집합(같은 형태, 시드만 적음): 음성 20 영상(형태 5 × 설계 2 × 시드 2) — 예산 1 건 이하, 직선성 그룹 총수 20 이하. 양성 30 영상(조합 30 × 시드 1) — 29 이상. 시드 번호는 전체 규모의 앞 시드와 같다.
- 수정 전(옛 통계) 결과를 `20_old_statistic_results.txt` 에 남겼다: 음성 20 중 14 영상에서 거짓 직선성(효율 0.6 5, 효율 0.44 8, 이분산 4), 양성 30 모두 통과, 선형 + 고잡음 4/4 가 직선성으로 켜짐(분리 시험 실패). 효율 0.6 형태에서 옛 통계가 켜는 비율은 전체 규모 기준 25/40 = 62.5 % 로 §2 의 "30 % 이상" 조건을 만족했다(생성기가 실제 현상을 재현한다). 예산·기대는 이 결과를 보고 바꾸지 않았다.

## 6. 별도 고정 합성 시드 (측정 2, 실행 전에 기록)

환경변수 `XPE_LOF_SEED_OFFSET=77000` 로 전체 규모의 두 시험(`DISABLED_*`)을 각각 한 번 돌린다. 모든 시드가 77000 만큼 이동한다(개발 중에 돌린 시드와 겹치지 않는다: 개발은 offset 0, 시드 1000~1100·5000~5300·8000~9200). 예산과 기대는 §2 와 같다: 음성 100영상에서 심은 줄 위 거짓 직선성 2 건 이하, 직선성 그룹 총수 100 이하; 양성 120영상 중 114 이상, 모든 조합 3/4 이상. 한 번만 돌리고, 결과를 보고 설계·문턱을 바꾸지 않는다. 시험 코드 변경은 이 환경변수 읽기 한 곳뿐이다.
