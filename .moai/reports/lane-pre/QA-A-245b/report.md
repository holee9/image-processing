# QA-A-245b — gain -17 이 10-03 DLL 에서만 난 이유, calib-real-v2 gain 값 범위

## 1. 결과

| 질문 | 답 |
|---|---|
| 10-03 DLL 은 같은 a240b gain 을 -17 로 거부했고 10-07 DLL 은 통과시킨 이유 | **FUNC-002 의 처리 방식이 바뀐 커밋 `56a05cc5` (QA-A-211, 2026-10-02 14:28, dev/preprocess)** 의 유무. 그 전의 적재기는 범위 밖 화소가 **하나라도** 있으면 맵 전체를 `XPE_ERR_INVALID_CALIB_DATA`(-17)로 거부했고, 그 뒤는 범위 밖 화소를 결함으로 분류하고 적재한다 |
| 10-03 DLL 이 왜 그 커밋 없이 만들어졌나 | 파일 시각은 10-03 이지만 **그 커밋이 없는 소스에서 빌드된 것**이다 (§3 의 문자열 대조). 어느 트리에서 빌드했는지는 확인하지 못했다 |
| `calib-real-v2` gain 값 범위 | 최소 0, 최대 29.3285, 중앙값 1.0206, `[0.1, 10]` 밖 **44,053 화소 = 0.4668 %** (§4) |

제품 코드 변경은 없다 (조사와 측정만).

## 2. 무엇이 바뀌었나

- **이전 (`56a05cc5^`, `src/xpe_calib_load_gain.cpp`)**: `SRS-CALIB-FUNC-002 "Values shall be in range [0.1, 10.0]; out-of-range values shall trigger XPE_ERR_INVALID_CALIB_DATA error"` 를 적재 때 맵의 모든 화소에 적용해, `!(값 >= 0.1 && 값 <= 10.0)` 인 화소가 하나라도 있으면 `return XPE_ERR_INVALID_CALIB_DATA` (`evidence/20_loader_before_56a05cc5.txt`).
- **이후 (`56a05cc5`)**: 범위 밖 화소는 **결함으로 분류**하고(gain 은 1.0 으로 대체, 색인은 결함 단계에 넘김), 알림 `XPE_WARN_GAIN_PIXELS_CLASSIFIED_DEFECT` 를 낸다. 분류된 비율이 `XPE_GAIN_DEFECT_MAX_FRACTION` (5 %, 241 에서 잠정값으로 표시)를 넘을 때만 이전처럼 `XPE_ERR_INVALID_CALIB_DATA` 로 거부한다 (`evidence/21_loader_at_56a05cc5.txt`).
- 5 % 한도 상수(`0.05`)는 이 커밋 때부터 있었다. 241 계열이 바꾼 것은 한도의 **잠정** 표시와 근거 문서뿐이고, 이번 차이는 241 이 아니라 **QA-A-211 (10-02)** 이 만든다. (카드가 짐작한 "241 계열의 FUNC-002 화소 결함 분류" 는 이 커밋이다. 241 보고서의 "gain 범위 밖 비율 상한(5 % 잠정)" 은 그 한도를 잠정으로 적은 것이다.)
- a240b 맵(6 장 평탄으로 만든 gain, `build/a240b/maps/gain.xcal`)은 범위 밖 화소가 **42,026 개 (0.4453 %)** 다. 이전 규칙은 한 화소만 있어도 거부하므로 이 맵은 이전 적재기에서 반드시 -17 이고, 이후 적재기는 5 % 미만이라 적재한다. 즉 gui 가 본 두 결과는 모두 해당 코드의 정확한 동작이다.

## 3. 10-03 DLL 이 이전 코드였다는 증거 (추정이 아니라 관측, 단 소스는 미확인)

## 4. `calib-real-v2` gain 값 범위

`xpe-data/calib-real-v2/gain.xcal` (페이로드 = 파일 끝의 3072×3072 float32; 스크립트 `evidence/10_gain_range.py.txt`, 출력 `evidence/11_gain_range_values.txt`). 같은 스크립트가 센 범위 밖 화소 수 44,053 이 앱의 알림 숫자(44,053 / 0.467 %)와 같아서 읽은 위치가 맞다는 대조가 된다:

| | `calib-real-v2` (평탄 4·5·6) | a240b (평탄 6 장) |
|---|---|---|
| 최소 / 최대 | 0 / 29.3285 | 0 / 15.4126 |
| 평균 / 중앙값 | 1 / 1.0206 | 1 / 1.0200 |
| p0.1 / p99.9 | 0.0269 / 1.0975 | 0.0284 / 1.1058 |
| `[0.1, 10]` 밖 | **44,053 화소 = 0.4668 %** | 42,026 화소 = 0.4453 % |
| 그중 0.1 미만 / 10 초과 / 비유한 | 44,052 (정확히 0 은 1) / 1 / 0 | 42,024 (정확히 0 은 1) / 2 / 0 |
| 가장자리 64 화소 띠 안 | 44,051 | 42,023 |

범위 밖 화소의 거의 전부(99.995 %)가 프레임 가장자리 64 화소 띠 안에 있고 값이 0.1 미만이다. 한도 5 % 의 약 1/11 이다. 이전 규칙(하나라도 있으면 거부)이라면 이 세트도 -17 이다.
