# QA-A-250b — 측정 방법 (측정 전에 고정, 측정 전에 커밋)

이 문서는 v2 세트를 만들고 평가하기 전에 쓴다. 결과를 본 뒤 이 문서의 방법을 바꾸지 않는다. 바꿔야 한다고 판단되면 리더에게 보고만 한다.

## 0. 왜 다시 재는가

QA-A-250 의 카드는 `Bright_17~36` 을 "단일 선량"이라고 적었다. 실제는 다섯 선량이다 (`QA-A-250/evidence/10_data_inspection.txt`). 250 의 게인 맵은 다섯 선량 18장을 평균한 것이어서 `xpe_calib_generate_gain` 의 한 선량 가정을 어겼고, 합격은 최고 선량 두 장에서 났다. 이 카드는 결과를 바꾸려는 것이 아니라 잘못된 전제를 바로잡는 재판정이다. 250 의 결과와 기록은 그대로 남는다 (QA-A-250 보고서, 커밋 `a4222bc6`).

## 1. 분할

| 역할 | 프레임 |
|---|---|
| 게인 생성 | `Bright_23` ~ `Bright_28` (6장, 순신호 약 9.3k ADU 묶음) |
| 게인 판정 (남김) | `Bright_29`, `Bright_30` (같은 묶음의 나머지 두 장) |
| 오프셋 생성 | `Dark_07` ~ `Dark_14` (250 과 같음) |
| 결함 맵 생성 | 다크 `Dark_07~14` + 밝은 영상 `Bright_17~34` 18장 (250 과 같은 입력, 선량 혼합 허용) |

기준: 카드 그대로. 판정은 남긴 두 장에서만 낸다. 다른 선량 묶음 프레임의 잔차는 참고로 공개하고 판정에 쓰지 않는다.

## 2. 도구의 선량 혼합 거부 (측정 전에 정한 한도)

규칙: 게인용 밝은 영상(`--bright`)의 **오프셋 뺀 프레임 평균**(프레임 평균 − 다크 입력 평균들의 평균)의 최대/최소 비가 **1.25** 를 넘으면 종료 코드 12 로 끝낸다. 아무것도 쓰기 전에 끝난다. 결함 맵의 밝은 영상(`--bpm-bright`)에는 적용하지 않는다.

근거 (`evidence/10_dose_spread_basis.txt`, 250 의 밝은 영상 20장의 프레임 평균, 오프셋 수준은 생성 다크 8장 평균 11012.120 ADU):

| 수치 | 값 |
|---|---|
| 같은 선량 묶음 안의 최대/최소 비 (가장 큰 것) | 1.0712 (`Bright_17~19`, 첫 프레임의 단차) |
| 같은 선량 묶음 안의 나머지 | 1.0012 ~ 1.0059 |
| 선량 묶음 사이 단계의 최소 | 1.5593 (`Bright_23~30` 대 `Bright_20~22`) |
| 인접 비 중에서 1.0697 과 1.5593 사이 | 없음 |
| 두 값의 기하평균 | 1.2924 |

한도 1.25 는 묶음 안 최대(1.0712)보다 1.167 배 위, 묶음 사이 최소(1.5593)보다 1.247 배 아래다. 이 값은 이 한 데이터 세트에서 정했다. 선량 단계가 25 % 보다 작은 패널의 혼합은 통과시킬 수 있다.

## 3. 생성

```
xpe_calib_fixture_gen --out D:/workspace-github/xpe-data/calib-cyan-v2 --expiry-ms 4102444800000
   --compare-bpm BPM.raw
   --dark Dark_07.raw ... --dark Dark_14.raw
   --bright Bright_23.raw ... --bright Bright_28.raw
   --bpm-bright Bright_17.raw ... --bpm-bright Bright_34.raw
```

다크 참조 등 나머지는 기본값 (250 과 같음). 생성 세트는 저장소에 넣지 않는다. 250 세트(`calib-cyan-v1`)와 비교해 `offset.xcal`, `defect.xcal` 이 바이트 동일해야 한다고 예측했고 (`31_predictions…`), 하니스가 이것을 확인해 출력한다.

## 4. 평가

게인 판정은 QA-A-250 의 §3.2 와 같다:

| 항목 | 정의 |
|---|---|
| 입력 | 남긴 밝은 영상의 원시 프레임 |
| `Y` | `xpe_preprocess_pipeline_out` 의 최종 출력 (앱 구성) |
| ROI | v2 게인 맵이 유한하고 0 보다 큰 화소 |
| `FlatResidualPct` | `100 · std(Y_roi) / mean(Y_roi)`, 모집단 표준편차 |
| 판정 가능 | `mean(Y_roi) ≥ 2000 ADU` |
| 합격 | `FlatResidualPct ≤ 1.0 %` — `Bright_29` 와 `Bright_30` **모두** |

오프셋은 250 에서 판정했고 맵이 같으므로 다시 판정하지 않는다. 결함 맵의 장비 회사 비교는 `manifest.json` 의 `bpm_comparison` 에 나온다 (판정 아님). 팬텀 5장은 250 과 같은 구성과 같은 비교표로 낸다.

## 5. 실행 범위

도구 시험은 `CalibFixtureGenTest.*` 만. 생성 1회, 평가 1회. 한 번에 프로세스 하나, 각 실행 뒤 남은 프로세스 0 확인. 전체 스위트는 돌리지 않는다.
