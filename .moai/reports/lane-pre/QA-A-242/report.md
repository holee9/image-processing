# QA-A-242 — B6 평탄 잔여(1.18~3.34 %, 기준 1.0 %)의 원인

조사만 했고 제품 코드는 바꾸지 않았다. 입력은 CalData_6 평탄 6장과 제품 생성기가 만든 gain 맵(`build/a240/maps/gain.xcal`)이다. 가설과 "맞으면 무엇이 보여야 하는가"는 측정 전에 적어 두었다 (`evidence/00_hypotheses_written_before_measuring.md`). 분석 스크립트는 `evidence/flat242.py.txt`, 출력은 `evidence/10_flat_residual_analysis.txt`와 PNG 둘이다. 측정일 2026-10-05.

## 1. 결론

**원인은 제품 결함이 아니라 데이터와 측정 방법이다.** 잔여는 두 부분으로 갈라지고, 둘 다 gain 맵을 어떻게 만들어도 단일 gain 으로는 없앨 수 없다.

1. **큰 규모의 모양 차이 (전체 분산의 76~91 %)**: 평탄 6장은 서로 다른 큰 규모 음영(최대 약 6 % 의 대각선 기울기와 휨)을 가진다. 선량에 비례해서 커지거나 작아지는 것이 아니라 장마다 모양이 다르다. gain 은 이 6장을 선량 가중 평균하므로 어떤 한 장도 맞지 않는다. 판정: **촬영 조건의 차이 (H3) 지지**, 단 "노출 기하가 다르다"와 "특정 선량 위에서 응답이 꺾인다"는 이 데이터로 구별하지 못한다.
2. **화소 규모의 잡음 (선량이 낮을수록 큼)**: 샷 잡음처럼 σ ≈ 0.29·√평균(ADU) 로 움직인다. 저선량 평탄은 이것만으로 flat3 1.5 %, flat4 0.97 % 라서 1.0 % 를 넘거나 닿고, 큰 규모 성분(모양을 완벽히 맞춰도 0.3 % 남는다)과 합치면 1.0 % 아래로 내려가지 않는다.

그래서 B6 의 1.0 % 기준은 "서로 다른 조건·선량 6장으로 만든 gain 한 장 + 단일 프레임으로 잰 균일도"라는 현재 측정 방식으로는 이 데이터에서 달성할 수 없다. 이건 기준 측정 방법의 문제로 적는다 (카드 4번 항목).

## 2. 측정 정의 확인 (H0 — 기각)

정의는 프로토콜 5.3 의 `FlatResidualPct = 100·std/mean`, 대상은 gain 이 유한하고 0 보다 큰 화소 전부다. 하니스 밖(numpy)에서 다시 계산한 값이 하니스 값과 같다.

| | flat1 | flat2 | flat3 | flat4 | flat5 | flat6 |
|---|---|---|---|---|---|---|
| QA-A-240 하니스 (마스크 제외) | 1.987 | 1.171 | 3.312 | 2.411 | 2.34 | 2.30 |
| 이번 계산 (마스크 제외) | 1.987 | 1.171 | 3.312 | 2.411 | 2.343 | 2.298 |

제품 gain 맵과 "6장 평균 ÷ 전체 평균"을 numpy 로 직접 만든 것은 화소 단위로 같다 (최대 차이 0).

덧붙일 점 하나: 프로토콜의 ROI 문구("gain 이 유효한 모든 화소")대로 **결함 보정 전** gain 단계 출력에서 재면 6.5~11.2 % 가 나온다 (BPMap 화소의 65 k 값 때문). 결함 단계 뒤에 재야 1.2~3.3 % 다. 프로토콜은 어느 출력에서 재는지 적지 않았다.

## 3. 먼저 보인 구조: 생성기가 선량 가중 평균을 만든다

`xpe_calib_generate_gain.cpp` 는 평탄을 장마다 정규화하지 않고 **ADU 그대로 평균**한다. 그래서 gain 은 선량이 큰 장의 모양에 끌려가고, 장 j 의 잔여는 "그 장의 정규화한 모양이 가중 평균 모양과 다른 정도"다 (가중치 = 평균 ADU 비율).

| 장 | 평균 ADU | 가중치 | 잔여 % |
|---|---|---|---|
| flat2 | 5015 | 0.395 | 1.171 |
| flat1 | 2883 | 0.227 | 1.987 |
| flat6 | 2196 | 0.173 | 2.298 |
| flat5 | 1396 | 0.110 | 2.343 |
| flat4 | 867 | 0.068 | 2.411 |
| flat3 | 351 | 0.028 | 3.312 |

잔여는 가중치가 작을수록 단조 증가한다 (P0, 예측대로). 또 가중치를 곱해 더한 잔여 지도의 rms 는 0.0003 % 로 사실상 0 이다 (한 장의 잔여 rms 는 약 2.07 %). 즉 6장이 평균 모양에서 벗어난 만큼을 각자 나눠 가진 상태다.

"gain 을 만든 평탄 영상으로 재면 순환이라 작아야 한다"는 직관은 **한 장으로 만든 gain 을 그 장에 적용할 때만** 맞다 (교차 행렬 대각선, 0.00~1.3 %). 6장 평균 gain 은 어느 한 장의 순환이 아니고 장 사이 차이가 그대로 남는다.

### 구조를 가르는 두 실험

**① 같은 모양끼리 묶은 gain** (같은 가중 평균 방식, 표의 숫자는 잔여 %, 괄호는 16화소 이상 부분만):

| gain 의 재료 | flat1 | flat2 | flat3 | flat4 | flat5 | flat6 |
|---|---|---|---|---|---|---|
| 6장 전부 (제품) | 2.00 (1.90) | 1.19 (1.13) | 3.32 (2.95) | 2.42 (2.21) | 2.35 (2.21) | 2.31 (2.21) |
| flat 4,5,6 | 4.40 | 3.63 | 2.45 (1.43) | **1.54 (0.35)** | **1.43 (0.34)** | **1.35 (0.33)** |
| flat 3,4,5,6 | 4.42 | 3.66 | **2.32 (1.33)** | **1.54 (0.36)** | **1.43 (0.35)** | **1.35 (0.34)** |
| flat 1,2 | **0.80 (0.68)** | **0.46 (0.39)** | 4.51 | 3.73 | 3.69 | 3.66 |

굵은 글씨는 gain 의 재료인 장이다. 모양이 같은 묶음 안에서는 큰 규모 잔여가 0.33~0.36 % 로 떨어진다. 남는 1.35~1.54 % 는 거의 전부 화소 규모(샷 잡음)다. 묶음 밖은 3.6~4.5 % 로 나빠진다. **어떤 조합도 6장 전부를 1.0 % 아래로 만들지 못한다.**

**② 큰 규모 모양의 좌표를 선량 순서로 놓으면**:

| 장 | 선량 ADU | 첫 모양 위 좌표 |
|---|---|---|
| flat3 | 351 | +132.5 |
| flat4 | 867 | +103.0 |
| flat5 | 1396 | +103.2 |
| flat6 | 2196 | +103.3 |
| flat1 | 2883 | −83.6 |
| flat2 | 5015 | −53.0 |

선량이 2.5배 변하는 동안 좌표가 0.3 만 움직이고, 1.3배 변하는 한 걸음(flat6→flat1)에서 187 이 뛴다. 매끄러운 곡선으로는 이런 모양이 안 나온다. 가능한 설명은 둘이다.
- 평탄 1,2 와 3~6 이 **다른 촬영 조건**(거리·필터·관전압 등 조사장 모양이 달라지는 것)에서 찍혔다. 평탄 1 과 2 도 서로 다르니(−84 대 −53) 적어도 세 가지 조건이다.
- 약 2500 ADU 위에서 응답이 **꺾인다** (연속이 아니라 문턱이 있는 비선형).

선량·관전압·거리 기록이 저장소 어디에도 없어서(데이터셋 README 가 이미 밝힌 사실) 이 둘을 가를 수 없다. 이 부분은 **판정 불가**다.

## 6. 해석과 다음 카드 제안 (고치는 것은 다음 카드)

**이번 B6 실패는 제품 결함의 증거가 아니다.** 제품은 설계대로 "6장의 선량 가중 평균"을 gain 으로 만들었고, 그 6장이 서로 맞지 않는다. 그리고 단일 프레임으로 잰 `100·std/mean` 은 화소 잡음을 포함하는데, 저선량에서는 그것만으로 1.0 % 에 닿는다. 두 이유 모두 gain 코드를 바꿔서 풀리지 않는다 (등가중으로 바꿔도 3.0 / 2.3 / 2.3 / 1.5 / 1.4 / 1.3).

판단이 필요한 지점 (리더):
1. **B6 의 측정 방법**: 이 기준을 어떤 평탄 집합에서 어떻게 재야 하는지가 정해져 있지 않다. 지금 데이터로 의미 있는 측정은 "한 조건에서 찍은 평탄 묶음"(예: 평탄 4,5,6)을 쓰고, 프레임 평균으로 화소 잡음을 줄이고, **결함 단계 뒤 출력**에서 재는 것이다. 이 조건에서 큰 규모 잔여는 0.33~0.36 % 로 기준 안이다. 단일 프레임의 잡음 하한(≈ 0.29·√평균)은 별도의 문제라서, 선량 기준(예: 평균 ≥ 2000 ADU 에서만 판정)이나 프레임 평균 중 하나가 필요하다.
2. **데이터 메타데이터**: 평탄 1~6 이 어떤 조건에서 찍혔는지(선량, 관전압, 거리, 필터, 촬영 순서)를 아는 사람이 있으면 §4 의 "판정 불가" 하나가 풀린다. 평탄 1,2 가 다른 세션인지가 핵심이다.
3. **제품 쪽에서 볼 만한 것 (결함이 아니라 기능)**: 선량 의존 gain 다항식(`xpe_calib_generate_gain_polynomial`, FUNC-027)은 바로 이런 "선량마다 모양이 다른" 경우를 위한 것이다. 다만 이 데이터에서는 모양이 선량의 매끄러운 함수가 아니라(§4 ②) 다항식으로 맞는다는 보장이 없다. 선량 값이 없어서 평균 ADU 를 선량 대용으로 써야 하는 점도 걸린다. 다음 카드로 "다항식 gain 이 이 6장의 잔여를 줄이는가"를 재 볼 수 있는데, 위의 1·2 가 정해진 뒤가 낫다.
4. 생성기가 장을 정규화하지 않고 ADU 로 평균하는 것은 **문서에 없는 동작**이다 (코드 머리 주석은 "Pixel-wise mean" 이라고만 적는다). 선량이 크게 다른 평탄을 섞으면 큰 선량이 gain 을 지배한다. 이번 데이터에서는 등가중이 나아지지 않았으므로 우선순위는 낮지만, 의도라면 SRS 나 API 문서에 한 줄 적어 둘 만하다.

- 평탄 6장뿐이고 검출기도 하나다 (그리고 이 평탄이 같은 검출기인지는 QA-A-241 에서 "미확정").
- 선량은 평균 ADU 로 대신했다. 실제 노출량이 아니다.
- 타일 모델 비교(M0~M3)는 한 장을 뺀 5점으로 맞춘 것이라 양 끝 장(flat3, flat2)은 외삽이다. 그 결과를 "모델이 틀렸다"의 단독 근거로는 쓰지 않았고, 모양 좌표(§4 ②)와 교차 행렬을 근거로 삼았다.
- 시간적 잡음과 고정 화소 패턴은 가르지 못했다 (같은 조건의 반복 프레임이 없다). "샷 잡음처럼 움직인다"는 k 가 일정하다는 관측이고, 시간적 잡음임을 증명한 것은 아니다.
- 잔여 모양의 물리적 이름(힐 효과, 산란, 거리 변화 등)은 붙이지 않았다. 위아래 기울기가 커서 힐 효과와 닮았지만 대각선·휨 성분과 장마다 다른 방향이 있어 확인하지 못했다.
- 제품 파이프라인은 새로 돌리지 않았다. numpy 재현이 하니스 값과 같다는 것(§2)으로 대신했다.
- 이 보고서는 `moai-domain-humanize` 최종 패스를 거치지 않았다.
