# 가설과 예측 (측정 전에 적음)

QA-A-242. 이 파일은 `flat242.py` 를 처음 돌리기 전에 작성했다. 예측과 판정 기준은 측정 뒤에 바꾸지 않는다 (바꾸면 보고서에 "사후 수정" 으로 따로 적는다).

대상: CalData_6 평탄 6장(`bright01~06.raw`, 평균 2883 / 5015 / 351 / 867 / 1396 / 2196 ADU)에 제품 생성기가 만든 gain 맵을 적용했을 때 `FlatResidualPct` = 100·std/mean = 1.18~3.34 %.

## 먼저 알려진 것 (읽은 코드, 이미 확인된 사실)

`xpe_calib_generate_gain.cpp` 는 평탄 6장을 **ADU 값 그대로 평균**한다 (장마다 정규화하지 않음): `G_raw = mean_k(flat_k)`, `G = G_raw / mean(G_raw)`. 따라서 장 j 의 잔여는 `N_j / G − 1` (N_j = flat_j / mean_j) 이고, G 는 선량이 큰 장의 모양에 가중된다 (가중치 w_k = mean_k / Σmean). 즉 잔여는 "그 장의 정규화한 모양이 선량 가중 평균 모양과 얼마나 다른가" 다. 이 구조 자체가 예측 하나를 준다.

- **P0** 장별 잔여 크기는 가중치가 클수록 작아야 한다. 가중치 순서(큰 것부터): flat2 > flat1 > flat6 > flat5 > flat4 > flat3. 이 순서로 잔여가 단조 증가해야 한다 (측정치 1.18, 2.06, 2.34, 2.39, 2.46, 3.34 가 이미 그렇게 보이지만, 이 파일을 쓰는 시점에 그 의미를 가설 검증으로 확인하지 않았다).

## 가설

각 가설마다: 맞으면 무엇이 보여야 하는가 / 틀리면 무엇이 보이는가.

### H0 측정 정의와 하니스가 다르다
- 맞으면: 정의대로(프로토콜 5.3: gain 이 유한하고 > 0 인 모든 화소의 std/mean) 하니스 밖에서 다시 계산한 값이 하니스 값(1.987 1.171 3.312 2.411 2.34 2.30)과 다르다.
- 틀리면: 같은 값이 나온다 (±0.01).

### H1 (a) 오프셋 불일치 — 평탄 영상에서 뺀 암 프레임이 실제와 다르다 (가산 오차 b(x,y))
- 맞으면: 타일 평균 `T_j(t) = a(t)·m_j + b(t)` 가 성립해서, 한 장을 빼고 나머지 다섯으로 적합한 **아핀 모델(M1)** 이 빠진 장의 타일 평균을 비례 모델(M0)보다 훨씬 잘 맞힌다. 잔여는 `b(t)·(1/m_j − 1/m̄)` 모양이라 **ADU 로는 장마다 거의 같고, 백분율로는 선량이 낮을수록 크다**. 추정한 b 의 표준편차를 m_j 로 나눈 값이 장별 타일 퍼짐과 맞는다.
- 틀리면: M1 이 M0 보다 낫지 않거나, ADU 로 본 잔여가 선량에 비례해서 커진다 (flat3 의 잔여 ADU 가 flat2 의 몇 분의 1).

### H2 (b) 선량이 다른 장을 섞는다 + 응답이 선량에 비례하지 않는다 (비선형)
- 맞으면: 이차 모델(M2)이 M0, M1 보다 빠진 장을 훨씬 잘 맞힌다. 잔여 모양은 하나(rank-1)이고 진폭이 `|m_j − 가중 평균 선량|` 에 비례한다 (가중 평균 선량 ≈ 3234 ADU: flat2 와 flat3 이 가장 커야 하고 flat1 이 가장 작아야 한다).
- 틀리면: M2 가 낫지 않다, 또는 진폭 순서가 위와 다르다 (측정치는 flat1 이 2.06 으로 flat2 보다 훨씬 크다 → 이미 불리하지만 모델 적합으로 확인).

### H3 (c) 평탄 영상 자체의 조사 불균일이 장마다 다르다 (힐 효과·산란·노출 기하 차이 — 촬영 조건)
- 맞으면: **M0~M3 어느 것도** 빠진 장을 못 맞힌다 (선량만으로는 설명되지 않는 모양 변화). 잔여 지도는 **저차 매끄러운 곡면**(평면~2차)이 분산의 대부분을 설명하고, 6장의 잔여 지도가 소수의 모양(rank 1~2)을 공유한다. 행·열 띠나 화소 단위 구조가 아니라 완만한 기울기·동심원이다.
- 틀리면: 곡면 적합이 분산의 절반도 설명하지 못하고 잔여가 화소~16화소 규모에 몰려 있다.

### H4 (d) 결함 단계 뒤 계산이 결함·이상치를 포함하거나 제외하는 방식 때문이다
- 맞으면: 5 로버스트 시그마를 넘는 화소 몇 개를 자르거나 제외하면 `100·std/mean` 이 크게 줄어든다 (절반 이하). 마스크 제외 값과 "결함 단계 뒤 전 화소" 값이 크게 다르다.
- 틀리면: 이상치를 잘라도 값이 거의 그대로이고 (10 % 이내), 마스크 포함·제외 차이가 0.1 %p 안이다 (QA-A-240 에서 이미 2.062 대 1.987).

### H5 화소 잡음이 본체다 (저선량 flat3 에서 특히)
- 맞으면: 규모별 분산 중 4화소 미만 몫이 대부분이고, 자기 자신으로 만든 gain(교차 행렬의 대각선)의 잔여가 총 잔여와 비슷하다.
- 틀리면: 4화소 미만 몫이 작고 대각선 값이 총 잔여보다 훨씬 작다.

## 추가 진단 (판정에 쓰는 것)

- **교차 gain 행렬**: 장 k 한 장으로만 만든 gain 을 장 j 에 적용한 잔여 6×6. 대각선은 잡음 바닥. 비례 응답이면 비대각도 대각선과 비슷하다. 선량 차이가 클수록 비대각이 커지면 응답이 비례가 아니다 (H1/H2 쪽), 선량 순서와 무관하면 모양이 장마다 다른 것 (H3 쪽).
- **등가중 gain**(장마다 정규화해 평균): 생성기의 선량 가중이 잔여를 키우는지 본다. 등가중에서 모든 장이 같은 수준이고 그 수준이 1 % 를 넘으면 가중이 원인이 아니라 장 사이 모양 차이 자체가 원인이다.

## 판정 규칙

- 지지: 위 "맞으면" 의 항목이 모두 보인다.
- 기각: "틀리면" 의 항목이 보인다.
- 판정 불가: 둘이 섞이거나 이 데이터로는 구별되지 않는다.
- 결론이 "촬영 조건(H3)" 이면 이것은 제품 결함이 아니라 **기준 측정 방법의 문제**(서로 다른 선량·기하의 6장으로 만든 단일 gain 의 잔여를 한 장의 평탄 균일도로 읽는 것)로 적는다.
