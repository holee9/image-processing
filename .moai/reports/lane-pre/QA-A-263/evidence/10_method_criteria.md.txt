코드는 바꾸지 않는다. 라이브러리는 ctypes 로 호출한다(`20_dll.py.txt`; Codex #232 가 같은 DLL 호출로 잰 여섯 프레임의 FlatResidualPct 와 두 다크의 DarkBias 를 **소수점 아래 9째 자리까지** 재현해 호출 방식을 검증했다 — `22_dll_check_result.txt`, 최대 차이 3.45e-10). 입력은 cyan_test 의 원시 프레임 `Bright_17~36`, `Dark_07~16` 과 QA-A-260 의 깨끗한 1판 세트(`clean_set_v1`: 쓴 다크 `Dark_08~14`, 게인 `Bright_23~28`).

## 지표의 정의 (공식과 진단을 따로 둔다)
- **공식 FlatResidualPct** = 라이브러리 `xpe_verify_gain` 의 `prnu_after`: offset 보정(UINT16) → 게인 보정(FLOAT32) 프레임 **한 장**의 std/mean×100, 게인이 유한 양수인 모든 화소(촬영 영역·결함 맵 제외 없음), 시간 잡음을 빼지 않는다. SRS FUNC-017: Phase 1 한계 1.0 %, 알려진 게인 의미의 release-hardening 목표 0.5 %(라이브러리의 현재 합격선도 0.5 %). 프레임마다 두 기준 상태(1.0 % 이내 / 0.5 % 이내)를 따로 적는다.
- **진단 분해**(EMVA 1288 3.1 8.1 의 취지: 평균 영상의 공간 분산에서 시간 잡음 분산을 뺀다): 같은 선량 그룹의 보정 프레임들을 평균 1 로 정규화한 Y_j(j=1..n)에서, 총분산 V_tot,j = var(Y_j)(공식과 같은 화소 집합), 시간 분산 V_t = 화소별 프레임 간 분산(ddof=1)의 화소 평균, 고정 분산 V_fix,j = max(V_tot,j − V_t, 0). 그룹 평균 영상의 고정 분산 V_fix,avg = var(Ȳ) − V_t/n. 보고는 퍼센트(√)로: P_tot(=공식 값), P_t, P_fix, 시간 몫 V_t/V_tot,j.
- **고정 분산의 공간 모양**(그룹 평균 영상 R = Ȳ − 1에서, 시간 분산의 해당 몫을 뺀 값): 행 성분(열 방향 평균, 시간 몫 V_t/(n·W)), 열 성분, 두 성분을 뺀 나머지의 저주파 성분(64×64 블록 평균, 시간 몫 V_t/(n·64²)), 그 나머지의 국소 성분(시간 몫 V_t/n 를 뺀 값). 네 몫의 합이 V_fix,avg 와 같음을 확인한다.

## 비교 게인 맵 (코드 불변, numpy 로 만들고 한 번 라이브러리와 대조)
게인 맵 만드는 규칙은 생성 도구와 같다(내 재계산이 도구의 gain 과 상대 차이 0 임을 261 에서 확인): 순신호 = 프레임 − 정수 반올림 평균 다크(쓴 7장), 평균을 내고 전체 평균으로 나눈다. 선량 그룹: A = `17~19`, B = `20~22`, C = `23~28`(현재), D = `31~33`, E = `34~36`. 맵 X_ALL(그룹 G 평가용) = G 와 같은 그룹을 뺀 나머지 그룹들의 정규화 맵의 평균(여러 선량 평균). `29, 30` 은 그룹 C 의 평가 프레임이다. 프레임을 만든 그룹의 맵으로는 그 프레임을 평가하지 않는다(자기 표본 제외).
- 평가 지표: 프레임마다 (i) 공식 방식 FlatResidualPct(numpy; 라이브러리와의 일치를 먼저 확인), (ii) 그 맵의 잡음이 만드는 성분 예측 σ_map(X) = s_X/√n_X (s_X = 그룹 X 의 단일 프레임 상대 시간 잡음 √V_t(X), n_X = 맵을 만든 프레임 수; 게인 맵이 이 크기의 고정 무늬를 보정 결과에 새긴다), (iii) 그룹 평균 영상의 고정 성분 P_fix,avg(X).
- 라이브러리 대조 한 번: 맵 E 와 D 를 `gain.xcal` 형식으로 쓰고(복제한 헤더, 페이로드, SHA-256 갱신) 별도 프로세스에서 DLL 로 적재해 `Bright_17`, `Bright_29` 의 공식 값과 numpy 값을 비교한다(합격선 1e-4 퍼센트 포인트).

## 분류 규칙 (원인은 프레임 단위, 맵 의존성은 비교 단위)
1. **시간 잡음 우세**: 시간 몫 V_t/V_tot,j ≥ 0.6. **고정 구조 우세**: 시간 몫 ≤ 0.4. 사이는 혼합.
2. **한 선량 게인 맵이 원인** (알고리즘 개선 대상): 프레임 f 에 대해, f 의 그룹을 쓰지 않은 다른 맵 중 최선 맵의 그룹 평균 고정 성분 P_fix,avg 가 현재 맵(C)의 값보다 **30 % 이상** 작고, 그 감소가 맵 잡음 성분 예측의 차 √(σ_map(C)² − σ_map(X)²) 로 설명되는 양보다 클 때. 감소가 맵 잡음 차로 설명되면 "게인 프레임 수·선량 문제"(데이터 한계).
3. **요구 해석 문제**: 공식 FlatResidualPct 가 1.0 % 를 넘는데 시간 잡음 우세이면 — 어떤 게인 맵으로도 줄지 않는 값이며 FUNC-017 이 프레임의 선량을 정하지 않는다는 것이 문제의 중심. 고정 구조 우세인데 0.5 % 를 넘으면 알고리즘 개선 대상.
4. 판정 불가: 그룹 장 수가 1 이하이거나 분해의 합이 맞지 않을 때.

## 예측 (결과 전)
- 공식 값은 라이브러리 값과 소수 넷째 자리까지 같다(numpy 의 모집단 표준편차 가정; 아니면 표본 표준편차 차이로 1e-6 수준).
- `Bright_17` 의 1.27 % 는 **시간 잡음 우세**: 261 에서 3장 평균의 시간 잡음이 0.6517 % 였으므로 한 장 약 1.13 %, 시간 몫 약 0.79. 고정 성분은 0.2~0.6 % 대.
- 그룹 안의 첫 프레임 `Bright_17` 이 같은 그룹의 `18, 19` 보다 눈에 띄게 높다(평균 신호가 1.5 % 낮은 첫 프레임 효과). 다른 그룹의 첫 프레임에도 같은 경향이 있을 수 있으나 약하다.
- 한 선량 게인 맵의 선량 의존성은 **없다**: 어느 대안 맵도 P_fix,avg 를 30 % 줄이지 못하거나, 줄이더라도 맵 잡음 차(0.24 % 대 0.19~0.24 %)로 설명된다. 고정 성분의 공간 모양은 국소 성분(백색에 가까운 게인 맵 잡음)이 대부분이고 행·열·저주파는 작다.
- 분류 예측: `Bright_17` = 요구 해석 문제(+데이터 한계: 저선량 3장); `Bright_20` 0.78 % 와 `29, 30` 0.64 % = 시간 잡음이 반 이상인 혼합 또는 시간 우세, 1.0 % 이내이고 0.5 % 초과; `31, 34` 는 0.5 % 이내.
