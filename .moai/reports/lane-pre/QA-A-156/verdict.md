### "안 갈렸다" 보다 강한 근거 — **갈리는 데 필요한 크기가 아닙니다**

원 프레임만 봤다면 근거가 약했을 것입니다. 값이 전부 10~17% 로 **문턱 1% 근처에 오지도 않아**,

게인 맵을 다른 선량에 적용한 교차 선량 평탄화 보정.

거기서 두 식은 **`9.0330` 대 `9.0330`** 으로 소수점 넷째 자리까지 같습니다.

| | 두 식의 상대 차이 |
|---|---|
| 실물 보정 프레임 | **< 0.01 %** |
| 실물 원 프레임 (최대, `bright03`) | 1.2 % |
| `QA-A-155` 에서 **뒤집힘이 일어난** 합성 입력 | **5.7 %** |

**실물에서 관측된 차이는 뒤집힘에 필요한 크기보다 자릿수가 작습니다.** 보정된 프레임은 대칭에
가까워 평균과 중앙값이 사실상 같아지고, 뒤집힘을 만들었던 합성 입력은 화소 10% 를 한쪽으로
민 **치우친** 분포였습니다.

곁가지: `dark.raw` 전 화소에서 평균 2503.1270, 중앙값 2505.0000 — **차이 1.87 ADU** 입니다.

## §3 카드가 3곳이라 했는데 **5곳입니다** — 나머지 둘은 보고만

`compute_robust_mean` 호출처 전수:

| 자리 | 함수 | 처리 |
|---|---|---|
| `:296` · `:386` · `:390` | offset·gain | **고침** |
| **`:603` · `:606`** | `xpe_verify_pipeline` | **보고만** |

파이프라인 쌍은 SNR 을 이렇게 냅니다:

```cpp
double snr_raw   = 20.0 * std::log10(mean_raw / std_raw);      // :610
double snr_final = 20.0 * std::log10(mean_final / std_final);
metrics->snr_improvement_db = snr_final - snr_raw;
```

**맞출 정본이 없습니다.** 정본에서 SNR 계열로 정의된 것은 `Protocol.md:194` 의
`PSNR = 20·log10(65535 / RMSE)` 뿐이고, 이는 **다른 양**입니다. 두 프레임의 변동계수 비를
dB 로 낸 이 값에 대응하는 정의를 `docs/` 에서 찾지 못했습니다.

그래서 여기는 *"정본과 다르다"* 가 아니라 *"정본이 없다"* 입니다 — 그 게이트를 먹이는
`SNR_IMPROVE_MIN_DB` 가 `QA-A-152` 에서 **출처 없음**으로 분류된 넷 중 하나인 것과 같은 자리입니다.
같은 헬퍼를 쓴다는 이유만으로 함께 바꾸면 **근거 없이 값을 옮기는 일**이 되어 두었습니다.
