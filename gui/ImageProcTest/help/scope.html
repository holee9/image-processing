Scope

Current Build Scope and Limitations

GUI-S0 is intentionally narrow. It proves the host shell, fixture path, telemetry surfaces, and settings persistence before native DLL integration begins.

Included

  • Mock backend initialization and shutdown
  • Raw binary image loading and preview rendering
  • Source-vs-processed comparison viewport with swipe, split, overlay, difference, zoom, pan, and optional detach
  • Calibration path settings
  • Logs, alerts, and fixture-first automation
  • Offline packaged help pages

Excluded

  • Real native P/Invoke backend
  • Real DICOM read/write
  • Phase 1a preprocessing controls
  • Full Phase 1b EI and DICOM workflow controls
  • Tile-backed rendering for images beyond the 4096x4096 comfort envelope
  • Phase 2 and Phase 3 premium or assistive features

Ownership Boundary

Real DICOM behavior remains owned by xpe_dicom.dll. Real runtime activation remains owned by the native integration sprint. The comparison viewport is a host review surface: it preserves the source frame, displays processed output as a separate layer, and records viewport state for evidence.
