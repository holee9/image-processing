ImageProcTest

Offline Help Bundle

This build ships a local quick-start and scope guide so the operator can run and check the first processing stage on a real raw image without relying on a network connection.

Quick Start

Start the app on the Native backend, set the calibration folders, load a raw image, run Phase 1a preprocessing, compare the result, and read the messages when it does not work.

Scope and Limitations

Understand what the Mock and Native backends do today, what is not available, and how the app's preprocessing differs from the module's own pipeline.

Current Build Intent

  • Native backend: real display pipeline and Phase 1a preprocessing on a loaded raw image
  • Mock backend: synthetic results for shell and automation checks, always marked [MOCK]
  • Raw binary image loading only; no DICOM open yet
  • Logs, alerts, calibration directories and fixture-first E2E are active
