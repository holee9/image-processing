Quick Start

Validate the GUI-S0 Shell

Use this procedure to verify the current GUI shell exactly the way the packaged fixture and E2E path expect.

  1. Launch ImageProcTest.exe.
  2. Confirm the status bar and runtime panel show the mock backend version v0.0.0-mock.
  3. Select Load Raw Image and open the packaged fixture under fixtures/gui-s0/raw/.
  4. Review the Source vs Processed Comparison viewport, image summary, logs, and alerts.
  5. Select a comparison mode such as SwipeVertical, OverlayOpacity, or DifferenceHeatmap.
  6. Use mouse wheel zoom, right-drag pan, and left-drag swipe movement to inspect large images in one synchronized viewport.
  7. Open calibration directories or adjust raw and display settings if needed.
  8. Select Save Settings to persist the current GUI-S0 paths and comparison viewport state to appsettings.json.

Expected Visible Results

  • The image summary begins with RAW 1024x1024 for the packaged fixture, or the selected raw dimensions for automation inputs.
  • The comparison viewport defaults to SwipeVertical with the source layer on the left and processed layer on the right.
  • The detached comparison viewer opens from the display settings panel when a larger review surface is needed.
  • Logs increase after a successful raw load.
  • Alerts are present and severity-colored.
  • The last raw directory persists after saving settings.
