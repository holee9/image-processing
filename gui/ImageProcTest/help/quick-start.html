Quick Start

Validate the GUI-S0 Shell

Use this procedure to verify the current GUI shell exactly the way the packaged fixture and E2E path expect.

  1. Launch ImageProcTest.exe.
  2. Confirm the status bar and runtime panel show the mock backend version v0.0.0-mock.
  3. Select Load Raw Image and open the packaged fixture under fixtures/gui-s0/raw/.
  4. Review the source preview, processed preview, image summary, logs, and alerts.
  5. Open calibration directories or adjust raw settings if needed.
  6. Select Save Settings to persist the current GUI-S0 paths to appsettings.json.

Expected Visible Results

  • The image summary begins with RAW 1024x1024.
  • Logs increase after a successful raw load.
  • Alerts are present and severity-colored.
  • The last raw directory persists after saving settings.
