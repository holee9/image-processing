## 3. 위험 식별 표

### HAZ-EB-001: Log Transform에서 log(0) 오류

| 필드 | 값 |
|------|-----|
| **위험 ID** | HAZ-EB-001 |
| **위험 상황** | ε = 0 또는 음수 → log(0) 또는 log(음수) → -∞ 또는 NaN → 다운스트림 CLAHE/Window가 무한대 처리 → 화면 출력 오류 또는 응용 충돌 |
| **원인** | ε 계산 버그, 입력 검증 누락 |
| **영향 SWU** | SWU-2.1 (LogTransform) |
| **심각도** | 심각 (이미지 출력 불가) |
| **확률** | 거의 없음 (코드 검토 + 단위 테스트로 포착) |
| **위험도 (전)** | **낮음** |
| **통제** | FR-200-002: ε = max(1e-6 × range, 1e-3), ε > 0 검증 |

### HAZ-EB-002: EI를 로그 변환 후 계산

| 필드 | 값 |
|------|-----|
| **위험 ID** | HAZ-EB-002 |
| **위험 상황** | EI를 Stage 5 (로그 변환) **후**에 계산 → log 함수에 의해 신호 압축 → EI가 과다 추정 → DI가 거짓으로 0에 가까움 → 실제 선량 이상을 간과 |
| **원인** | 실행 순서 오류, 데이터 도메인 규칙 위반 |
| **영향 SWU** | SWU-2.0 (EI_Baseline), SWU-2.1 (LogTransform) |
| **심각도** | 심각 (선량 지표 오류) |
| **확률** | 원격 (설계 명세서에 명시, 코드 리뷰로 포착) |
| **위험도 (전)** | **낮음** |
| **통제** | SAF-100-001: EI 계산은 로그 **전**에 (명확한 순서), 데이터 도메인 규칙 문서화 |

### HAZ-EB-003: CLAHE 과도한 증폭

| 필드 | 값 |
|------|-----|
| **위험 ID** | HAZ-EB-003 |
| **위험 상황** | clip_limit 너무 높음 (> 0.1) → 히스토그램 clipping 약함 → 노이즈 과도 증폭 → 배경에서 인공 구조 생성 → 위음성 진단 (인공 병변 감지) |
| **원인** | 잘못된 구성, 프리셋 오류 |
| **영향 SWU** | SWU-2.2 (CLAHEProcessor) |
| **심각도** | 심각 (위양성 진단) |
| **확률** | 원격 (구성 범위 검증: 0.01~0.1) |
| **위험도 (전)** | **낮음** |
| **통제** | FR-300-003: clip_limit 범위 [0.01, 0.1], 범위 외 → 오류, 검사 프리셋 최적화 |

### HAZ-EB-004: 잘못된 Window Preset 선택

| 필드 | 값 |
|------|-----|
| **위험 ID** | HAZ-EB-004 |
| **위험 상황** | Window preset 잘못됨 (예: 골격 환자에 복부 preset 적용) → WC/WW가 조직 최적화되지 않음 → 대비 감소 → 미묘한 병변 시인성 저하 → 진단 오류 |
| **원인** | 검사 유형 잘못 입력, 프로필 실수 |
| **영향 SWU** | SWU-2.4 (ExamProfileManager), SWU-2.3 (WindowLevelMapper) |
| **심각도** | 심각 (진단 신뢰도 저하) |
| **확률** | 원격 (임상 워크플로: 자동 프리셋 선택 또는 기본값 사용) |
| **위험도 (전)** | **낮음** |
| **통제** | FR-400-004: 표준 검사 프리셋 제공, 사용자가 선택 또는 기본값 사용 |

### HAZ-EB-005: Window Width 음수 또는 0

| 필드 | 값 |
|------|-----|
| **위험 ID** | HAZ-EB-005 |
| **위험 상황** | WW ≤ 0 → 윈도우 계산 분모가 0 또는 음수 → 무한대 또는 역 명도 → 출력 NaN 또는 부정확 |
| **원인** | 잘못된 구성 입력, 사용자 오류 |
| **영향 SWU** | SWU-2.3 (WindowLevelMapper) |
| **심각도** | 심각 (이미지 출력 오류) |
| **확률** | 원격 (범위 검증) |
| **위험도 (전)** | **낮음** |
| **통제** | FR-400-005: WW > 0 검증, 범위 외 → `XPE_ERR_INVALID_PARAM` |

### HAZ-EB-006: Log Transform 단조성 위반

| 필드 | 값 |
|------|-----|
| **위험 ID** | HAZ-EB-006 |
| **위험 상황** | Log 함수 구현 오류 → 픽셀 I1 < I2인데 log(I1) ≥ log(I2) → 대비 반전 또는 평탄화 → 미묘한 구조 시인성 저하 |
| **원인** | 구현 버그, 테스트 누락 |
| **영향 SWU** | SWU-2.1 (LogTransform) |
| **심각도** | 심각 (이미지 품질 저하) |
| **확률** | 거의 없음 (표준 라이브러리 log() 사용) |
| **위험도 (전)** | **낮음** |
| **통제** | FR-200-005: 단조성 검증 테스트 (100 무작위 쌍) |

### HAZ-EB-007: 구성 파일 손상

| 필드 | 값 |
|------|-----|
| **위험 ID** | HAZ-EB-007 |
| **위험 상황** | JSON 구성 파일 손상 (형식 오류, 누락된 필드) → 파싱 실패 → 기본값 또는 오래된 프리셋 사용 → 부정확한 강화 |

| **통제** | SAF-200-001: JSON 스키마 검증, 손상 시 기본값 사용 및 경고 |
