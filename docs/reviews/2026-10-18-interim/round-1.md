이슈: #276. 사용자 승인 기준: 요구사항별 구현, 경계값, 오류 처리, ABI, GUI 동작.

## 고정 범위

main d06de68c / pre 75c00431 / post d0e66d77 / GUI 541ee6d1 / 문서 ceb088a4.
각 레인의 소유 경로를 합쳐 비교하되 실제 병합본으로 간주하지 않았다. 제품 GUI `gui/`와 진단 앱 `clients/`를 모두 포함했다.

## 전수 조사

- 고정 Git 객체에서 대상 1,062파일을 읽어 문서198개, SRS·SPEC 정의 문서30개를 조사했다.
- 규범 ID 선언 후보1,018행을 인용 행렬로 추출했다. 코드 인용0인 행762개, 시험 인용0인 행736개는 **미구현 수가 아니다**. ID 없는 기능 구현과 기능명이 다른 시험을 수작업 의미 대조 없이 부재로 확정하지 않았다.
- 이 행렬은 추적성의 탐색 목록이며 합격표가 아니다. 일부 문서에는 정형 ID가 없고, 같은 ID가 여러 권위 문서에 반복된다. 따라서 전체 제품 요구 개수나 검증률의 분모로 사용할 수 없다.
