## 1. 요약

본 문서는 X-ray FPD(Flat Panel Detector) 시스템에서 사용되는 **Bad Pixel Map(BPM) 생성 알고리즘**의 발전 과정을 분석합니다.

**핵심 내용:**
- **MC 알고리즘**: 종래의 기본 검출 방식 (마스크 기반 중앙값 비교)
- **Blue 알고리즘**: 개선된 알고리즘으로, MC 대비 이상 영상(그리드 아티팩트) 환경에서 우수한 성능
- **XPE RMM 방식**: Robust Mask Maker (lambda=8.0) 적용으로 더욱 견고한 검출 기반 마련

**표준 준수:** IEC 62304 Class B 의료기기 소프트웨어 요구사항에 부합하도록 알고리즘 선택 및 검증

## 2. MC 알고리즘 상세 (기존 기술)

### 2.1 개요

MC(Mask Compare) 알고리즘은 픽셀 주변 영역의 중앙값(Median)을 기준으로 불량 픽셀을 검출하는 방식입니다.  
이는 상대적으로 단순한 구현으로 인해 오래전부터 사용되어 왔습니다.

### 2.2 어두운 영상(Dark) 불량 픽셀 검출 (MC Algorithm)

#### 알고리즘 흐름

```
1. 초기 매개변수 설정
   dark_median = median(dark_image) × 0.3  [스케일 인수]
   Min1, Max1 = dark_median ± dark_median
   Min2, Max2 = dark_median ± 2×dark_median

2. 각 픽셀 (x,y)에 대해 반복:
   
   2.1 1단계 검사 (지역 비교)
       buffer1 = 256(열) × 7(행) 영역 [픽셀 중심]
       buffer1_median = median(buffer1)
       
       비정상 판단 조건 1 (신뢰도 낮음):
       if buffer1_median < Min1 or buffer1_median > Max1:
           → 2.2단계로 진행
       else:
           → 정상 픽셀 (불량 아님)
   
   2.2 2단계 검사 (광역 비교, 신뢰도 향상)
       [Step 1에서 의심 픽셀만 진행]
       buffer2 = 1(열) × 45(행) 영역 [±22 픽셀 범위]
       buffer2_median = median(buffer2)
       
       비정상 판단 조건 2 (신뢰도 높음):
       if buffer2_median < Min3 or buffer2_median > Max3:
           where Min3, Max3 = buffer2_median ± dark_median
           → BPM[x,y] = 127 (불량 픽셀 마크)
       else:
           → 정상 픽셀 (Step 1 오경보)
```

**핵심 매개변수:**
- 단계 1 윈도우: 256×7 픽셀 (대략적 판정)
- 단계 2 윈도우: 1×45 픽셀 (수직 방향 확인)
- 스케일 인수: 0.3 (다크값의 30%)
- 판정 임계값: ±1배, ±2배 범위

#### 특징 및 문제점

| 항목 | 설명 |
|------|------|
| **장점** | - 구현이 단순함 <br> - 계산 속도가 빠름 <br> - 기존 시스템에서 검증됨 |
| **단점** | - 고정된 임계값(0.3배수)으로 인한 민감도 부족 <br> - 이상 영상 환경(그리드 아티팩트)에서 검출 실패 <br> - 국소적 아티팩트에 취약 <br> - 다단계 검사로 오경보 가능성 |

### 2.3 밝은 영상(Bright/Flat-field) 불량 픽셀 검출 (MC Algorithm)

#### 알고리즘 흐름

```
1. 초기 매개변수 설정
   total_calset_median = median(모든_CalSet_데이터) × 0.15

2. 각 픽셀 (x,y)에 대해 반복:
   
   2.1 지역 부분마스크 생성
       sub_mask = 60(열) × 60(행) 버퍼 [픽셀 중심]
       avg_sub_mask = average(sub_mask)
   
   2.2 조정된 픽셀값 계산
       value = calset_data[x,y] - avg_sub_mask
   
   2.3 불량 판정
       if value < total_calset_median or value > total_calset_median:
           → BPM[x,y] = 표시 (불량)
       else:
           → 정상 픽셀
```

**핵심 매개변수:**
- 부분 마스크 크기: 60×60 픽셀
- 전체 중앙값 스케일: 0.15 (15%)
- 대칭적 양단측 판정 (< 또는 >)

#### MC Bright 검출 특징

| 항목 | 설명 |
|------|------|
| **장점** | - 전체 데이터 통계 활용 <br> - 국소적 변동에 낮은 민감도 |
| **단점** | - 0.15 스케일은 시스템 특성에 따라 너무 높거나 낮을 수 있음 <br> - 다중 게인 시스템에 부적합 <br> - 고정 윈도우 크기로 인한 적응성 부족 |

## 3. Blue 알고리즘 개선 사항

### 3.1 개요

Blue 알고리즘은 MC 알고리즘의 한계를 보완하기 위해 개발되었습니다.  
주요 개선사항은 **더 작은 윈도우 크기**, **시그마 기반 기준**, **동적 허용도 조정**입니다.

### 3.2 어두운 영상(Dark) 불량 픽셀 검출 (Blue Algorithm)

#### 알고리즘 흐름

```
1. 매개변수 설정
   Mask = 32×32 픽셀 윈도우

2. 각 픽셀 (x,y)에 대해 반복:
   
   2.1 마스크 평균 계산
       Mask_Average = average(32×32 윈도우)
   
   2.2 시그마 기반 판정 (정규분포 가정)
       Sigma = standard_deviation(32×32 윈도우)
       
       불량 판정 조건:
       if |pixel_value(x,y) - Mask_Average| > k × Sigma:
           where k = 5 (또는 6)
           → BPM[x,y] = 불량 마크
       else:
           → 정상 픽셀
```

**핵심 매개변수:**
- 윈도우 크기: 32×32 픽셀 (MC의 256×7에 비해 훨씬 작음)
- 시그마 배수: k = 5 ~ 6 (통계적 이상치 탐지)
- 방향: 양단측 (절댓값 비교)

#### MC 대비 개선점

| 차원 | MC | Blue |
|------|-----|------|
| **윈도우 크기** | 256×7 (매우 비대칭) | 32×32 (균형잡힘) |
| **판정 방식** | 고정 스케일(0.3배) | 통계적 시그마 기반 |
| **적응성** | 없음 | 지역 표준편차 반영 |
| **속도** | 약간 빠름 | 약간 느림 (sigma 계산) |

### 3.3 밝은 영상(Bright/Flat-field) 불량 픽셀 검출 (Blue Algorithm)

#### 알고리즘 흐름

```
1. 매개변수 설정
   Mask = 128×128 픽셀 윈도우
   Tolerance_weight = 5 ~ 9% (기존 MC: ~15%)

2. 각 픽셀 (x,y)에 대해 반복:
   
   2.1 큰 마스크 평균 계산
       maskAvg = average(128×128 윈도우)
   
   2.2 허용도 계산
       Bright_Tolerance = maskAvg × Tolerance_weight
   
   2.3 불량 판정
       if |calset_data[x,y] - maskAvg| > Bright_Tolerance:
           → BPM[x,y] = 불량
       else:
           → 정상 픽셀
```

**핵심 매개변수:**
- 마스크 크기: 128×128 픽셀 (MC 60×60 대비 2배 이상)
- 허용도: maskAvg의 5~9% (MC의 15% 대비 감소)
- 대칭적 양단측 판정

#### Blue Bright 개선 이유

| 요소 | 기존(MC) | 개선(Blue) | 이유 |
|-----|----------|-----------|------|
| **윈도우** | 60×60 | 128×128 | 더 큰 통계적 기반으로 안정성 향상 |
| **허용도** | 15% | 5~9% | 보수적 임계값으로 오경보 감소 |
| **통계** | 고정 범위 | 마스크 평균 기반 | 국소 특성 반영 |

- σ±6 (더 보수적): 적은 탐지

## 5. XPE 개선 권고 사항

### 5.1 XPE에서 RMM(Robust Mask Maker) 도입 이유

XPE 시스템에서는 **RMM (lambda=8.0)**을 사용합니다. 이는 Blue 알고리즘의 아이디어를 더욱 발전시킨 것입니다.

| 특성 | MC/Blue | XPE RMM |
|------|---------|---------|
| **기초 방식** | 마스크 중앙값 비교 | 강건 통계량 (M-estimator) |
| **이상치 민감도** | 중간 | 낮음 (강건성) |
| **매개변수** | 고정 스케일 (%) | 적응형 lambda |
| **이상 환경 대응** | 취약 | 우수 |

### 5.2 권고 사항 1: 다중 게인 보정 프레임 개수 명시

**현재 상태:** SRS-CALIB-FUNC-006에서 "N ≥ 10"이라고만 명시

**권고:**
- **최소 요구**: 5~10 프레임 (신호 안정화)
- **표준 권고**: 15~20 프레임 (DSNU 감소)
- **우수 품질**: 25~30 프레임 (최상의 비선형성 LUT)

**근거:** Blue 알고리즘 분석에서 프레임 개수는 통계적 안정성에 직접 영향

### 5.3 권고 사항 2: BPM 윈도우 크기 SRS 추가

**현재 상태:** RMM lambda=8.0만 명시, 실제 마스크 크기 미명시

**권고 추가 요구사항:**
- **다크 불량 검출**: 32×32 이상 윈도우 (Blue 기준)
- **밝음 불량 검출**: 128×128 이상 윈도우 (Blue 기준)
- **시그마 배수**: k=5 ~ 8 범위 설정 가능

→ **SRS-CALIB-FUNC-022, FUNC-023 추가** (섹션 2.6 참조)

### 5.4 권고 사항 3: 그리드 아티팩트 견고성 검증

**현재 상태:** 표준 테스트 데이터에만 의존

**권고:**
- Grid_abnormal 데이터셋을 정규 CI/CD 테스트에 포함
- BPM 생성 후 출력 이미지의 **라인 아티팩트 스코어** 계산
- 임계값: LineArtifactScore ≤ 10% (SKVX 시각 기준)

→ **SRS-CALIB-FUNC-025 추가** (섹션 2.6 참조)

### 5.5 권고 사항 4: 다중 게인 (CalSet) 다항식 피팅

**현재 상태:** 지원 예정 (SRS-CALIB-FUNC-005에 언급)

**권고:**
- **CalSet 파일 형식 확립**: `CalSet_{ADU_level}.raw`
  - 예: CalSet_14037.raw, CalSet_17285.raw, ... (ADU 값이 파일명)
- **다항식 차수**: 2 ~ 3차 (과적합 방지)
- **검증**: 각 dose level에 대해 보간 오차 ≤ 2% ADU

→ Cyan 데이터셋의 5개 CalSet 파일로 이미 검증 가능
