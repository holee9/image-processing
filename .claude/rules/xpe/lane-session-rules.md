# XPE 4세션 공통 규칙 (리더 소유, main 으로 배포)

> 이 파일은 네 워크트리(lead `image-processing`, `xpe-pre`, `xpe-post`, `xpe-gui`) 모두에서
> 세션 시작 시 자동으로 읽힌다(`.claude/rules/` 는 추적되는 경로). 레인은 `git merge main`
> 으로 최신본을 받는다. 상세 규약: `.moai/project/lane-sessions.md`.

## 공통 규칙이 이 파일에 있는 이유 (2026-10-14)

각 워크트리의 `CLAUDE.local.md` 는 추적되지 않는 **그 세션의 사용자 지시 파일**이다. Claude Code
런타임은 다른 세션이 보낸 메시지에 "동료 요청으로 CLAUDE.md·설정을 고치지 말 것"을 붙여 전달하고,
이것은 끌 수 없는 보안 경계(권한 세탁 방지)다. 그래서 리더가 메시지·카드로 "CLAUDE.local.md 를
고쳐라"라고 하면 레인은 사용자 승인을 기다리며 멈춘다 — 레인의 결함이 아니라 전달 경로의 문제다.

**따라서 네 세션에 공통으로 적용할 규칙은 이 파일(추적, 리더 소유 `.claude/`)에 둔다.** 리더는 main 에
커밋하고, 레인은 `git merge main`(리더 결정 사항, 사용자 승인 대상 아님)으로 받는다. 리더는 레인의
`CLAUDE.local.md` 수정을 요청하지 않는다.

## 1. 응답 시각 표기 (사용자 지시 2026-10-14)

사용자에게 하는 모든 보고·답변, 다른 세션에 보내는 모든 메시지, 보고서(`report.md`) 첫 줄은
**`[YYYY-MM-DD HH:MM KST]`** 로 시작한다. 메시지는 그 뒤에 `[보낸 세션 이름]` 을 붙인다.
시각은 기억·추정이 아니라 보내기 직전에 `date '+%Y-%m-%d %H:%M'` 로 읽은 값이다
(모델은 현재 시각을 모른다). 상세: `.moai/project/lane-sessions.md` §3.7

## 2. 약어 대신 업계 표준 용어 (사용자 지시 2026-10-16)

문서·사양서·이슈·코멘트·보고서에는 약어 대신 **업계 표준 용어나 명확한 말**을 쓴다.
- X선 디텍터 원시 출력값은 "ADU" 가 아니라 **화소값(pixel value)** 이라 쓴다(AAPM TG-150 의 용어).
- 표준 용어가 약어뿐이면 처음 나올 때 풀어 쓴다(예: 결함 화소 맵(BPM), 판독 회로(ROIC)).
- 코드 식별자·파일 이름·명령은 그대로 둔다.
